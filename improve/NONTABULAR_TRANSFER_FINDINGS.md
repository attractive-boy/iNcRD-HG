**本轮使用配对表格特征的非预训练预测器与检索/传播/PU 修正，没有通过相对已接受 TabICL 参考的联合门槛。** 树、MLP、SVM 等仍是表格预测器，不能将其失败概括成“非表格技术无效”。后续直接图/矩阵实验已发现“GNN＋乘积核”相对原 GNN 的增益，见 [后续审计报告](NON_TABULAR_FRONTIER_FINDINGS.md)；它仍未超过强 TabICL 参考。

本轮另检验了检索、转导标签传播、PU 先验重加权，以及三个开发集重划分上的组合。`pu_gbdt w=0.1` 的 MiDrug 两指标在三个划分中都上升，但 LncDrug 一个划分的 AP 下降约 0.001，未通过该轮预设门槛。三个重划分来自同一开发数据池、彼此重叠，不是独立生物或外部验证；不同方案的局部正负变化均应保留，不能概括为其余结果全部稳定为负。

2026-09-14。参考固定为已接受的 `0.5 × graph_context + 0.5 × tiered_evidence` TabICLv2 分数（MiDrug `0.962593 / 0.927204`，LncDrug `0.993750 / 0.987141`）。所有成员、权重和门槛在读取指标前固定，没有结果后的系数搜索。

## 一、非预训练表格预测器的系统筛查（内部划分）

在冻结的 62 维证据特征库（`tiered62`）上从头训练 8 类打分器，再与参考按固定 logit 权重融合。结果是内部划分上绝大多数成员单独或小权重融合都不通过门槛；只有少数在内部划分“看起来通过”。

|---|---:|---:|---|
| HistGradientBoosting | 0.956178 / 0.917449 | 0.993607 / 0.987349 | 否（MiDrug 降） |
| ExtraTrees | 0.960869 / 0.923659 | 0.992561 / 0.982486 | 否（LncDrug 降） |
| RandomForest | 0.959921 / 0.914986 | 0.993104 / 0.983235 | 否 |

| kNN 检索 | 0.944145 / 0.896155 | 0.987760 / 0.973306 | 否 |
| 线性 logistic | 0.951259 / 0.914686 | 0.990146 / 0.976383 | 否 |

## 二、开发集重划分验证：内部的正增益区未稳定迁移

`validate_transfer_splits.py` 提供了 3 个新的开发集重划分（split 42 / 2026 / 31415），每个从头训练的打分器在 36 维图特征上重新拟合，与对应的已接受 `tiered` 参考融合：

| 技术 | MiDrug 平均 ΔAUC / ΔAP | LncDrug 平均 ΔAUC / ΔAP | 3 划分全部为正？ |
|---|---:|---:|---|
| `hgb` w=0.05 | +0.000108 / +0.000172 | +0.000195 / +0.000048 | 否（split 2026 负） |
| `mlp` w=0.05 | −0.000001 / −0.000005 | +0.000029 / +0.000002 | 否 |
| `et` w=0.05 | −0.000034 / +0.000080 | +0.000065 / +0.000323 | 否 |

内部划分上 `ref + 0.1×MLP` 的“六格全正”未在这三个重划分中保持。现有证据不能区分开发选择偏差与划分波动，不能断言局部增益完全由反复使用内部划分造成。

同时，直接把 3 个重划分上已经算好的 5 条 arm（gnn / tabm / tabicl / graph_context / tiered）做低权重融合，**没有任何组合**能让 MiDrug 上升且 LncDrug 不降；所有组合的 MiDrug ΔAP 都落在 `-0.0003 ~ 0.0000`。这包括非表格的 GNN（`gnn`）——它与参考互补性不足，融合只能拉低。

## 三、三个具名非表格技术

代码：[nontabular_transfer.py](nontabular_transfer.py)。结果：`results/nontabular_transfer_20260914/{RESULTS.json,inner_summary.csv,resplit_deltas.csv}`。

| 技术 | 机制 | 内部划分 | 3 重划分 |
|---|---|---|---|
| `retrieval_knn` | 特征空间距离加权 kNN 检索（无参数） | 全部负 | MiDrug ΔAP 平均 −0.005 ~ −0.008，稳定负 |
| `label_prop` | 在配对特征 kNN 图上做转导标签传播（Zhou 2004），利用评测流形 | 全部负 | MiDrug ΔAP 平均 −0.0008 ~ −0.0045，稳定负 |
| `pu_gbdt` w=0.1 | 把 0 当作未观测，按估计逆倾向给正例重加权后拟合 GBDT | **过门槛**（6/6 格正） | MiDrug 3/3 划分正（+0.00025/+0.00064/+0.00010）；LncDrug 混合（−0.0001/−0.0004/+0.0002） |

`pu_gbdt` 是本轮较接近的候选：它在内部划分上严格通过，重划分上 MiDrug 的 AUC 在 3/3 划分均为正、AP 在 2/3 划分为正（split 31415 的 AP 为 −0.000040）；但 LncDrug 在 split 2026 的 AP 下降 **0.000996**，超过“扰动级”容忍，故不能作为联合改进。它作为“观察过程建模（PU）”方向的弱先验值得保留。注意：该 `pu_gbdt` 是在 **36 维图特征**上拟合的；后续在完整 62 维证据特征上重做时结果更好，见 [ANCHOR_SHRINKAGE_FINDINGS.md](ANCHOR_SHRINKAGE_FINDINGS.md)。

## 四、为什么非表格技术在这条协议上难有增量

以下观察限定在本轮特征、预测器和比较对象内：

1. **参考已吸收了图结构信息。** 冻结的 36 维图特征本身就包含协同过滤（`collab_*`）、长度 3/5 路径（`path3/path5`）、SVD16 低秩分解、桥接与属性支持。非表格的 CF / 图传播 / 检索只重算这些量，不新增信息。
2. **本轮较强的候选来自 TabDPT。** 其历史内部 MiDrug 结果为 `0.963903/0.929644`，但应按 [修正后的 TabDPT 报告](FOUNDATION_TRANSFER_FINDINGS.md) 理解证据范围。较弱成员也可能提供互补信息，不能从这一轮失败推导“融合必然只会稀释”或替代独立确认。
3. **重划分揭穿了内部增益。** 3 个开发集重划分上，任何 arm 组合都无法超过 `tiered`。这与历史结论（图模型 / HGT / 序列模型 / 对比学习均未超过强参考）一致。

## 五、正确结果与建议

- 本文测试范围内没有通过相对强 TabICL 参考的共同门槛。该结论不覆盖未测试的直接图模型；树、线性模型及多数核分类器在这里使用的仍是配对表格特征。
- TabDPT 是历史内部筛查中的较强候选；新增证据也必须通过信息量、打乱和分组对照，不能将所有位点/靶点语义输入都概括成已验证有效。后续直接图核组合的正结果与限制另见上述审计报告。
- **方法学教训：** 内部划分已被反复使用，任何“内部通过”的融合都必须先在 3 个开发集重划分上复验；本轮的低权重正增益区就是反例。

## 边界

- 内部划分与 3 个重划分都是开发数据；3 个推理种子是随机性，不是独立生物划分。
- 未打开历史外层、原始关联测试或来源留出数组；未替换已接受模型。
- `0` 标签仍是采样未观测配对，不是已验证生物阴性。
- 复现：`python -m improve.nontabular_transfer report`；筛查脚本与逐项 CSV 见 `results/nontabular_transfer_20260914/screen/`。
