# 近期论文支持的其他改进方向

> **2026-09-12 调参更新：** 第一项原型又完成同预算 12 组配置、152 次训练。MiDrug 度数校正版本相对原 TabM 的 AP 增加约 0.123 个百分点，AUC/宏 AP 也提高；LncDrug 未超过原基线，仍没有双任务一致提升。详见 [调参结论](../../results/structure_program_tuning_20260912/FINDINGS.md)。

> **2026-09-11 后续实验更新：** 第一项“类型约束的结构程序搜索”已完成 56 次正式训练、四组对照和全部重放核验。当前原型未通过：LncDrug 搜索规则 AP 下降约 0.50 个百分点；MiDrug 度数校正 AP 微涨，但 AUC/宏 AP 下降。详见 [实验结论](../../results/structure_program_20260911/FINDINGS.md) 和 [实现说明](../../STRUCTURE_PROGRAM_SEARCH.md)。以下保留检索阶段的原始方案与判断；第二、三项尚未在本轮实现。

2026-09-11。**建议优先研究“类型约束的结构程序搜索”；跨关系迁移可以考虑“关联事实图”；若优先做低成本性能试验，则考虑“频率与配对相容性分解”。** 这些是待验证的研究设计，本轮没有新增训练或性能结果。

本次通过公开 arXiv API、PubMed、CrossRef 和 OpenAlex 做有限检索，主要范围为 2025-01-01 至 2026-09-11。它不是系统综述，也不构成首创认证。论文已按题名、作者、版本日期或 DOI 核对。arXiv 主站的 HTML/PDF 请求遇到连接重置，随后通过官方 `export.arxiv.org` 取得 Code evolution、Reification、SLogic 和 DDC 四篇 PDF，已核对题名、相关方法与限制；其余条目主要核对官方摘要和元数据。取得全文不等于已复现论文。各次成功和失败请求都保留在本目录。

**为什么换这些问题。** 当前图结构特征 + TabM 的 LncDrug 全局 AP 为 0.966260，高于原 GNN 的 0.943892，但按药物宏 AP 为 0.825590，低于原 GNN 的 0.892087。这是同一历史外层验证、三个初始化的比较；宏 AP 只覆盖该验证中有两类标签的药物。该现象提示，应同时检验“结构证据还缺什么”和“模型是否改善单药物候选排序”，不能单凭这个差异认定频率偏差是唯一原因。

已有 HGT、PENCIL、配对状态、双流传播、矩形闭环、局部案例适配和集合去噪原型未给出双任务一致的稳定收益；链路 PFN 已有研究提案。本轮建议不把这些原型换名后重新算成新增方向。历史依据见 [TabM](../../GRAPH_TABM.md)、[HGT](../../GRAPH_TRANSFORMER_BACKBONE.md)、[结构实验](../../STRUCTURAL_MODEL_FINDINGS.md) 和 [集合去噪](../../SET_DENOISING.md)。这些负结果只约束已运行配置。

| 方向 | 在本项目中要改变的核心 | 优先检验的收益 | 判断 |
|---|---|---|---|
| 类型约束的结构程序搜索 | 从固定 36 维图特征，推进到搜索少量新的关系组合与归一化规则 | 全局 AP 与药物内排序；规则跨划分稳定性 | 综合优先级最高 |
| 关联事实图与共享关系词表 | 将已观测关联和关系类型都作为输入节点，研究跨任务共享的传播规则 | 少样本和跨关系迁移 | 架构变化明确；新论文证据仍早期 |
| 频率与配对相容性分解 | 对表示中的频率方向做显式分解，并保留单独的频率分支 | 修复药物内排序，观察全局指标代价 | 原型成本较低；单独的创新空间较小 |

**1. 类型约束的结构程序搜索：让模型发现哪些关系组合有用。**

直接来源是 Vlaskin 与 Altmann 的 [Code evolution for link prediction in complex networks](https://arxiv.org/abs/2606.26132)，官方首发日期 2026-06-18。其第 2.2 节用 LLM 提议程序变异/交叉，并以十个合成或真实网络上的表现选择程序；第 4 节显示最优程序仍主要是拓扑特征加随机树或模型融合，作者明确没有发现全新的算法架构。它在其他网络上的结果不能转写成本项目的预期涨点。该文还发现某些候选利用节点编号，因此本项目语法应禁止原始 ID 数值特征，并检查节点重编号后的不变性。

另一个近邻是 Le 等人的 [SLogic: Subgraph-Informed Logical Rule Learning for Knowledge Graph Completion](https://arxiv.org/abs/2510.00279)，首发 2025-09-30，核对版本更新于 2026-08-22。第 4 节先用简单路径建立静态规则库，再用局部子图编码器赋予查询相关权重。它的直接启发是规则权重依赖查询局部上下文；不能把它描述成已经实现下面的程序语法或空模型校正。

当前 [PairFeatureEncoder](../../graph_tabm_modules.py) 的程序结构由人固定，TabM 学习的是这些数值如何组合。新的原型可以把搜索对象提前到特征生成过程：

1. 建立有类型检查的矩阵/集合运算语法。输入只用当前拟合集的 RNA–drug 关联、RNA 相似关系、药物相似关系和跨 RNA 桥接。候选运算可以包括关系顺序组合、排除回走的路径、邻域交集、最大支持与度数归一化。单纯重发现既有的 `bridge`、`path3`、`path5` 不算新增机制。
2. 用受限枚举或进化搜索选择少量短程序，加长度和冗余惩罚；无需先引入在线大模型服务。将每个程序的输出作为可解释特征，仍由相同 TabM 或稀疏预测头读出。
3. 一个值得单独检验的扩展是“超出度数预期的结构证据”：对当前支持图做保留关系类型及端点度数的随机交换，将真实程序值与空模型均值/方差比较。频率特征另行保留，避免直接抹掉现有全局信号。空模型不是生物学反事实，更不提供因果识别。
4. 对两个任务共享程序模板，允许少量任务系数变化；检验程序能否在稀疏 LncDrug 和相对稠密 MiDrug 中迁移。共享模板本身也需要单任务对照。

潜在贡献在于**哪些类型化结构规则在密度变化后仍提供超出简单频率的证据**。自动公式发现、逻辑规则和空模型标准化各自都有先例；这一组合目前只是本项目的候选增量。若搜索到的程序只是原 36 维特征的改写，不能据此立一个新方法故事。

最小对照：固定 36 维 + TabM；相同规模的随机程序特征 + TabM；搜索程序 + 同一 TabM；搜索程序加空模型校正。选程序、选系数与选停止轮数都留在内部开发划分，并限制搜索预算。先证明新增信息有效，再考虑查询相关规则权重，避免把搜索和更强预测头的作用混在一起。

所有依赖目标关联的操作须在遮蔽查询正边及反向边后重算，包括空模型。训练使用折外特征；不能先在完整关联图搜索程序再做交叉验证。小图无法有效随机交换时，需记录空模型退化并回退，不能用接近零的方差制造极端分数。

**2. 关联事实图：研究可以跨关系共享的表示方式。**

Pradel 的 [Reification as a Transferable Vocabulary: Zero-Shot Link Prediction with Vanilla GNNs](https://arxiv.org/abs/2609.11347) 于 2026-09-10 首发，本轮按预印本引用。第 3.1 节将每条事实变成一个节点，连接主体、客体和关系类型节点，使用六种固定元关系；关系类型是共享的匿名输入节点，而非每种关系单独一套模型参数。第 3.2 节用查询端点和关系节点标记进行条件化传播，并删除查询事实的六条连接。作者报告普通 GNN 在这种表示上获得跨图迁移能力。这篇非常新，尚不能把作者结果当作独立复现结论。

本项目的候选适配：

- 将可见的 `lncRNA–drug`、`miRNA–drug`、`lncRNA–miRNA` 等关联变为事实节点，与实体节点、关系节点共同组成图。保留真实 RNA 与药物属性；关系词表共享不能成为丢掉生物学类型区别的理由。
- 在多种已知关系上学习统一的消息传递，再检验某一种目标关系仅有少量支持时能否适配。主要改变是图表示与跨关系训练方式，而不是更换注意力公式。
- 对查询构造一致的标记和读出方式。查询正关联不得留在支持事实节点中，正例与未标注配对不能因为“是否创建查询节点”而泄露答案。

它与已做过的配对状态网络有近邻关系：边/配对表示已有先例。本轮值得验证的差别是**显式支持事实节点与共享关系词表能否带来迁移**。若只在当前固定随机边划分上涨一点，不能宣称证明了跨关系或零样本泛化。

最小对照：相同参数规模的原异构图；事实图但每种关系用独立参数；事实图加共享关系词表；取消跨关系预训练。先做开发数据内的少样本曲线。严格新药物试验要同时屏蔽该药物在各 RNA 关联中的通道；仅从一个任务删边是另一种较弱设置。

当前关系类型少、LncDrug 支持集中，跨任务迁移可能产生负迁移。原文使用每个查询一份全图、12 层传播；一个原图跳步变为两个事实图跳步，因此不能把它当成无成本的预处理。原论文报告的硬件时间也不能直接用于估算当前工程成本。

原文主要实验是无属性 KG，属性融合是本项目新增的适配；其全实体 softmax/filtered-ranking 与本项目多正例 BCE/AP 也不同。需保持任务适用的多正例目标，并给对照相同训练目标。原文第 5.3 节还报告孤立候选在特定基准上异常高排，当前零支持药物较多，必须检查不可达候选与属性读出的行为。公开代码尚未复现。

**3. 频率与配对相容性分解：面向当前宏 AP 损失的小原型。**

两篇近期依据：

- [Post-hoc Popularity Bias Correction in GNN-based Collaborative Filtering](https://arxiv.org/abs/2510.12959)，arXiv 元数据列出 WWW 2026，但其列出的 DOI 在本轮 CrossRef 精确查询返回 404，标题搜索也未找到同名条目，故本轮仅按已核对的预印本摘要引用。它在预训练表示中估计并移除流行度方向，不要求重训原推荐模型。
- [Rethinking Popularity Bias in Collaborative Filtering via Analytical Vector Decomposition](https://doi.org/10.1145/3770854.3780295)，**KDD 2026**，CrossRef 与 PDF 会议信息一致；[预印本](https://arxiv.org/abs/2512.10688) 首发 2025-12-11，核对版本 2026-01-18。其第 4 节 DDC 冻结原用户/物品表示，按用户学习偏好方向和流行度方向的两个校正系数，用非对称的正负项训练，再在推理时合并校正。它不是简单把热门药物扣一个常数，也不是已有的双 RNA–drug 端点投影模型。

本项目使用 BCE 和非点积预测头，不能直接套用第二篇关于 BPR 的理论结论。可迁移的是一个可检验的表示假设：RNA 与药物表示中，与训练频率高度相关的方向可能干扰具体配对的区分。

候选结构是 `总分 = 频率分支 + 配对相容性分支`。只从训练部分估计各节点类型的频率方向，相容性分支读取经过投影/收缩的表示并输出随 RNA–drug 配对变化的分数；频率分支保留粗粒度信号。配合内部选择的药物内排序目标，观察是否能补回宏 AP，并同时跟踪全局 AUC/AP。

**不能只给一个药物的所有 RNA 减同一个常数。** 这种修改不改变该药物内的排序，也不会提高其 AP。真正要检验的是配对交互项的几何变化。两个网络头也不会自动识别“研究偏好”和“真实耐药作用”，输出仍是关联分数。

最小对照：相同排序损失但不做投影；随机方向投影；简单频率重加权；有/无频率分支；现有 GNN 和 TabM。若缓存预训练分数或表示用于第二阶段拟合，要采用折外生成。该路线更适合低成本诊断与改进，直接迁移 PPD/DDC 的新颖性较有限。

这些论文适合作为需要补充核对的近期比较对象。“GNN + 扩散”“多模态 + LLM”“双分支 + 因果”本身已经不足以构成新的研究贡献。

**Sheaf 作为备选，暂不列首选。** [Deep Neural Sheaf Diffusion](https://arxiv.org/abs/2605.19021)，2026-05，作者备注为 ICML 2026 GFM Workshop 接收，使用矩阵值边函数和 sheaf adjacency 改善深层传播；这不是 ICML 主会录用信息。它确实提供了不同于标量边权的设计空间。

但 [On the Necessity of Learnable Sheaf Laplacians](https://arxiv.org/abs/2603.05395)，2026-03，发现恒等映射基线在其五个异配基准上可接近多种 Sheaf 模型；[Benchmarking Sheaf Neural Networks for Inductive Tasks](https://arxiv.org/abs/2608.02558)，2026-08，在其受控比较中发现外围架构组件的影响超过 sheaf 设计本身，且未超过最强基线。结合本项目的既有结构负结果，Sheaf 应先证明超过相同残差、归一化和容量的恒等/对角映射对照。不能用新名称或理论性质代替本任务证据，也不能从这些论文推断整个家族无效。

**实施顺序与结论标准。**

优先固定一个小预算的结构程序试验，保留同特征读出器和程序搜索对照；若更重视低成本恢复药物内排序，则先做第三条。第二条在明确研究少样本迁移后再投入。每项同时记录两个任务的全局 AP/AUC、按药物宏 AP、头部候选排序以及单药物变化分布。不能只根据一个指标选择“胜利版本”。

历史外层验证已经被多轮查看。新随机种子只检验初始化波动；同一批数据重切也不能称为全新的外部验证。开发期使用嵌套、分组的选择协议，正式泛化结论仍需没有参与方案选择的来源、时间批次或外部数据。

本轮产物包括原始检索、精确元数据、访问失败记录和本方案；未改动训练实现及已有实验结果。
