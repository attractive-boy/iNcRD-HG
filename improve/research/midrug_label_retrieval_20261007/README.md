先前独立8成员集成完成21次新拟合，内部均值AUC/AP为.954011346/.914335062，
成员残差相关约.99408；未通过双+.002推进门槛。不能由此断言一般性能上限。
本轮检验不同的学习机制：原属性检索训练案例，直接学习标签值与key差值的聚合。
原测试目标仍为seeds42/43/44平均AUC≥.9733929274189016、AP≥.933683373732677，
PLMF两数据集不降。仅原miRNA/drug，无lncRNA、外部数据、注释、序列或新权重。

## 文献和历史边界

近期文献及TabR原文/作者固定commit阅读见
`../midrug_task_literature_20261007/READING_NOTES.md`。
TabR是2023首发的较早参照，非2026新方法。采用其负平方L2、分类标签embedding、
key差值两层MLP及隐藏表示相加思路。原作者完整表格模型、数值embedding、dropout、
训练优化器和参数搜索未搬用。实现是本地适配，不是完整复现。
旧local_support已有配对top-k检索与Newton残差，未通过双指标筛选；本轮不同处在于
直接学习非线性values而非闭式误差修正，不能称检索家族首次尝试。

## 固定候选与对照

label：完整案例标签embedding加key差值MLP；唯一可推进候选。
features：相同检索与key差值MLP，不加入标签embedding。
direct：相同原属性查询编码与预测头，不加入任何检索结果。
三配置×三固定内折，seed42，共9次新拟合。既有纯M123和unmasked10复用不可变重放。
候选相对features、direct、纯M123和unmasked10的内折平均AUC/AP都≥+.002才推进。
不选择不同邻居数、宽度、种子或检查点组合，不读取原验证/测试。

## 输入及计算

两类型各按原全体节点的已有属性作逐列标准化，population std下限.05。
这是已允许的无监督转导属性，不从案例标签拟合标准化。
每类型原属性→64→64/ReLU得到node hidden，配对hidden是两个端点hidden之和。
共享Linear64→64产生key，分开计算两类型线性项后相加，避免query批次改变编码。
只有当折训练配对和观测标签进入案例库；正负查询都按完整pair ID删除自身。
按负平方L2检索32个最近案例，不作维数缩放；离散排序使用float64、稳定排序，
同距离按冻结案例顺序。选中后在float32重算距离softmax及值，允许反向传播。
值为label_embedding(0/1)+Linear64→128/ReLU→Linear128→64(末层无bias)。
查询hidden加加权值后进入LayerNorm64→Linear64/ReLU→Linear1，末层初始为零。
该标量加到原M123 logit上；重构模块和原查询删边主干保持不变。
label值初始uniform[-1,1]。没有读取原模型的支持训练预测，不使用拟合残差或OOF分数。
零标签仅为原数据的观测类别，不解释为真实药物敏感性。

所有模型模块定义相同，但features的标签表、direct的key/value表不参与预测，
有效参数和计算量不同，不能称严格等容量/算力对照。案例库随折重建，作为
非持久buffer不存进权重；复现依赖冻结训练输入、顺序及源码哈希。

## 训练和核验

RMSprop alpha.99，全模块lr1e-4；主干wd0，重构和检索分支wd1e-4，
zero_grad(set_to_none=True)，因此停用参数不因零梯度weight decay变化。
原重构权重10，前50轮爬升、半节点私有采样seed20261006+fold；无额外标签辅助BCE。
最多800轮、至少300轮、耐心200，最早最大内部(AUC+AP)/2检查点。

拟合前核验零残差恢复原模型、正负自身标签翻转不变、物理删除案例一致、
query子集预测一致、独立NumPy距离/值聚合、真实更新有限梯度及完整M1/M2/M3物理删边。
正式结果需重放并检查选轮、损失、案例边界和预测批次不变；PLMF保护性核对哈希。
