# 独立连续边方向学习 v1：性能前适配声明

## 来源与选择

Pahng 与 Hormoz，*Improving Graph Neural Networks by Learning Continuous Edge Directions*，[arXiv:2410.14109v1](https://arxiv.org/abs/2410.14109v1)，2024-10-18，预印本。已取得30页公开全文，核读第1–5节相关方法、式(1)–(4)以及附录实验设置；没有把2024工作描述成2026新发表论文。作者仓库为 [hormoz-lab/coed-gnn](https://github.com/hormoz-lab/coed-gnn)，固定提交 `5e88be92c22754f022add14ba3b8c5a5e22603c5`。核读 `src/model.py`、`src/utils/fuzzy_laplacian.py`、参数定义、合成图集合训练和节点分类入口，Git blob 按固定 tree 校验。没有使用作者预训练权重。

检索还确认 MAP/MAP++（WWW2025，DOI [10.1145/3696410.3714939](https://doi.org/10.1145/3696410.3714939)），并读取作者固定提交的主要算子与模型；ACM全文请求403，尚未取得全文。它依赖已有方向构造磁相位。本项目缓存的同类型边采用去重存储，端点先后不能作为观测方向；因此没有将其直接当成有向生物图来运行MAP++。OpenAlex与Crossref对MAP第四作者名存在差异，正式书目信息优先出版社登记。检索不是穷尽式新颖性证明，下载／阅读也不算性能验证。

本候选假设：从中性的无向支持关系开始，将每个物理事实的方向作为独立、与节点特征无关的参数学习，并保留流入／流出消息的分离，是否比固定中性传播和同维度的可学习对称边权更能补充MiDrug强参考。不同于此前SO(2)特征传输，它不旋转特征向量，也不从当前端点表示计算正交运输映射。它仍属于学习图传播结构的研究范围，不能把相近变体或控制臂分别算成多项创新。

## 作者论文和代码之间的差异

论文式(1)–(3)使用 cos(theta)、sin(theta)，并从复数 fuzzy Laplacian 讨论理论表达能力。固定作者代码实际先取复指数的实部／虚部，再平方，使用 **cos²(theta)、sin²(theta)** 来构造传播质量和度数。本地跟随发布代码的平方质量，不混称为论文式(1)的逐字实现，不直接沿用其表达能力定理。论文的图集合数据拥有同一结构下多组特征与目标；本项目是单个异构关联图、训练折图不同，不能声称重现那一应用设置或恢复真实生物调控方向。

作者合成实验入口对theta使用独立学习率、无权重衰减，并在每步更新后投影到[0, pi/2]。本地保留这三点。作者入口还报告7次重复中的最佳5个测试误差；本地没有采用这种选择，严格保留全部登记初始化与既有分阶段门槛。

## 明确的算子与对照

每条物理事实e只保存一个参数theta_e，初始为pi/4，跨三层共享。输入端点s、t只用于索引记账。令 `B[t,s]=cos²(theta_e)`、`B[s,t]=sin²(theta_e)`，有平行关系时逐事实相加；无自环。构造

```
D_in  = diag(B @ 1)
D_out = diag(B.T @ 1)
P_in  = D_in^(-1/2) @ B @ D_out^(-1/2)
P_out = P_in.T
```

保留作者度数加1e−12与小于1e−11置零的边界处理。无需建立复数张量即可准确实现其两路实数传播。交换某条边的存储端点，同时将theta替换为pi/2−theta，算子不变；中性初始化没有任何先验方向偏好。独立theta组权重衰减为0，避免将任意存储方向当作衰减目标。

三臂在性能评价前固定：

| 臂 | 传播质量 | 作用 |
|---|---|---|
| full | 正向cos²(theta)，反向sin²(theta) | 主候选：学习互补方向 |
| symmetric_weights | 双向都为cos²(theta) | 同数量可学习标量，对称亲和权重对照 |
| fixed_direction | theta固定为pi/4 | 无方向／边权学习对照 |

三臂的参数张量、初始化、输入、配对头、两路变换和训练预算相同。固定臂保留theta张量但它不进入梯度，记录其活跃方向参数为0；不能将存储参数数目等同于有效自由度。主方法必须在两个指标均胜过两个对照，才支持方向学习的收益。

原属性先逐行RMS归一，与同一masked支持图的log1p关系度数拼接，经节点类型专属投影得到64维输入。每层独立变换自特征、流入与流出聚合，组合为 `self + 0.5*(in + out)`，随后LayerNorm、ReLU和0.1 dropout。三层后，用两端表示、乘积与绝对差预测残差；末层零初始化。类型化属性／度数、LayerNorm、三层、配对头、AdamW主参数组、BCE参考残差与五图平均均为本地适配。theta仍独立于节点特征，没有替换成attention生成的方向。

## 隔离、拟合与判定

每个训练查询折的目标事实及逆向弧在度数和传播构造前删除。原始物理事实编号只用于对齐角度参数，删除的事实没有传播贡献或该步角度梯度。模型学习的是训练支持图上的传播偏好，不是新增实测关系。LncDrug预先为精确强参考恒等：不建图、不训练。

MiDrug损失为 `BCEWithLogits(nested OOF strong reference + residual)`；预测沿用强参考logit加0.1倍五张支持图的平均原始残差。强参考保留 `0.7*logit(tiered_reference)+0.3*mean(logit(HGB, ExtraTrees, MLP, LogisticRegression))`，经典成员使用冻结context76。此基础设施与融合权重不计创新。

主参数学习率仅0.001、0.003；theta组固定0.01、无衰减、每步投影。每模型400次更新，每20步检查；seed666筛选后按共同规则固定学习率，只有全部筛选门槛通过才追加seed0、1。历史确认通过后固定各臂检查点步数中位数，验证三个预定划分，再进入冻结outer重查。主方法MiDrug AUC/AP均值需同时正增益，每项至少2/3初始化或划分为正，且均值同时胜过两个机制对照；LncDrug单项损失不得超过0.001。任何阶段失败即停止该版本。

历史划分、追加划分和历史outer都有开发暴露；不能称独立队列或无偏最终测试。本候选不读取原始保留测试源。作者结果不能代替本项目验证，学到的方向不作生物因果解释。

## 性能前检查

五项检查覆盖：固定作者算子与梯度一致；独立稠密归一和有限差分；转置关系、端点换序与对称对照；相同初始化、非零读出换序分批、标签翻转隔离和删除边零梯度；训练专用入口、独立学习率、无方向衰减与投影边界。三臂真实图各五步探针、三条LncDrug恒等重放和40个任务／折边界检查均需先通过，才可冻结正式评价。详见 `CONTINUOUS_DIRECTION_UNIT_V1.json` 和 `CONTINUOUS_DIRECTION_SMOKE_V1.json`。

正式入口必须为 `anchor_direction_experiment_v1.py`，否则会丢失theta分组学习率和投影。该文件与核心、测试、来源、输入和协议一起冻结。这里未预先宣称任何性能收益。
