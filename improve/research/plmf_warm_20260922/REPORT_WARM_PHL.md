# PLMF-MDA warm 面提分：溯源超图启发式学习（PHL）— 前沿文献 + 诊断 + 单模型实测

目录：`improve/research/plmf_warm_20260922/`　日期：2026-09-22
约束（用户）：**不做冷药物**、**单模型**、目标是提高 PLMF-MDA warm 协议（论文 5 折 + 官方 80/20）的 **AUC / AUPR**，且要比"图上下文 + 扩散谱特征 + 线性读头"更有创新点。

---

## 0. 结论

1. **warm 面不是完全饱和，但剩余空间有明确的结构**（§1，新发现）：
   - 残差损失集中在"**warm 划分内部的稀疏 miRNA**"：训练图中度数 ≤1 的 miRNA 只占测试正例 20%，却贡献 33–35% 的 AUC 损失；度数 ≤3 占 40%、贡献 55%。把它们排对的 oracle 上限是 AUC 0.967/0.970（≤1）、0.978/0.980（≤3）。
   - 采样负例里约 **2% 是别处已记录的正例**（MDS↔MDR 互查、ncRNADrug），它们吃掉 12–14% 的负例侧损失。这是基准的标签噪声天花板：去掉后基线 AUC 0.957/0.959。
   - 因此"再换架构"没有空间（本轮再次证实：排序损失、AP 损失、负例清洗、门控交互、HGB/MLP 读头都 ≤ 0），**但"给稀疏 miRNA 补信息"有空间**。

2. **提出并实测单模型 PHL（Provenance-Hypergraph Heuristic Learner）**（§3）：
   把数据库的**策展溯源**（每条关联来自哪篇 PMID、在什么细胞系/表型/疾病语境下报道）建成**研究超边 / 语境超边**，
   把 miRNA 的**标签无关旁信息**（名称家族、seed 家族、HMDD 疾病谱、另一表型的度数、PubMed 文献热度）建成 miRNA 侧关系，
   在这张多关系超图上计算可解释的路径/桥接启发式，与原 ctx+diff 一起进入一个线性读头（一个模型，~130 个参数，交叉拟合、无泄漏）。

3. **结果**（内折 K=10 交叉拟合；多种子配对比较，全部种子为正，打乱对照归零）：

   | 协议 | 数据集 | 基线 ctx+diff×LR | **PHL** | Δ AUC / Δ AUPR | 打乱对照 Δ | PLMF-MDA 官方复现 |
   |---|---|---|---|---|---|---|
   | 论文 5 折（4 seeds） | MDR | 0.9529 / 0.9494 | **0.9591 / 0.9565** | +0.0062±0.0003 / +0.0071±0.0005（4/4） | +0.0007 / +0.0006 | 0.9243 / 0.9146 |
   | 论文 5 折（4 seeds） | MDS | 0.9560 / 0.9536 | **0.9607 / 0.9587** | +0.0047±0.0002 / +0.0051±0.0007（4/4） | +0.0011 / +0.0012 | 0.9270 / 0.9175 |
   | 官方 80/20（5 seeds） | MDR | 0.9544 / 0.9509 | **0.9602 / 0.9572** | +0.0058±0.0018 / +0.0063±0.0026（5/5） | +0.0002 / +0.0001 | 0.9287 / 0.9162 |
   | 官方 80/20（5 seeds） | MDS | 0.9561 / 0.9523 | **0.9614 / 0.9584** | +0.0053±0.0009 / +0.0061±0.0020（5/5） | +0.0010 / +0.0004 | 0.9294 / 0.9189 |

   论文口径 seed 42：MDR **0.9578 / 0.9540**（原最强 0.9510 / 0.9455），MDS **0.9595 / 0.9577**（原 0.9540 / 0.9516）。
   去噪评估（剔除"已记录为正例"的负例）：PHL MDR 0.9649 / 0.9650，MDS 0.9654 / 0.9656。
   对 PLMF-MDA 的领先：**+0.033~0.035 AUC / +0.040~0.042 AUPR**；对 MPHGNN（无泄漏口径 0.9205/0.9092、0.9246/0.9168）约 +0.036~0.040。

4. **创新点核查**（§2.3）：arXiv / Europe PMC 检索没有任何工作把"策展溯源（PMID / 实验语境）"当作超边用于关联预测；2026 年 ncRNA–药物论文用的超图全是 kNN 构造的（HDBI、HMHLVI、HGNNLDA）。
   "warm 基准的误差集中在稀疏实体"在通用链路预测里有平行工作（2306.00899、2310.04612、2407.20499），但 MDA 领域没人量化过，也没人给出去噪负例评估。

5. **研究分组划分下的表现**（§4.6，已实测）：把同一 PMID 的关联放进同一折后，基线从 0.953 掉到 0.915（MDR）/ 0.924（MDS），说明论文随机划分重度"同研究内"；PHL 在该划分下仍 **+0.008~0.009 AUC / +0.006 AUPR**（打乱对照 +0.001~0.003），其中溯源超边的增益缩到 +0.003、AUPR 中性，而 miRNA 旁信息的增益放大到 +0.007~0.010。
6. **边界要写清**：随机划分上的提升是 +0.005~0.007（约 1/8 的剩余误差），不是 0.97+；溯源桥接利用"同一研究报道多对关联"的传递性，要连同 §4.6 一起报告；HMDD/溯源/跨表型度属于外部知识，方法应定位为 knowledge-enhanced，并给 prov-only / mprior-only / 去 xdeg 消融（都已在 §4.1）。

## 1. 诊断：warm 面的残差在哪里

代码：`warm_scores.py`（复现基线并存每对得分）、`error_analysis.py`、`hidden_pos_audit.py`；日志 `logs/error_analysis.log`。
损失分解：对每个测试正例，loss = 排在它前面的负例比例（均值 = 1 − AUC）。

### 1.1 按 miRNA 在训练支持图中的度数分桶（seed 42，5 折）

| miRNA 支持度 | MDR 正例占比 | MDR 损失占比 | MDR 单例均损 | MDS 正例占比 | MDS 损失占比 | MDS 单例均损 |
|---|---|---|---|---|---|---|
| 0 | 10.0% | 13.4% | 0.066 | 10.7% | 12.3% | 0.053 |
| 1 | 10.4% | 19.6% | 0.092 | 11.5% | 22.3% | 0.090 |
| 2–3 | 19.9% | 22.5% | 0.055 | 17.7% | 22.3% | 0.058 |
| 4–7 | 29.2% | 26.6% | 0.045 | 28.9% | 25.6% | 0.041 |
| 8–15 | 26.8% | 15.8% | 0.029 | 28.1% | 16.1% | 0.026 |

药物侧 95% 的正例落在度数 16+ 的药物上，不是瓶颈。

这解释了为什么"注意力/元路径/对比学习"全部无效：它们都不给零度 miRNA 带来新信息。

## 3. 方法：PHL（Provenance-Hypergraph Heuristic Learner）

单模型：`score(m,d) = w·z(h(m,d)) + b`，`h` 是在"支持图 + 溯源超图 + miRNA 旁信息关系"上确定性计算的启发式向量，`z` = signed log1p + 标准化，`(w,b)` 为逻辑回归（C=0.3）。训练行用 K=10 内折交叉拟合（query 对绝不在自己的 support 中），测试行用全部训练正例作 support。代码：`final.py`（入口）、`prov.py`、`mprior.py`，基础 ctx+diff 复用 `../plmf_innov_20260921/bank.py`。

**关系与启发式（128 列）**

| 组 | 关系/超边 | 列（均只用 support 正例） |
|---|---|---|
| ctx (33) + diff (52) | miRNA–drug 支持图，kNN 内容图 | 度、共邻、path3/5、SVD16、属性支撑、PPR/Katz/path7 及其行/列归一化（原 iNcRD-HG） |
| prov·pmid (6) | **研究超边**：PMID → 它报道的 (miRNA, drug) 对 | 桥接数 `|P_m ∩ P_d|`（m 与 d 通过其它对被同一研究报道）、按研究规模加权、Jaccard、实体研究数 |
| prov·costudy (6) | 研究共现图 `S_r = M_r M_rᵀ`、`S_d = M_d M_dᵀ` | 共研究 miRNA 的 d 关联数 `(S_r A)[m,d]`、共研究药物 `(A S_d)[m,d]` 及归一化 |
| prov·ctx (4) | **语境超边**：细胞系 / 表型 / 疾病 token | IDF 加权的 token 交集、余弦、实体 token 数 |
| prov·rec (8) | 记录统计 | 实体记录数、低通量比例、首末报道年份（相对 2000） |
| mprior·fam (5) / seed (5) | 名称家族（去 -3p/-5p、字母后缀）、seed 7-mer 家族 | 家族成员数、成员对 d 的关联数/均值/占比、家族总度 |
| mprior·hmdd (7) | HMDD v4 miRNA–疾病谱（茎名匹配覆盖 83–85%） | 疾病数、疾病桥 `Σ_dz H[m,dz]·(HᵀA)[dz,d]`、HMDD 相似 kNN 标签迁移、邻居流行度 |
| mprior·xdeg (2) | 另一表型矩阵 | miRNA 在另一表型中的度（流行度先验） |
| mprior·pub (3，可选) | PubMed esearch 计数 | miRNA 总文献数、药物反应语境数、癌症语境数（label-free） |

对照：`final_shuf` 把溯源记录在配对间置换、把 miRNA 旁信息在 miRNA 间置换（保留边缘分布）。

读数：
1. 随机划分 → 研究分组划分，**基线掉 0.03–0.04 AUC**：PLMF-MDA 的随机 5 折确实重度"同研究内"，这是所有现役 MDA 论文共享的乐观偏差，值得在论文里单列一节。
2. **溯源超边的增益随划分缩水**（AUC +0.003，AUPR 略负）——与预判一致，它主要利用同研究传递性；论文里要如实写。
3. **miRNA 旁信息的增益反而变大**（+0.007~0.009 AUC / +0.009~0.010 AUPR）：更难的划分让更多测试 miRNA 在训练图中变稀疏，正是先验补信息的场景。这使 PHL 在两种划分下都是全部为正、且都显著高于打乱对照。
4. 论文主张因此应写成两层：**旁信息关系（HMDD 疾病谱 / 家族 / 跨表型度）是划分无关的稳健增益；溯源超边是随机划分下的额外增益、研究分组下中性**。

## 5. 论文写法建议

**题目方向**：Curation provenance as structure: a provenance-hypergraph heuristic learner for miRNA–drug resistance/sensitivity association prediction（或中文：基于策展溯源超图的可解释 miRNA–药物关联预测）。

**贡献顺序**
1. 诊断（新）：warm 基准的误差集中在稀疏 miRNA 与隐藏正例（§1），给出度分层损失分解与去噪评估协议；引用 2306.00899 / 2310.04612 / 2407.20499 / 42439426 / 2405.14985 说明这是领域共性而非本文孤例。
2. 方法（新）：PHL——研究超边 + 语境超边 + miRNA 旁信息关系上的可解释启发式 + 线性读头；强调"线性 ≥ 深层"（LI-DTI, Bioinformatics 2026 有同样论证）、参数量、每列可解释、无泄漏交叉拟合。
3. 结果：两协议 × 两数据集 × 多种子全部为正，打乱对照归零，增益落在稀疏 miRNA；对 PLMF-MDA +0.033 AUC / +0.041 AUPR。

**必须如实写的风险**
- 溯源桥接依赖"同一研究报道多个关联"的传递性，随机划分天然奖励它；**study-grouped split 已做（§4.6）**：溯源增益缩到 +0.003 AUC，旁信息增益放大，整体 PHL 仍 +0.008~0.009 AUC。把这一节写成"评估协议贡献"，而不是藏起来。
- HMDD / 溯源 / 跨表型度是外部知识，PLMF-MDA 只用三类原始数据；对比时要说明信息量不同，并给 "仅 prov" / "仅 mprior" 消融。
- 提升 +0.005~0.007 约为剩余误差的 1/8；不要写成"大幅超越"，用配对多种子 + 打乱对照说服审稿人。
