# M123 配对表示的对抗／随机扰动

目标仍为原 MiDrug 测试三种子均值 AUC≥.9733929274、AP≥.9336833737，
且 PLMF 两个数据集不下降。只加载原 miRNA/drug 白名单图、原训练内部三折。
没有 lncRNA、外部数据、序列、注释或新权重。

上一轮标准 SAM 降低了固定参数半径下一步训练损失敏感性，但未产生足够的
双指标内部收益。本轮检验不同位置的扰动：M1/M2/M3 各通道拼接后的配对表示 H，
位于 lin1 之前；该表示仍由当前查询精确删边的原流程产生。保留原全部模型参数、
初始化、M1/M2/M3 和推理前向，不增加推理分支。读取临时 lin1 前向hook捕获H，
立即移除hook；扰动只经过原 lin1→LeakyReLU→lin2→LeakyReLU→lin3。

这是监督训练正则项，不把扰动表示或其标签当作新增观测关联。不宣称复现 E2A；
E2A 的条件VAE／能量引导方法及适用范围已在上一轮文献记录中核读。
历史 stochastic_augmentation_graph_v1.py 已有扩散式表示增强，但使用另一图输入、
主干、排序与对比损失。本次仅做源码比对，没有执行其数据加载器或导入其节点。

对每个训练配对 i，g_i=∂BCE/∂H_i。仅用当次原训练配对的未扰动表示计算
s_j=max(std_train(H_j,unbiased=False),.001)，其值停止梯度。
在约束 ||delta_i/s||₂≤rho*sqrt(dim(H)) 下，线性化损失的最优上升方向为
delta_i=s * rho*sqrt(dim(H)) * (s*g_i)/||s*g_i||₂。
rho固定.05，即标准化空间中的RMS半径.05。除尺度下限外，该度量对表示列的
正比例缩放与平移等变，减少不同通道单位对扰动方向的影响。

对照 random 使用同一尺度／半径、独立固定 RNG 的逐配对高斯方向。
若||s*g_i||₂≤1e-12，两种方法都不扰动该配对，避免不同有效样本支持。
方向与尺度都detach；原H保留梯度，因此扰动损失可更新编码器和融合头。
有限半径下只是一阶近似，不能称为精确非线性最坏扰动或生物学保真增强。

关联损失为 (1-alpha)*BCE_clean + alpha*BCE_perturbed。
前30轮alpha=0，随后30轮线性增至.5；保持两项权重和为1。
重建仍是原始特征重建，权重0/10、前50轮爬升，采样节点RNG与旧对照一致。
每轮只运行一次原M123前向／BN统计；扰动后的融合头不含BN。
优化器为RMSprop lr1e-4/alpha.99，主干wd0、重建wd1e-4。

冻结四配置 adv、random、adv_rec10、random_rec10 × 三内部折，seed42，12次拟合。
最多800轮、至少300轮、patience200，按内部(AUC+AP)/2选轮。
仅adv/adv_rec10可以推进：各自须同时超过纯M123、unmasked10、匹配random和上一轮
匹配参数SAM，在每个对照的三折平均AUC/AP上均至少+.002。
不追加半径/权重搜索，不依据原验证或测试选择配置。

验证包括float64线性分类器闭式椭球最优解、独立逐样本NumPy公式、固定扰动后
非线性网络的有限差分、尺度等变与零梯度处理、零半径／零权重退化回普通BCE、
实际模型融合头等价性、训练参数不被扰动原地改写、BN计数一次、显式查询删图、
留出标签翻转不变。训练后重放新检查点及指标／选轮／损失／半径／方向，
并移除训练正则项和重建解码器确认原M123推理等价。

旧对照复用已经重放的原检查点及原始概率，当前重新核对源码、权重、数据、
配对标签索引和概率指标哈希；复用核验不计为新的GPU检查点重放。
