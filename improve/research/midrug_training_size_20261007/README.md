# 固定原训练内部留出集的训练量诊断

目标仍是原 MiDrug 测试三种子均值 AUC≥.9733929274、AP≥.9336833737，PLMF 两集不降。
本轮不是新的模型候选筛选，不放宽旧实验门槛，不把内部学习曲线当作最终验收。
只用原 miRNA/drug 图、属性及原训练标签；无 lncRNA、额外数据/注释/权重。

前轮多成员融合头没有超过原重建对照，故先检查较稳定的重建增益与训练量的关系。
每个原内部折有约 6474 条拟合配对，其内部留出配对固定。用 NumPy default_rng
seed20261007+fold 分别排列该折训练零/一标签的本地索引，每类取前 floor(n*.5)
或 floor(n*.75)，再按原本地索引排序。两个子集嵌套；100% 是既有完整内部训练集。
原三个内部留出集和原外层划分均不变。未选中的训练配对不进监督或关联图，
也不被改成负例。subsets.npz 和 subset_manifest.json 在训练前冻结。

原全部 miRNA/drug 属性和同类图保留；各训练子集独立重建关联图、M2/M3、EASE
以及配对特征标准化。纯 M123 与 unmasked10 共用完全相同索引和主干初始化。
原推理模型不改变。重建只用原属性与该子集图，其权重 10 在前 50 轮线性爬升。

两个新训练量×两个固定模型×三折，共 12 次新拟合。六个100%检查点使用既有结果，
再次重放以计算训练/留出指标；因此共有18个本轮检查点重放，只有12次新拟合。
学习率/选轮与100%来源相同：主干 RMSprop lr1e-4/wd0/alpha.99，重建lr1e-4/wd1e-4，
max800/min300/patience200，内部(AUC+AP)/2选轮，seed42。
重建节点采样独立生成器 seed20261006+fold，采样比例 .5，不遮蔽原输入。

先验证嵌套及留出互斥、原顺序、支持图严格只含子集正例、原主干初始化相同、
有限共享编码器梯度、BN一次，以及正例度一变零和负例的完整物理删除。
每个训练量覆盖三折的图构造，两个模型均检查不依赖内部留出标签。
重放时核对保存概率、选轮和损失组成，删除重建模块后预测应等价。

诊断预先限定为固定留出集上的 AUC/AP、相邻训练量变化、重建减纯M123的差值，
以及使用精确查询删除预测计算的训练/留出指标差距；完整逐折结果全部报告。
不能把这些重叠子集/初始化当成独立数据重复，不拟合三个点的外推性能保证。
100%约6474条，仍小于全部9712条原训练配对。没有原验证/测试评估或自动晋级。
PLMF 十个检查点、冻结图/划分及发布代码继续保持哈希保护。
