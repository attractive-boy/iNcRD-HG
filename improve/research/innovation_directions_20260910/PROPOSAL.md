# 下一轮创新方向：集合去噪、链路 PFN 与证据事实生成

> **2026-09-11 验证更新：** 第 1 条的轻量原型与四组消融已完成，当前实现未通过预设性能与机制筛选：LncDrug 选择原样回退，MiDrug 宏 AP 略降，两个任务均未显示去噪优于无去噪集合模型。56 个精排作业、24 个初始模型的检查点重放及特征核验已再次通过。详见 [实验报告](../../results/set_denoising_20260911/REPORT.md)、[实现与实验设计](../../SET_DENOISING.md) 和 [复核记录](../../results/set_denoising_20260911/recheck_20260911/RECHECK.md)。以下保留 2026-09-10 的方案依据；该负结果限于当前原型，尚无分组或外部泛化验证，暂缓扩大预算。

2026-09-10。**优先做药物条件的多正例集合去噪；把“缺失机制感知的异构链路 PFN”作为方法开发空间更大、成本更高的第二主线。** 如果愿意扩展研究问题，第三条是把已有的上下文方向研究推进到记录级的超关系事实生成。

这三项是研究候选，尚未实现或证明涨点。“开发空间更大”是结合本项目的判断，不是新颖性认证。本轮完成公开文献检索、选中论文的方法核对和训练数据可行性检查，没有启动新训练或读取测试集。

## 为什么选择这些方向

最近完成的架构实验中，TabM 的 LncDrug 全局 AP 从 0.943892 升至 0.966260，但按药物宏 AP 从 0.892087 降至 0.825590，分别变化 **+2.24 和 −6.65 个百分点**。宏 AP 只覆盖验证集中同时有正、负标签的 31 种药物。这个差异提示局部排序值得单独优化，不能据此直接断言全部增益来自药物频率。详见 [既有实验报告](../../results/backbone_comparison_20260910/REPORT.md)。

本轮只读取当前外层训练部分的 `pairs_train`、`y_train`，得到：

| 训练数据情况 | LncDrug | MiDrug |
|---|---:|---:|
| 正关联数 | 1,266 | 3,236 |
| 药物总数 | 216 | 216 |
| 没有当前任务训练正关联的药物 | 161 | 50 |
| 仅有一条训练正关联的药物 | 25 | 78 |
| 至少两条训练正关联的药物 | 30 | 88 |
| 前五种药物占训练正关联的比例 | 78.99% | 31.33% |
| 单药物全部 RNA 候选数 | 1,322 | 605 |

因此，模型必须跨药物共享参数，并处理零例和单例支持。没有当前任务的正边不等于严格冷启动：图中可能还有该药物的另一类 RNA 关联。计数和输入哈希见 [feasibility.json](feasibility.json)。

已有实验覆盖了普通注意力、双流与成对传播、四配对交换、案例检索与岭回归适配、表达可靠性、癌种多实例聚合、可靠负例筛选和 RNA-FM 特征。这些不能重新命名后当作本轮新增创新。新文献也已有同任务的高阶解耦超图 HDBI 和预训练序列/药物特征融合 MIFNDRA，见文末来源表。

## 1. 药物条件的多正例集合去噪排序

**最适合先做小原型，目标是改善同一药物下的 RNA 筛选。**

**近期依据。** [RADD](https://arxiv.org/abs/2604.25693) 于 2026-04-28 首次发布，2026-07-20 更新。它用全实体检索提供候选，再用离散去噪模型排序。全文明确：去噪目标是一个实体身份，输出仍覆盖整个固定实体词表；推理从 `[MASK]` 出发只前向一次，最终用 top-K 硬筛选。不能把它描述成已经实现多正例集合联合生成或多步推理。[KREPE](https://arxiv.org/abs/2605.24064)，2026-05-22，则支持多个事实成分的联合掩码恢复。两篇均按已核对的预印本版本引用。

**项目中的具体改法。**

1. 将一个药物的多个候选 RNA 一起送入共享模型。每个候选 token 包含 RNA 属性、当前可用支持图生成的配对特征，以及可选的 TabM 初始分数；药物作为条件输入。模型对候选排列等变，避免用候选位置记答案。
2. 将已知关联集合的一部分遮蔽，学习根据剩余支持和候选之间的关系恢复关联指示。去噪对象是关联集合，而不是仅给 embedding 加高斯噪声。每个候选输出独立 logit，允许同一药物有多个正例。
3. 共享全部药物的参数，训练时覆盖空支持、单例支持和多例支持。按药物组织训练采样，控制少数高频药物对目标的支配；这项采样调整本身不作为算法创新。
4. 原型优先保留完整候选集合。当前每个药物只有 605 或 1,322 个 RNA，不能未经召回检查就照搬 RADD 的硬 top-K。若后续需要缩小候选集，应先在内部数据确认召回上限，并保留名单外候选的评估。

**值得争取的贡献。** 检验“多个可能正确的候选能否在共享、药物条件化的去噪过程中相互补充证据”，以及动态候选表示是否能适配稀疏和新药物。RADD 的单实体恢复、KREPE 的事实成分恢复、普通集合模型和离散扩散都属于已有方法。具体的多正例关联集合设计仍需进一步查近邻工作，不能宣称首次。

**必须处理的标签问题。** 本项目的采样负标签来自未观测配对，不是实验确认的无关联。恢复观测集合只能直接学习已记录关联的分布，不能自动恢复真实生物学关联。如果采用 PU 风险或软标签，必须说明类别先验/标注机制假设，并将同样的目标用于无去噪对照。只重建正例又没有其他约束会出现全部预测为正的退化解；用自己的高分伪标签循环训练也不能充当验证。

训练查询正边及反向边必须从支持图删除，所有目标依赖的路径、SVD、属性统计和初始预测均按当前可用支持重算。用于训练精排器的初始模型分数必须来自折外模型，不能直接拿在该行标签上拟合过的分数制造虚假的精排收益。

**最小有效对照。**

| 对照 | 要分辨的机制 |
|---|---|
| 原 GNN 与当前 TabM | 是否超过现有真实强基线，特别是原 GNN 的单药物排序 |
| 相同特征的逐配对精排器 | 收益是否只是多加一个预测头 |
| 相同候选交互模型，无去噪训练 | 收益是否需要去噪，而不只是集合注意力 |
| 相同去噪模型，取消候选间交互 | 收益是否需要联合建模多个候选 |

各组使用相同训练信息、候选集合和调参预算。先比较按药物宏 AP 与 Top-K 排序，同时跟踪全局 AP/AUC；不能把局部排序变化直接解释为全局涨点。若使用条件 softmax，跨药物分数还需校准，不能直接当成可比较的关联概率。

这与已失败的支持案例岭回归不同：此前案例用于生成药物专属线性预测器；这里研究的是候选集合的联合恢复与排序。该区别只说明本项目中的新增设计，不保证更有效。

## 2. 缺失机制感知的异构链路 PFN

**方法开发空间较大，主要争取小样本与冷启动泛化，成本高于第一条。**

**近期依据。** [GraphPFN](https://arxiv.org/abs/2509.21489) 首发于 2025-09-25，最新核对版本为 2026-08-20 的 v4。它在合成图任务上预训练，再通过上下文中的少量标签预测新查询。其附录明确指出：**当前模型只支持节点任务，不能直接用于链路预测**，现有图先验主要面向社会与信息网络。

[Monroe](https://arxiv.org/abs/2608.18982)，2026-08-19，提供了分子表示与 PFN 下游预测结合的近期经验；它不是 ncRNA–drug 关联模型。[另一项 2026 年研究](https://arxiv.org/abs/2606.31126)也发现生物分子预测可从 PFN 受益，但小分子任务上不存在统一最优的预测器—表示组合。这些结果构成尝试动机，不是本任务的涨点证据。

**项目中的具体改法。**

1. 构建合成的 RNA–药物异构关联任务。先生成潜在完整关联及辅助关系，覆盖不同社区结构、度数、跨 RNA 支持关系和属性—结构耦合强度。训练任务须有足够多样性，不能只制造容易被单一度数规则解决的图。
2. 再模拟观测过程：热门药物更容易被研究、某些 RNA 或关系更少被记录、部分药物完全没有支持。合成数据中完整标签已知，因此可以训练模型从不完整观测预测被隐藏的关联。
3. 模型的上下文输入是带类型的关联支持与属性，查询输入是 RNA–drug 配对。替换节点标签入口与预测头，开发真正的链路任务预训练；直接安装 GraphPFN 或把它的名字放到现有编码器上不够。
4. 真实数据用于适配与内部选参；未见药物的预测依据其属性、可用辅助关系和支持，而不是训练好的药物 ID。相关生成参数只能由开发部分估计。

可用下面的简化观测过程组织合成任务：

\[
O_{rd}=Y^*_{rd}E_{rd},\qquad
E_{rd}\sim\operatorname{Bernoulli}(\pi(r,d,\text{source})).
\]

其中 `Y*` 是仿真中的完整关联，`E` 表示一条正关联是否被观测，`O` 是可见图。这是生成先验的假设，不是从现有数据已识别出的生物学真相；它初步假定观测正例可靠，后续还需检查假阳性敏感性。

**值得争取的贡献。** 将异构链路结构和非均匀缺失过程共同纳入预训练，让模型在零/少量支持下仍能推断配对，而不是仅拟合已记录边的频率。图 PFN、合成任务预训练、上下文链路预测、PU 学习都已有先例；例如 [UniLP](https://arxiv.org/abs/2402.07738) 已在 2024 年研究跨图的上下文链路预测。可能的增量在任务先验、链路信息流和缺失机制迁移的组合及其证据。

**成本与可行边界。** GraphPFN 原文使用 160 万个合成任务、8 张 A100 80GB 训练约 36 小时，而且主要更新图适配层。当前两张 A40 不适合直接照搬该预训练预算。合理原型是冻结可复用的预训练部分，训练小型链路适配器，或训练紧凑模型并先观察任务量—性能曲线。还需单独核对代码、权重许可、依赖和显存，当前尚未下载或实测该模型。

**决定性验证。** 使用同一架构、相同任务量与计算预算，比较普通随机先验、异构结构先验、异构结构加缺失过程先验；同时保留同配对特征的普通 PFN/TabM。必须检查模型是否只对自己的合成分布有效，以及缺失率、热门药物分布和结构改变后是否仍能迁移。

真实评估需要新药物/新 RNA 划分。严格新药物协议应同步屏蔽该药物在 LncDrug、MiDrug 等关联关系中的泄漏通道；仅删掉一个任务的边不能证明全冷启动。合成监督不能消除真实观测过程的不可识别性，输出概率仍需独立校准与敏感性检查。

## 3. 来源约束的超关系事实生成

**适合扩展生物学研究问题，数据整理成本最高，不是最快的原指标提分路线。**

**近期依据。** [KREPE](https://arxiv.org/abs/2605.24064)，2026-05-22，将任务扩展为从任意缺失的事实成分恢复完整超关系事实。它处理的是 Wikidata 类数据，不是经过实验验证的耐药机制。

本项目已有上下文方向反转的研究提案和癌种多实例实验。因此，“加上下文”不是新问题；这条路线的新增候选是**保留原始实验记录，并对多个缺失成分进行联合建模**。

将一条记录组织为 `RNA、drug、细胞状态、实验类型、Effect、剂量/时间（若真实记录）`，将 PMID 作为证据来源与分组依据。根据已知成分预测缺失条件或方向，并区分实际记录和模型假设。来源 ID 不应成为在新论文上无法使用的记忆捷径，也不生成虚构 PMID。

可争取的技术贡献是：在事实生成中加入证据类型对应的观测约束，使表达差异记录、RNA 干预后的药物响应和机制救援记录承担不同监督作用。缺少功能实验的记录不能自动变成干预方向标签；生成的条件组合也不能作为新增真实标签回填数据。

与直接迁移 KREPE 相比，是否真正需要证据类型和来源建模，要用同输入的普通记录模型、已有上下文模型、KREPE 直接适配和去掉证据约束的版本检验。主要评估按 PMID/实验记录分组留出、同配对跨状态方向变化及冲突时的预测可靠性，而非仅看混合配对 AUC。

现有候选证据尚不足以支持干预因果结论；来源与状态严重混杂时，两者也不能靠两个网络头自动分开。此前发现部分方向反转候选实际上来自耐药株与亲本的表达芯片比较，原始记录复核是这条路线的必要前置工作。详见 [既有证据审计与干预提案](../intervention_design_20260909/ASSESSMENT.md)。

## 建议的下一步

先围绕第一条建立一个共享、小规模的集合去噪原型，并把无去噪、无候选交互对照一起固定。主要判断它能否补回 LncDrug 的药物内排序，同时保住全局指标。只有机制对照成立，再扩大预算。

第二条适合作为独立的方法研发线：先验证合成先验能否迁移，再投入大规模预训练。第三条应先完成原始实验记录整理；不能靠新的生成架构补齐缺失的功能证据。

既有验证集已经反复用于开发。新增随机种子不能提供独立泛化证据，重新切分同一批已查看数据也不能当作全新的外部验证。应在开发部分安排新分组划分，并为正式结论预留未参与方案选择的研究来源、时间批次或外部数据。
