## 0. 结论

**1）新模块：经验贝叶斯实体随机截距头（EB head，`--ebpost 10`）。** 网络训练完、按 valsel 选定 epoch 后，把网络 logit 当作固定偏移，在训练 + 验证对上用岭化 logistic 拟合每个 miRNA 和每个药物的一个截距，加到测试 logit 上。λ = 10 是事先定的默认值（λ 敏感性见 §3.4）。

主口径（valsel，同折配对，`make_tables.py 10` → `tables_main_lam10.md`）：

| 评测面 | 折数 | F AUC / AUPR | **F + EB** AUC / AUPR | Δ AUC / AUPR | 胜折 AUC / AUPR |
|---|---|---|---|---|---|
| MDR 5cv × seeds 42–44 | 15 | 0.9554 / 0.9529 | **0.9560 / 0.9534** | +0.0006 / +0.0004 | 15 / 13 |
| MDR 80/20 × seeds 0–4 | 5 | 0.9565 / 0.9541 | **0.9572 / 0.9547** | +0.0006 / +0.0006 | 5 / 5 |
| MDS 5cv × seeds 42–44 | 15 | 0.9569 / 0.9555 | **0.9575 / 0.9561** | +0.0006 / +0.0006 | 14 / 11 |
| MDS 80/20 × seeds 0–4 | 5 | 0.9592 / 0.9576 | **0.9595 / 0.9578** | +0.0003 / +0.0002 | 4 / 4 |

官方协议（100% 训练对、无留出；EB 在全部训练对上拟合；`OFF_FE10`）：

| 评测面 | F 测试最优 → +EB | F 最后 epoch → +EB |
|---|---|---|
| MDR 5cv seed 42 | 0.9551/0.9530 → **0.9557/0.9535**（5·5/5） | 0.9540/0.9517 → **0.9553/0.9529**（5·5/5） |
| MDR 80/20 × 0–2 | 0.9565/0.9545 → **0.9570/0.9547**（3·2/3） | 0.9559/0.9537 → **0.9565/0.9541**（3·3/3） |
| MDS 5cv seed 42 | 0.9582/0.9577 → **0.9587/0.9582**（4·4/5） | 0.9573/0.9569 → **0.9580/0.9575**（5·3/5） |
| MDS 80/20 × 0–2 | 0.9605/0.9587 → 0.9606/0.9587（2·2/3） | 0.9601/0.9581 → 0.9602/0.9583（2·2/3） |

**2）它为什么是"新方向"，以及它为什么只能这么小：** 本轮先做诊断（§1）。F 的 logit 对它自己的全部输入已经是充分统计量：在 F 的输入通道上再训练任何叠加器（LR / 梯度提升树）都会变差；隐空间 kNN、沿 kNN/家族关系传播残差、低秩残差矩阵分解、每个药物的低秩专属头、度数斜率、药物 × 家族/seed/臂交叉效应、行/列配额、整矩阵 SVD 平滑，全部 ≤ 0。**唯一剩下的结构是实体身份本身：每个 miRNA、每个药物一个标量截距。** 这与前十二轮尝试过的配对通道、编码器、解码器、负例/损失设计都不同：那些都改"特征 → 分数"的函数，EB 头改的是函数无法表达的实体级偏移。最接近的旧尝试是 R11 的 ID 嵌入（每个节点一个可学习向量，拼在编码器输入上，fold 0 上 MDR +0.0007、MDS ≈0，未保留）；本轮在同一模型里把实体参数做成端到端可学习的截距也只有 +0.0003（MDR），有效的是"网络先收敛、再在标注对上按经验贝叶斯拟合截距"的后置随机效应头（§3.5）。

**3）EB 头与底座无关，也不来自负采样泄漏：**
- 在 10 个不同底座上（R8 base、VG、F、严格池 F、F+dropout 等，seed 42），EB 都是 +0.0005 ~ +0.0015 AUC、+0.0004 ~ +0.0012 AUPR，大多 5/5 折（§3.2）。
- 把拟合截距用的负例换成"不知道任何正例/测试身份"的均匀单元格，增益不变（§3.3）。
- 在非空心的 plain iNcRD-HG 上，EB 的增益不稳定（MDS AUPR ±0，胜折 3/2）；空心模型的训练对 logit 是"不看自己的边"的，残差诚实，截距才估得准。

**4）审计：F 的 HN 有一小部分收益来自负例池文件的闭世界性质（§4）。** HN 的同药物候选取自官方负例池文件减去划分对，这个文件按定义不含任何正例（包括测试正例）。改为从"消息图外、训练/验证对外"的全部单元格抽（`--strict_pool`，不用负例池文件、不用测试身份），F 在 MDR 5cv×3 上 −0.0004/−0.0007，MDS −0.0001/−0.0003。严格池 F 加上 EB 后回到 F 的水平（MDR +0.0002/−0.0003，MDS +0.0004/+0.0003 对 F）。

**5）本轮其余 11 个训练/结构候选全部为负或零（§5）**，包括两类新的训练目标（跨对矩形对比、解耦辅助头）和三种负例采样变体。

## 2. 方法：EB 头

对网络 logit f(m,d)（对查询边空心），在 valsel 选定的 epoch 上解

  (u, v) = argmin Σ_{(i,j) ∈ 训练+验证对} BCE(y_ij, f(i,j) + u_i + v_j) + λ (‖u‖² + ‖v‖²)

（L-BFGS，求和尺度的 BCE，λ = 10，`run_r13.py: ebias_post`）。测试打分 f(m,d) + u_m + v_d。

- **为什么用训练 + 验证对**：验证对只用来选 epoch；选定之后它们就是普通训练数据。只用训练对 +0.0006/+0.0005（seed 42），加上验证对 +0.0007/+0.0006；给验证对更高权重（κ = 2/4/8）没有帮助。
- **为什么是后置而不是端到端**：同样的截距放进网络一起训练都更弱或不稳定（§3.5）。后置时网络先把能从内容/结构泛化的实体倾向学进去，截距只收剩下的实体特异部分。
- **为什么依赖空心性**：训练对的 logit 不包含它自己的边，残差 y − σ(f) 对图通道是"留一"的；非空心 plain 模型上同一个头不稳定（§3.2）。
- 代价：每折一次 1.4k 参数的凸优化，< 1 s。

## 4. 审计：HN 负例池的闭世界性质

R11 的 HN 从 `D.neg_pool`（官方负例池文件 = 全部正例的补集）中去掉训练/验证/测试对后抽同药物/同度数分箱候选。因为 5cv 与 80/20 都把全部正例放进了划分，这个池子里**不可能出现测试正例**；而一个不知道测试身份的采样器（从消息图外、训练/验证对外的全部单元格抽）对热门药物会有约 15% 的候选是测试正例（例如顺铂未观测单元格 ~825 个中 ~124 个是测试正例）。

| 对照（valsel） | MDR 5cv×3 | MDS 5cv×3 | MDR 80/20×3 | MDS 80/20×3 |
|---|---|---|---|---|
| F（默认池） | 0.9554 / 0.9529 | 0.9569 / 0.9555 | 0.9556 / 0.9535 | 0.9602 / 0.9585 |
| F，严格池（`--strict_pool`） | 0.9551 / 0.9522（−0.0004/−0.0007） | 0.9568 / 0.9552（−0.0001/−0.0003） | 0.9555 / 0.9530 | 0.9600 / 0.9584 |

seed 42 上拆开：只有 UNL 时严格池 = 默认池（0.9540 两者相同）；差异全部来自 HN。HN 在 MDR 上的收益约一半来自这个池子性质（默认池 HN +0.0010/+0.0013，严格池 +0.0005/+0.0005）。这不是使用了测试标签（排除的是全部评估对，正负对称），但它依赖"全部正例都在划分里"这一闭世界设定。建议论文同时报告严格池的数字。

| 参数平均 / SAM | Parameter Averaging in LP（2510.25361）、Graph SAM（2602.08855） | EMA 0 |
| 跨对排序 | CPR（交叉成对排序，去曝光偏差） | 在本基准上为负（流行度本身是被奖励的信号） |
| 负采样与评测泄漏 | 生物医学 KGE 数据泄漏基准（2026-08，PMID 42623034）、实体平衡评测（42439426） | §4 的负例池审计 |

| 2026 miRNA/ncRNA–药物模型 | RGDAGMAE（42470826）、HDBI（42427293）、HMHLVI 等 | 仍是节点级编码器 + 融合，没有空心约束 |

## 7. 诚实边界

1. **量级小**：EB 头 +0.0003 ~ +0.0006 AUC、+0.0002 ~ +0.0006 AUPR（四个评测面全部为正，MDS 80/20 最小）。这是在 F 已经"特征充分"之后唯一找到的剩余结构，不是量级跃升。
2. λ = 10 是事先的默认值；seed 42 上调出的 λ = 3 在其他种子上不稳，表中只把它作为敏感性报告。
3. EB 头是后置的两阶段组件（网络 + 实体随机截距），不改变网络本身；端到端版本在 MDR 上不稳。
4. §4 说明 R11/R12 的 HN 在 MDR 上约一半收益依赖负例池的闭世界性质；严格池下 F+EB 的 MDR AUPR 仍比默认池 F 低 0.0003。
5. 本轮未引入任何外部信息；评估协议、负例、指标、选 epoch 规则都未改变。
