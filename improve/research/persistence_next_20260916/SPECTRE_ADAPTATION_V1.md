# SpectRe：查询局部图的事件对应谱

本候选检验学习过滤下的**事件对应连通分量谱**是否能补充 MiDrug 强参考。它属于持久同调与谱联合描述家族，不把普通图编码器、静态谱、参考融合或 LncDrug 恒等分支计为创新。仅在历史、三个固定开发分区及冻结 outer 的性能与机制门槛全部通过后计入成功。

## 来源与边界

- *Graph Persistence goes Spectral*，arXiv:2506.06571v3，2026-02-04。核读全文，尤其 Definition 2.3/3.1、图2、第5节和附录。
- 论文及作者仓库标注 NeurIPS2025；本次 OpenReview API 返回403，没有把出版者归属另作独立核验成功。
- 固定作者仓库 `Aalto-QuML/SpectRe`，commit `90ad637b00481a33318306d776882dce8e2012e8`。七个关键文件及 `unionfind.hh` 的 Git blob 与 SHA256 已校验，见两个 `SPECTRE_*SOURCE_V1.json`。
- 原样编译固定作者 `spectre_cpu.cpp` 和头文件，未修改作者算法源码；本地独立实现另存。没有下载或使用预训练权重，不声称复现其图分类实验。

## 本地适配

1. 每个支持折先删除整个查询折的目标事实，再生成逆边、类型度及图注意力输入。每个配对取两端点与它们的**全部一跳共同邻居**，保留诱导无向简单图的全部边。没有按节点编号截断，也没有节点数上限。这不是完整两跳图的近似谱；一跳/两跳选择来自训练专用资源探针。
2. 普通64维、两层、四头类型化图注意力提供节点表示。仅末层表示进入一组过滤器；节点和端点表示之和分别经 `64→16→1` MLP 与 sigmoid，变换到 `(1e-4, 1-1e-4)`。使用一组过滤、局部链路图、末层拓扑、LayerNorm及配对残差头，均是本地设计。
3. 所有顶点在0出生；按边过滤值构造子水平图。代表选择遵循较小 α 存活、α 同值时较大 γ 存活；完全同值时以本地编号选一个代表。完整相同边值块全部加入后，分别计算每个事件所在分量的谱。
4. 0维事件为 `(0, death, alpha, gamma, rho)`；1维事件为 `(1, birth, 0, 0, rho)`。未死亡及孤立点的无限值用1表示，严格大于任何有限边过滤值。每个连通分量最后存活的顶点使用该最终分量谱。无边图和孤立顶点保留，1维仅保留真实 cycle 事件。
5. ρ 包含当时无权重组合 Laplacian 的**全部非零特征值**。在 CPU FP64 精确 `eigvalsh` 求解，绝对值≤1e-10置零；检查有限性、半正定性、连通分量秩、谱迹、二阶矩及 Euler cycle rank。零值及补齐位在编码前后屏蔽。
6. 独立谱 DeepSet `1→16→16` 对每个 `log1p(lambda)` 编码后求和；固定可逆 log 变换用于控制数值尺度，没有选取部分特征值。两个事件 MLP `20→32→32` 分别编码0/1维，0维按节点平均、1维按 cycle 求和，然后经 LayerNorm 与32维 MLP接入配对头。输出层初始为0。
7. 离散配对和谱 detach；death、alpha、gamma 通过原始过滤值 gather 保留梯度。无权重谱在过滤排序不变的区域局部常数，因此其局部梯度为0。不为排序伪造连续导数，也不声称同值处存在唯一导数或将论文的全局表达能力结论直接移植到本地网络。

## 与作者实现的明确差异

- 作者原始0维张量顺序为 `[death, gamma, alpha, eigen...]`，其 Python 层重排并添加前导0；本地直接生成论文的顺序。作者 Python 层给1维也加前导0，本地遵循论文使用1；0/1维仍由独立编码器处理。
- 作者内部 Laplacian 求谱为FP32、阈值1e-5，本地为FP64、阈值1e-10。作者 Python 层跳过谱首位并屏蔽零，本地显式屏蔽全部零。
- 作者全局变量记录历史最大谱宽，本地每次调用独立决定补齐宽度，预测不依赖先前批次。
- 作者在同值边块内全局累计等待事件，以最后一个分量的谱回填它们。已运行五点反例：边 `(0,1),(1,2),(3,4)` 全部在0.2加入；三点路径死亡事件应得到 `{1,3}`，固定作者实现却返回二点分量的 `{2}`。本地结果与独立阈值图定义一致。该问题不同于论文 Appendix E 的 augmented Forman–Ricci 曲率修正。
- 作者有捕获异常后继续的逻辑，本地数值或边界异常立即失败。
- 为减少重复工作，每个 native 调用的每个工作线程最多缓存4096个**逐字节相同的完整 Laplacian**及其精确谱；不做近似图同构匹配、不共享跨调用状态、缓存满后正常求解。输出与关闭缓存逐位一致。未缓存源码、二进制和短测证据已单独保存。

## 预定三臂与训练

| 臂 | 事件使用的谱 |
|---|---|
| full（主模型） | 该事件时刻所在连通分量的完整谱 |
| no_spectrum | 谱全部置零，过滤器及所有网络模块保留 |
| final_spectrum | 每个事件改用该查询局部图最终的完整静态谱 |

三臂具有相同参数、初始化、随机流、过滤器和事件计算过程；全部调用相同 native 核心，不以跳过求谱给对照不同的随机过程。缓存命中数和实际谱分解次数可因学到的排序而不同，不声称各臂浮点操作量完全相同。

MiDrug 使用固定 nested OOF 强参考偏置的 BCE，优化残差；AdamW，权重衰减0.001，梯度范数上限5，每模型400次梯度与更新。学习率只用0.001/0.003，每20步按共同 AUC/AP 均值规则选检查点。先seed666筛选，通过才确认seed0/1，再按冻结规则进入三个追加分区及outer。推理为强参考加0.1倍五折平均原始残差；LncDrug 从登记起为严格零残差、零参数、零训练。

实现检查和短拟合使用训练字段，不读取评价标签或计算性能指标。训练配对的重放仅使用删除其整个折的支持图，避免在其他折暴露训练正边。正式评价使用原已暴露开发评价集；其结果、追加分区及历史outer均不得描述为独立测试。

## 已完成的性能前检查

`PERSISTENCE_UNIT_V2.json`：八项检查，包括24张随机/同值/空边图的独立阈值连通分量 oracle、固定作者源码在非并列值上的谱与梯度、同值多分量反例、重编号/边换序/分批补齐、有限差分、查询及反向边删除、标签隔离、三臂随机流及训练预算、缓存逐位等价。

`PERSISTENCE_SMOKE_V1.json` 保留未缓存的三次真实MiDrug五步资源探针和40项折边界审计。V2试图要求两次CUDA训练权重逐位相同，在一次五步拟合后失败，源码及日志保留。

`PERSISTENCE_SMOKE_V3.json` 完成三臂缓存版本五步拟合及一次同种子未缓存重复：未缓存自身重复的最大参数差异为1.30e-7，说明训练中的CUDA归约存在舍入扰动。缓存版本使用1e-6参数绝对容差作重复性检查，另在真实图的**同一组输入**上验证缓存与未缓存的事件及谱逐位相同。三个保存模型的查询换序/分批重放误差均为7.45e-9，峰值显存约0.349GiB；再次完成40项折边界审计。累计短拟合为8次（V1三次、失败V2一次、V3四次），正式拟合0。正式冻结须验证有效源码、Unit V2与Smoke V3的哈希一致。上述检查不算性能通过或最终创新成功。
