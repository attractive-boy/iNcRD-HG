# 原特征重建与同药物排序的组合

最终目标保持：固定 MiDrug 测试 seeds 42/43/44 均值 AUC ≥0.9733929274189016、
AP ≥0.933683373732677，同时保护 PLMF-MDA MDR/MDS。目标尚未达到。
仅加载独立冻结的 miRNA/drug 原特征和原训练集内部三折，不使用 lncRNA 或外部数据。

上一轮未遮蔽重建 weight=10 相对纯 M123 内部对照提高 AUC/AP 约 0.00111/0.00227，
同药物内部排序 AUC 从约 0.7387 到 0.7515。已有纯 miRNA BPR 方法也有历史增益，
本轮检验其与特征重建是否互补；不把原有 BPR 作为新技术。

## 固定配置

| 配置 | BPR 权重 | 重建权重 |
|---|---:|---:|
| bpr010 | 0.1 | 0 |
| bpr020 | 0.2 | 0 |
| rec3_bpr010 | 0.1 | 3 |
| rec10_bpr010 | 0.1 | 10 |
| rec10_bpr020 | 0.2 | 10 |

复用且重新重放的对照：三个纯 M123 BCE checkpoint，以及上轮的 unmasked3 和
unmasked10 各三个 checkpoint。所有对照都来自相同原训练内部折。
每个新配置训练三折，共 15 个新模型。

主干 M1/M2/M3 与预测头保持原实现。BPR 复用旧版已核验的 SameDrugRanking：
对每个有同药物训练负例的训练正例抽 8 个候选负例，取一个均匀负例和一个位于
当前分数中间四个名次的负例。仅使用原训练负标签，不声称其均为实测生物阴性。
BPR 在前 30 轮权重为 0，随后 30 轮线性升至指定值。
旧排序脚本的图/划分加载函数被禁用，本轮只调用其采样器和权重函数。

重建完全沿用上一轮的未遮蔽模式：每类节点随机选 50% 计算标准化原属性 MSE，
各类型等权；输入不遮蔽，不改写关联输入，前 50 轮权重线性上升。
它只约束共享编码器，推理不使用辅助解码器。
RMSprop lr=1e-4、alpha=0.99；辅助重建参数 weight_decay=1e-4，主干无 weight decay。
最多 800 轮、至少 300，最优后 200 轮无改善停止，按内部 `(AUC+AP)/2` 选轮。

组合按相对匹配 BPR-only 和 reconstruction-only 对照的四个平均增益的最小值选择。
同时报告纯 BCE 对照。只有相对每个对照的两指标均提升 ≥0.002 才考虑原验证确认。
这些是开发筛选规则，不替代最终原测试双指标 +0.02 的验收。

## 核验和复现

解释器 `/data1/licheng/miniconda3/envs/ncRNAdrug/bin/python`；环境变量
`OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2`。
按 `check.py` → `launch.py` → `audit.py` → `summarize.py` 顺序运行。
训练拒绝覆盖同名结果，输入和源码依赖的 SHA256 在 results/plan.json 中固定。
初始检查验证同药物训练负采样、增加正例分数使排序损失下降、联合损失梯度有限非零，
以及主干初始化与 M1/M2/M3/最终 logit 显式删边等价。
