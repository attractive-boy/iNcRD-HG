Read the main definitions, architecture and Appendix D. The group operation is P⊙Q=exp(log P+log Q), with orthogonal congruence restrictions. Since log(MPMᵀ)=M log(P) Mᵀ for orthogonal M, the stated coboundary and adjoint have exact symmetric-matrix linear forms in log coordinates. A fair later experiment must acknowledge this equivalence and compare appropriate matrix-valued controls; a change of coordinates cannot alone be treated as an independent mechanism gain.

The molecular construction requires directional coordinates or actual SPD-valued measurements. This project has neither molecular coordinates for every graph node nor node-wise covariance matrices with a shared physical interpretation. In addition, the described initial canonicalization uses a local frame whose first axis is the same normalized vector used in uuᵀ+epsilon*I. For a unit vector this yields diag(1+epsilon,epsilon,epsilon), losing its orientation; this is a concern about transferring that particular formula, not a claim that the complete author implementation was tested.
