PLMF MDR/MDS不下降；仅原miRNA/drug，不用外部数据、注释、序列或新权重。

## 三个配置，同一推理模型

原M123融合头和权重10的无掩码重构保持不变，不加入专家或其他新推理参数。
每个内部折只用原训练正负记录；不补采负例。根据训练查询删边后两端正支持度
的训练中位数固定四组（等于中位数计低）；与上一预检定义相同。

- all：当前训练的全部正负样本对。
- cross：只取正负样本属于不同支持度组的比较。
- within：只取正负样本属于相同组的比较。

排名项是所选比较集合的`mean(softplus(s_neg-s_pos))`，温度1；所有有效比较
逐块精确求和，不用随机排名负例或硬例选择。每种配置按自身比较数归一化。
cross和within的比较数加起来是all，按比较数加权的两种损失必须重构all。
组只用于训练排名比较，不进入推理或原验证/测试。零标签仍是抽样未观测状态，
不解释为实验确认的生物阴性。

损失为BCE + .1×排名项 + 10×重构；排名权重前30步为0，31–60线性升至.1，
重构权重前50步升至10。排名权重采用既有BPR的.1，不在本轮调参。
主干/重构RMSprop lr1e-4、alpha.99，主干wd0、重构wd1e-4，set_to_none=True。
seed42，辅助采样私有seed20261006+fold，保持原输入、图和原训练内部三折。
最多800、至少300更新，按内部(AUC+AP)/2选轮，200步无改善停，平分取较早。
三配置×三折，共9次新拟合。不会直接加载或继续上一轮专家模型。

唯一候选cross必须相对all、within、纯M123、原unmasked10的三折平均AUC/AP
每项都提高≥.002才能推进原验证。不能事后改选all/within；最终双+.02标准不变。
排名项无新推理参数，删除重构解码器保持原预测等价。

## 核验与诊断

独立NumPy枚举损失和显式梯度、float64 gradcheck、全/跨/内损失分解、平移不变性、
正负梯度方向、稀有组/无比较情况；真实数据分组与前轮预检一致，排名和重构
不额外更新BN，留出标签翻转不影响训练损失。完整查询物理删除和训练后checkpoint
重放照常执行。冻结选择后再检查训练排名项、梯度/错误变化，不按诊断重新选型。
