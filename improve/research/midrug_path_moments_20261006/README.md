# 同一条三边路径的两个中间节点：联合矩与协方差

仅原 miRNA/drug 特征和当次内部训练正例图；不使用 lncRNA 或外部数据。
当前方向来自对本地 M123 实现的检查，不声称复现某篇新论文或具有原创性。

## 与已有实验的区别

- 原 M2 和旧路径注意力分别池化 miRNA/药物中间节点。新分支显式汇总同一条
  `r—j—i—d` 路径上 i、j 的特征乘积。
- 旧 tensor/raw/latent 双线性分支主要在查询端点间计算交互，本轮处理中间节点对。
- 旧子图 GNN 曾做局部消息传播及均值/最大值汇聚；本轮直接计算完整三边路径分布
  的联合矩，不作 top-k 子图截断。不是说旧网络不可能间接学习配对信息。
- 固定中间状态的小例子里，连接配对交叉前后两侧边际均值相同，而联合矩异号；
  这只证明新摘要与独立均值摘要不同，不是对原整个网络表达能力的证明。

## 精确查询删除

令 `i != r, j != d`，路径权重 `P_q(i,j)=A[r,j]*A[i,j]*A[i,d]`。
两个端点排除后，查询边不可能出现在任何保留路径中。原输入为布尔训练正例图，
同类图对称；实现检查这一与原 M123 一致的条件。

原两层 M1 的端点第一层变化传播到中间节点后，线性投影状态可写为：

`phi_i(q) = phi_i + a_q + Sr[i,r]*b_q`，
`psi_j(q) = psi_j + c_q + Sd[j,d]*e_q`。

其中 a/b/c/e 为原 M1 的 W_dm/W_mm/W_md/W_dd 作用于激活变化后，再经过该侧
rank16 无偏线性投影。由于保留的 i 都邻接 d、j 都邻接 r，跨类型系数为 1。
这里使用真实删边后的中间状态，而非完整图状态直接池化。

以 P_q 归一化的三种对照为：

- independent：`E[phi] * E[psi]`；
- joint：`E[phi*psi]`；
- covariance：`E[phi*psi] - E[phi]*E[psi]`。

三者都乘相同的 `paths/(paths+1)` 可靠性系数，进入相同 LayerNorm/MLP 残差头。
零路径时整个残差严格为零，包括头部偏置。投影与头结构相同，最后输出层零初始化，
保留同一个原 M123 主干初始化。主干编码一次，供原头和新路径矩共同使用。

路径乘积先沿 miRNA 侧矩阵收缩，再沿药物侧汇总，避免四维 query×miRNA×drug×rank
张量。查询按 512 分块。协方差由两个较大的矩相减，采用 float64 累积，随后转回
原编码器 dtype；独立参考使用逐条路径枚举和中心化协方差公式。

## 初始检查与数值修正

初版 float32 累积在真实数据出现约 6.6e-4 的消减误差，未通过预设容差；没有放宽
容差。改为 float64 累积后重新核验。参考枚举的零路径返回 dtype 也已修正。
检查包括：12 个 float64 非零残差下的最终预测/参数梯度与显式删图对照；
六配置的原初始化一致、真实完整训练步/梯度/显存、正负查询的独立路径枚举和
M1/M2/M3 最终输出删边核验，以及非零分支下的留出标签翻转。

## 固定实验

三种矩 × 重建权重 0/10 × 原训练内部三折 = 18 次拟合，seed42。
RMSprop lr1e-4/alpha .99；主干 wd0，新分支/重建 wd1e-4；最多800轮，至少300轮，
patience200，以内部 (AUC+AP)/2 选轮。
所有配置须对纯 M123 和 unmasked10 两指标均平均 +.002；joint 还须超过对应
independent；covariance 还须同时超过对应 independent 和 joint。门槛均相同。
这是开发推进条件，最终目标仍是原测试三种子 AUC≥.9733929274、AP≥.9336833737，
PLMF 两数据集不下降。内部结果不能代替测试验收。
