# 两轮反馈的查询删除与计算复用

本文件补充冻结README的实现推导，不改变训练协议。

记原入边事件多重集为N(i)，每个事件包含源节点索引。各原相似关系和当折训练正关联
按原方向进入该集合；同端点的重复事件保留。缺少自环时仅补一个自环，以保证所有
目标softmax至少有一个有效项。查询q=(r,d)删除两个跨类型方向的全部对应事件，
得到N_q(i)。本数据正关联唯一；实现仍按端点掩码移除全部对应事件。

令S_i^l=(x_i^l,z_i^l)，单步更新是确定函数

    S_i^(l+1) = F(S_i^l, {S_j^l : j in N(i)}, type_i; theta).

F先按当前frame计算环境距离、归一化权重和传输消息，然后使用同组权重同时更新
节点状态与残差矩目标，最后更新frame坐标。full/diagonal/mean只改变矩目标的统计。
它们具有相同参数集合，但不需要具有相同训练轨迹或中间状态。

本地初始化S_i^0只依赖原属性、共享参数和固定单位frame，不依赖N(i)、节点度、
随机游走、当前查询集合或标签。因此，对查询删除前后的第一轮计算有：

    S_i^1(q) = S_i^1                   if i not in {r,d},
    S_i^1(q) = F(S_i^0, N_q(i))        if i in {r,d}.

接下来只需要两个查询端点的第二轮状态。对i=r，已删除的源d不在N_q(r)中；
对i=d同理。其余邻居j若等于i，所有自环事件必须使用S_i^1(q)；若j不等于i，
第一轮没有受查询删除影响，可以使用共享S_j^1。于是

    S_i^2(q) = F(S_i^1(q),
                  {S_i^1(q) on every self event,
                   S_j^1 on every remaining non-self event}, type_i; theta).

这等于在物理删除目标两方向后，对完整原图执行两轮更新再读取端点。
原图无查询弧时N_q=N，两个完整更新可以被所有这类查询共享。
图成员分派不使用传入的查询标签；例如移除监督负记录不会改变该分派或分支状态。

归一化权重、三角solve和残差矩均在正确的N_q上重新计算，没有从完整图上直接复用
查询端点的最终注意力或frame。显式删图参数梯度一致，是因为上述复用关系是每组
模型参数下都成立的计算恒等式；检查点重计算也必须使用相同参数和图。

这个结论不能推广为“任意反馈GNN都可以只修正两个端点”。第三轮时端点的邻居
第二轮状态也可能改变，必须继续传播影响；度/RW/结构atlas初值可使第一轮以前就
有更多节点改变。当前实现没有这些额外依赖，后续若加入必须重新推导和核验。

矩阵约定也需保持一致：代码frame为下三角L，环境长度度量为L^T L。残差矩C的
Cholesky因子满足R R^T=C+eta I；把R写入frame坐标后，frame度量通常为R^T R，
不能与C混为一谈。传输是solve(L_target, L_source * phi(x_source))，不显式求逆，
也没有把C的Cholesky解释成逆协方差白化。

实现证据：math_checks.json中的NumPy参考、有限差分和物理重建图的全部参数梯度；
initial_checks.json中的真实图训练、两个分块尺寸输出/梯度和M123整模型物理删边。
这些核验说明实现符合当前定义，不证明AUC/AP提升，最终必须独立按冻结规则评估。
