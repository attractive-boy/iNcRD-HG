## 反馈定义

每块L=lower(a)+diag(exp(ell))；环境表示h=L*x。邻居权重softmax(-||hi-hj||²)，温度1。
消息m(j→i)=solve(Li,Lj*phi(xj))，phi为共享无偏线性变换；门控插值更新x。
残差delta=m(j→i)-phi(xi)。full使用sum_j w_j delta_j delta_j^T + .001 I。
diagonal只保留该矩的对角；mean使用加权平均残差的外积+.001 I。
三者不是在邻域均值处中心化的协方差。

Cholesky固定再加1e-5 I数值jitter，R R^T=C+jitter I。目标坐标保存R的严格下三角和
对角的log，不把新的L^T L误写成C，也不把R误称为白化矩阵。
共享SiLU控制器输入[本节点块状态、聚合块状态、节点类型]，hidden16，输出rank4的
U/V和对角校正。新坐标=clip(.5*旧+.5*目标+.1*校正)，a范围[-2,2]，ell范围[-5,5]。
温度、混合系数、校正强度和clip范围沿用论文；ridge/jitter为本地固定数值设置。
不在数值失败时无记录地改变jitter。正定性不等于已满足原文固定点收缩条件。

## 两轮精确查询删除

初始x只依赖原属性/参数，初始frame固定I。删除训练正查询的两个方向时，第一轮
只有其两个端点的聚合、状态和坐标改变。其他节点的第一轮状态和坐标保持不变。
第二轮只需要查询两个端点的输出：重算其全部入邻居权重/消息/矩，排除对端查询弧；
自身事件使用校正后第一轮状态/坐标，其他邻居仍使用完整图第一轮结果。对端虽也变化，
但其弧已删除。每个端点的最终环境表示使用校正后的第二轮frame与状态。

图中不存在的查询本来不改变图，共享完整第二轮计算；分派依据图成员关系，不能读取查询标签。
已知正查询按256个分块，激活检查点只节省内存，不改变目标。没有跨查询归一化。
该推导只覆盖当前两轮及图无关初始化，不能直接推广到第三轮、结构atlas或随机游走初值。
