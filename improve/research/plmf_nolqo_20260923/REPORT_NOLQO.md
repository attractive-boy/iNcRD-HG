## 1. 为什么不用 LQO 也能做：问题是"查询边泄漏"，解法是让结构本身对查询边空心

LQO 在第六轮带来 +0.010，本质是在修一个问题：**训练正例 (m,d) 的边就在消息图里**，而测试对的边不在。模型因此在训练时"看得见答案"：

- plain 编码器里，查询边对 z_m 的影响最大达 6.0（`--check_enc` 实测），训练好的 full−M1 模型对训练正例 logit 的依赖平均 1.9，最大 8.3 / 10.9 logit；所有通道都不掩蔽时平均 18 logit（§3.5）。
- 同一组 11 个结构统计量（度、3-路径、内容桥接路径）喂 LR：**含查询边算 AUC 0.79，按简单路径定义（查询边不可能出现在长度 ≥ 2 的简单路径上）算 0.936**（MDR；MDS 0.79 → 0.940，`probe/feat_probe.py`）。第六轮"RT-NCN 不开 LQO 立刻过拟合"就是这个原因。

LQO 的做法是改**训练流程**，把查询边藏起来（K 组、K 次前向、训练图比测试图少 20% 的边）。本轮改**模型本身**：要求模型对每个查询对满足

　　**f(m, d; A) = f(m, d; A − A[m,d]·e_m e_dᵀ)**（查询空心，query-hollow）

即一个单元的预测永远不依赖该单元自己的观测值。这正是 EASE 的零对角约束（Steck 2019）、MADE 的掩码、"hollow" 网络（输出 i 与输入 i 无关，Chen & Duvenaud 2019；HollowFlow 2510.21542）在链路预测上的对应。满足这一条后，训练正例与测试对的输入分布一致，**不需要任何留出训练**；消息图在训练与推理时相同。下面四个模块分别在编码器、配对通道、闭式协同通道、旁信息四处实现空心。

## 3. 方法：`run_nl.py`

基线（plain）：kmer(80) / ChemBERTa(768) 行 min-max 特征，kNN(10) 余弦相似图，训练正例为 MiDrug 边，ToUndirected + AddSelfLoops；
HeteroConv(GeneralConv(−1,−1,256, aggr=add)) × 2，关系间平均，leaky_relu；解码器 Linear(2h,2h)-lrelu-Linear(2h,h)-lrelu-Linear(h,1)；
RMSprop(1e-4)，300 epoch 全批 BCE；训练对 10% 分层留出选 epoch（valsel）。与第六轮 plain 复现一致（MDR 5cv seed42：0.9230/0.9160 vs 0.9227/0.9162，差异来自 CUDA scatter 的浮点不确定性）。

记号：A 为消息图二部邻接（nm×nd），q = A[m,d]（训练正例为 1，训练负例 / 留出 / 测试对为 0），S_r、S_d 为零对角 kNN 关系。

### M1 QMP：查询掩蔽消息传递（`--enc mask --exact`）
编码器用稠密算子重写（与 PyG 实现数值一致，最大差 2e-5），对每个查询对直接算出"消息图中删去 (m,d) 后"的端点状态：
- 第 1 层：p1_m ← p1_m − ½·q·W¹_{d→m} x_d，p1_d ← p1_d − ½·q·W¹_{m→d} x_m，h1 = lrelu(p1)（½ 来自两种关系取平均）；
- 第 2 层：z_m ← z_m + ½(W²_{MiMi} + L²_{MiMi} + L²_{rev})(h1_m^¬ − h1_m) − ½·q·(W²_{d→m} h1_d + b)，z_d 对称；
- `--exact`：M2 汇聚的中间节点里，凡是邻接 m 或 d 的，其第 2 层状态同样做一阶修正（中间 miRNA m' 听得见 d、以及 kNN 邻居 m；中间药物 d' 听得见 m、以及 kNN 邻居 d），使**整个模型**精确空心。
q = 0 的对（训练负例、留出、测试）修正量为 0，与 plain 完全相同。无新参数；额外计算是每个查询对几次 h×h 的矩阵–向量乘，**单次前向**（plain 15 s/折 → 15.0 s/折；LQO 36.5 s/折）。

### M2 SP-RNCN：简单路径关系型神经共同邻居（`--qis --qis_ext --qncn`）
只在**不经过查询端点的简单路径**上取配对信息，因此查询边永远不在其中：
- 神经共同邻居（汇聚编码器状态，Linear(h,64) 投影）：
  二部 2-hop：中间 miRNA m'≠m，权重 w[m'] = A[m',d]·(C_m[m,m'] − q·A[m',d])；中间药物 d'≠d，w[d'] = A[m,d']·(C_d[d',d] − q·A[m,d'])（C = 共现计数，减去经过查询边的那一项）；
  关系桥接：w[m'] = R[m,m']·A[m',d]（R ∈ {kNN} ∪ M4 的序列关系，零对角）、w[d'] = A[m,d']·S_d[d',d]；e = Σ w·z / (Σw + 1)。
- 空心路径统计（log1p + z-score → MLP）：去掉查询伙伴后的度、简单 3-路径 P3 − q(deg_m + deg_d − 1) 及三种归一化、S_rA / AS_d / S_rAS_d 内容桥接路径；`--qis_ext` 再加删边后的 5-游走（闭式：(G u − G e_d − (deg_m−1)e_d)ᵀ(G e_d − u)，与显式删边逐位一致）、查询伙伴之外邻居的平均度、其余伙伴内容画像与查询节点的余弦。

### M3 MC-EASE：掩蔽单元闭式协同回归（`--ease 10,50`）
两侧 EASE：药物侧 S[m,d] = Σ_{d'≠d} A[m,d'] B[d',d]，B = f((AᵀA + λI)^{-1})，diag(B)=0；miRNA 侧对称（物品 = miRNA）。
EASE 的零对角只排除"用自己这一列"，查询单元仍在 Gram 里参与拟合；本模块把查询单元从 Gram 中精确扣除：
G' = G − u vᵀ − v uᵀ + v vᵀ（u = A[m,:]ᵀ，v = e_d，秩 2），用 Woodbury 得到 G'^{-1} e_d，每对 O(nd)（药物侧）/ O(nm)（miRNA 侧）。
λ ∈ {10, 50} 两个头 × 两侧 = 4 维，sign·log1p → BatchNorm → MLP。无可学习的闭式参数（可学习 λ 的版本 `--ease_learn` 与固定版相同，§8）。
不掩蔽时（`--ease_nomask`）同样的通道在训练后期崩溃（last AUC 0.60），valsel 能挑到早期 epoch 但全模型要靠掩蔽才稳定。

### M4 SeqSide：序列来源旁信息（`--rel seed7,seed6,pre,fam --ncn_rel ...,seed7,seed6,pre,fam --ease_side kmer`）
全部来自 PLMF-MDA 的 miRNA 名称与成熟序列：
- seed7 / seed6：成熟序列第 2–8 / 2–7 位完全相同（同种子 ⇒ 同靶基因谱）；覆盖 29% / 48% miRNA；
- pre：同一前体的 5p/3p 臂（名称去掉 -5p/-3p 后相同）；覆盖 41%；
- fam：名称家族（去掉臂、-1/-2 与字母后缀）；覆盖 52%；
- 以上作为 M2 的类型化关系（关系桥接共同邻居 + 计数）；k-mer 余弦 Gram 作为 M3 的 miRNA 侧旁信息核（Gram + αK，Jeunen 2020 式）。
种子/前体关系的标签富集很高：测试正例中 RA>0 的比例 14–31%，测试负例 0.6–2.6%（`probe/rel_probe.py`）。

### 3.5 空心性质的数值验证（`--check_inv 200`，fold 0 训练完 300 epoch 后）
对 200 个训练正例，比较"整图 + 掩蔽计算"与"真的把这条边从图里删掉后重算整个模型（编码器、M2、M3 全部重建）"的 logit：

## 7. 预期的审稿问题

1. **"这不就是 LQO / 删边训练换了个名字吗？"** 不是同一种东西。LQO / SpotTarget / SEAL 是改训练数据流：分组、删边、多次前向，训练图与测试图不同。本轮是对模型函数的结构约束（查询空心），训练图 = 测试图 = 全部训练正例，一次前向，训练负例 / 留出 / 测试对上与 plain 完全相同，只有训练正例的端点状态被精确替换为"这条边不存在时"的值（§3.5 数值验证到 1e-5）。它与 EASE 的零对角、MADE 的掩码是同一类约束。即便把 M1 整个去掉，M2/M3/M4 仍逐级为正（§4.4）。
2. **"评估方法变了吗？"** 没有。划分、负例、指标、10% 留出选 epoch 全部沿用前几轮；另给 PLMF-MDA 表的"测试最优 epoch"口径，结论相同（`tables_best.md`）。没有去噪、没有换划分、没有 TTA、测试时不插入任何边。
3. **"用了外部信息吗？"** 没有新增外部资源。ChemBERTa 与 k-mer 是 plain 基线自带的输入；M4 的种子/前体/家族关系由 PLMF-MDA 文件里的成熟序列与名称直接派生。若名称派生的 pre/fam 被质疑，可只保留纯序列部分（seed7/seed6 关系 + k-mer 核，`F_seqonly`）：对 L3 仍为 +0.0009/+0.0014（MDR 5cv×3，13/15 折）、+0.0008/+0.0009（MDS）、80/20 为 +0.0013/+0.0018、+0.0007/+0.0002，约为完整 M4 的一半；名称关系再加 +0.0008/+0.0007、+0.0013/+0.0015。
4. **"增益是不是来自更多参数？"** 不是：同通道同参数量只关掉掩蔽就掉 0.012–0.016（§4.3）；M1 零参数；M3 的闭式部分零参数。
5. **"为什么 16+ 度 miRNA 没有改善？"** 这些 miRNA 只占 2–3% 测试正例，plain 已经很准（损失 0.02–0.03）；新通道主要提供"邻居之外的证据"，对已经有大量邻居的节点没有新信息。
