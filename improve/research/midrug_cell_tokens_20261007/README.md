# 原miRNA表达列的药物条件注意力

最终要求保持：原MiDrug测试seed42/43/44均值AUC≥.9733929274、AP≥.9336833737，
PLMF MDR/MDS不下降。只用原miRNA/drug数据，不引入lncRNA、细胞注释、序列或新权重。

## 前序证据与本轮区别

边界原型辅助监督没有超过匹配随机选择；不自动搜索其权重/温度/边界比例。
此前FiLM先把整条938维RNA表达压为32维，再接受药物调节和图传播；本轮先保留
每个表达列，在查询配对的注意力聚合处才汇总。旧全局路由在图节点间交换特征。
旧Cellosaurus-MIL使用四个诊断分组及混合RNA图；这里只读取其源码，绝不调用
其加载器或导入诊断/lncRNA/circRNA输入。本轮不声称发明注意力或多实例家族。

## 原始列作为属性token

X是冻结的605×938原miRNA表达特征（沿用原按行min-max值）；D是216×768的原
ChemBERTa药物向量。每列X[:,j]经LayerNorm605、Linear605→32、LeakyReLU得到c_j。
候选RNA r在该列的标量X[r,j]经无偏Linear1→32，与c_j相加并经LeakyReLU，得到
RNA特定token h_rj。无偏线性映射生成key和值；药物向量经LayerNorm/Linear/
LeakyReLU/Linear得到32维query q_d。

对每条查询(r,d)，在**全部938列**上计算
`alpha_rdj = softmax_j(q_d·key(h_rj)/sqrt(32))`，
`z_rd = readout(sum_j alpha_rdj*value(h_rj))`。
readout是LayerNorm32、Linear32→32、LeakyReLU。零初始化投影把z加入原lin1激活前。
原M123主干、原图关系和输入、M1/M2/M3、对应重建目标与初始化均不变。

drug臂用真实候选药物query；mean臂用全部216种原药物query的均值广播。
两臂模块、参数、初始化、全列计算和优化设置相同；mean臂的原主干仍包含真实药物
信息。没有将细胞列变成新的图节点类型，也没有使用细胞名称、癌种或药敏监督。
这是原冻结节点全集上的传导属性编码，不声称支持新增RNA行的直接归纳推理。
注意力权重不是细胞特异药物反应证据或因果解释。

## 查询删除与计算边界

列编码、RNA标量及药物query仅取原属性和可训练参数，不依赖关联标签、度数、
查询批次或支持图。因此删除当前查询记录不会改变此属性分支；原M1/M2/M3删除
过程继续作用于原图分支。仍要核验非零新投影下完整模型的物理删记录预测，不能
用“属性无标签”替代完整模型检查。

查询按256条分块，每个查询仍使用全部列；没有截取列或邻居。相同列置换同步
作用于全RNA矩阵，输出应保持不变，因为不使用列位置编码；逐配对分块也不应
改变结果。训练重建只作用于原编码器，不新增列级伪标签或重建目标。

## 冻结训练及检查

drug/mean × 重建0/10 × 原训练内部三折，共12次拟合，seed42。
主干RMSprop lr1e-4/wd0；新属性分支及投影lr3e-4/wd1e-4，沿用既有特征分支配方；
原重建lr1e-4/wd1e-4、前50轮爬升。800轮上限、至少300轮、patience200，
以内部分数(AUC+AP)/2选轮。复用纯M123/unmasked10的六个不可变对照重放证据。

drug候选需相对纯M123、unmasked10和同重建mean，在三折均值上AUC/AP各提高≥.002，
才推进原验证。内部指标不替代最终原测试双+.02要求，不调整PLMF路径来牺牲其性能。

float64独立逐列/逐配对函数核对输出及全部参数梯度，检查列置换的输出/梯度、
分块等价和注意力归一化。真实模型核对原主干及重建初始参数/预测、非零投影下
各分支模块有限非零梯度、完整训练资源使用、BatchNorm一次、heldout标签翻转不变、
逐列参考、查询分块、原M123物理删记录。训练后每个新检查点重放指标/选轮/损失，
再次核验完整删除、无hook残留和移除原重建解码器的预测等价。
新属性分支属于推理模型，不能移除后声称与完整预测等价。
