令S为同类型属性sigmoid匹配，A/H为前轮对称归一化子图/隐藏图邻接。

root_path每步乘S，路径项含4个实际节点属性匹配；root_endpoints只在两端乘S，
省略中间属性。分母是同样输入/隐藏图路径在属性匹配恒为1时的质量。

图权重和S均非负，正常非零支撑下结果在[0,1]，对分母保留隐藏图梯度。
对称图使反向根读出相等，不重复增加一个等价通道。
