# PLMF-MDA 上更有创新点、可发论文的技术路线（2026-09-22）

对象：iNcRD-HG / PLMF-MDA（MDR + MDS）关联预测。
当前"最强单模型"：`ctx(33) + diff(52)` 交叉拟合特征 × 线性读头（LR C=0.3, kernel 图），
MDR 5cv **0.9510/0.9455**、MDS 5cv **0.9540/0.9516**（`plmf_innov_20260921`）。

本文回答：它为什么"不够新颖、指标不够狠"，以及下一步有哪些**真正有创新点且有提分空间**的路线。

---

## 0. 结论（先看这里）

1. **在"随机正负 + 5cv 全局 AUC/AUPR"这个 warm 面上，不要继续投入。** 本仓库已用
   87+ 机制、6 类算法族、注意力/OT/set-Transformer 证明：该面由**药物度数/流行度**主导
   （`drug_deg` 单独 AUC 0.9031/0.9135），参考模型已到这条信息量下的天花板（增量 ≈ 1e-4，
   低于折间噪声 ~5e-4）。换任何新网络、新目标、新融合都提不出可分增益——这不是能力问题，
   是评估面本身饱和（`NEW_MECHANISM_FINDINGS.md`、`algorithm_only_20260918/FINDINGS_V1.md`）。
2. **真正有空间、且"没人做过"的地方是严格归纳式（冷启动）MDA。** 今天的
   `plmf_frontier_20260922` 冷药探针 + 本文件新增的 `asym_probe.py` / `asym_stack.py`
   给出可直接写成论文的发现（数字见 §7）：

   | MDR · 冷门药物（plmf, 药物度 11–20） | AUC | AUPR | macroAUC |
   |---|---:|---:|---:|
   | 图上下文 LR（结构） | 0.7778 | 0.7767 | 0.8041 |
   | 图上下文+扩散 LR | 0.7890 | 0.7805 | 0.8269 |
   | **内容 kNN LR（Morgan-Tanimoto/ChemBERTa）** | **0.8137** | **0.8012** | **0.8338** |
   | 结构+扩散+内容 朴素融合 | 0.7821 | 0.7716 | 0.8276 |
   | 结构+扩散+内容+机制桥 融合 | 0.7935 | 0.7762 | 0.8306 |

   即：**冷药场景下"纯内容"打败"图结构"，结构-内容朴素融合是负迁移**（MDS 同样成立：
   内容 0.7682 > 图上下文 0.7403，融合 0.7352）。所有现役 MDA 论文（PLMF-MDA、MPHGNN、
   MGCNA、NCRDLLM、MIFNDRA、HDBI）都在 warm 划分上比指标，**没有一篇**做严格冷药/冷 miRNA
   归纳评测，也没有解释这个负迁移。这本身就是一个可发表的问题定义。
3. **一个重要的实测修正（§7）：内容→协同对齐（content→latent）不是万能钥匙。**
   本文件实现了 prototype/ridge 两类对齐（`asym_probe.py`）并接入内容 kNN 栈（`asym_stack.py`）：
   - 全局线性 `content→latent ridge map` **明显更差**（AUC 0.61–0.65）；
   - 内容加权 `latent profile` 单列只与内容 kNN 打平（0.8049 vs 0.8007），接入栈后
     在 11–20 度区间无增益（0.8107 vs 0.8138）；
   - **只在最冷的一档（药物度 1–4）对齐才带来正增益**（+0.008 AUC / +0.007 AUPR / +0.009 macro）。

   → 所以 R1 的方法贡献**不是**"再融一次就能涨"，而是"**按药物度分层**地刻画
   '内容 kNN 何时足够、对齐何时有用'"，并对最冷档做针对性设计。预期增益要按分层写，
   而不是笼统的 +0.02~0.05。
4. **推荐论文主线 = "严格归纳式 MDA 基准 + 分层诊断 + 冷端非对称方法"（R1，首要），
   辅以"可学习各向异性谱滤波/图信号生成"升级现有扩散谱特征（R2）与"基础模型 in-context
   链接预测"（R3）。** 三者可拼成一篇有诊断、有基准、有方法、有理论层次的工作；其中
   稳妥的贡献是基准+诊断，方法增益需按 §7 的分层证据谨慎声明。

## 1. 现状诊断：为什么"图上下文+扩散谱+线性读头"不难创新

- **无学习、无参、无预训练**：`ctx` 是度数/共邻/path/SVD 的手工统计，`diff` 是固定 α/β 的
  PPR/Katz，读头是线性回归。审稿人会问"机制贡献是什么"——答案是"更好的手工特征"，偏工程。
- **warm 指标已被流行度 shortcut 封顶**：线性头 ≥ 树 ≥ MLP、换图只动千分位、
  注意力要么崩（纯 softmax −0.077）要么只回 +0.001。说明"该特征空间近似线性可分，
  误差来自信息量不足而非容量"（`REPORT_PLMF_INNOV.md` §3.2）。
- **0.978/0.937 这个目标点本身是错的**：这是 MPHGNN 在**它自己的 MiDrug benchmark** 上的
  原文值，不是 PLMF-MDA；MPHGNN 搬到 PLMF-MDA 只有 0.9237/0.9136，连泄漏探针也只到 0.9616。
  把目标设成 0.978 只会不断否证自己。

**结论**：新颖性不能来自"再换一个图算子/再融合一次"，只能来自**新的问题设定**或**新的信息/监督**。
仓库里 `frontier_reassessment_20260913/REPORT.md` 已经给出过同样判断（"常规网络替换优先级低"）。

## 2. 竞争论文的覆盖边界（novelty bar）

必须先知道哪些卖点已经被占了，避免撞车：

| 已有工作 | 已覆盖的卖点 | 未覆盖 / 可切 |
|---|---|---|
| PLMF-MDA (PLoS CB 2026) | RNA-FM+ChemBERTa-2 多模态 + 跨模态注意力，warm 5cv | 严格归纳/冷启动；n=2 数据的泛化性 |
| MGCNA (PLoS CB 2025) | 多视图 GCN + 注意力，基因/结构多视图 | 视图间因果解耦；度偏置 |
| MPHGNN (BIB 2026) | miRNA-gene-drug 异质图 + 元路径 + GAE | 元路径在 PLMF-MDA 上增益≈0（本仓库消融证明） |
| NCRDLLM / MIFNDRA / HDBI / MVGSCA | 大模型/LoRA、预训练 GIN、超图解耦、谱编码+稀疏跨注意力 | 它们仍是 warm 转导；无跨数据集 in-context；无偏差审计 |
| mDADGAN / DMAGT | 扩散扰动 GAN；graph transformer | 扩散不是"图信号扩散"；无冷启动/无去偏 |

**空位**：① 严格归纳式 MDA 评测与基准（冷药 / 冷 miRNA / 跨 MDR↔MDS 迁移）；
② 基础模型 in-context 链接预测用于 MDA（无需按数据集微调）；
③ 发现/标注偏差（负样本、degree shortcut）的显式建模；
④ 条件化、细粒度（方向/剂量/细胞背景）关联——需要记录级标签，长期主线。

## 3. 前沿技术地图（2025–2026，按族）

检索来源：arXiv / Europe PMC / bioRxiv（`plmf_frontier_20260922/lit/scan_results.json`）。

### A. 链接预测的结构表达（替代/超越手工共邻）
- **OCN**（正交共邻，arXiv 2505.19719）：消除不同阶共邻的冗余 + 归一化缓解过平滑，平均 +7.7%。
- **NCN / MPLP**（arXiv 2302.00890 / 2309.00976）：用"准正交向量 + 纯消息传递"估计共邻，
  MPNN-then-SF 架构；指出 GNN 学不好共邻的根因是集合式池化。
- **HL-GNN**（arXiv 2406.07979）：把局部/全局启发式统一成邻接矩阵乘法，可堆 ~20 层。
- **LPFormer**（arXiv 2310.11009）：**自适应**成对编码，按边学该用哪些结构因子。
- **Link-MoE**（arXiv 2402.08583）：不同节点对需要不同成对信息 → 专家混合。
- **SP4LP**（arXiv 2507.07138）：GNN 编码 + 在最短路径序列上做 sequence model。

### B. 谱/图信号方法（直接升级"扩散谱特征+线性头"）
- **ASPIRE**（arXiv 2604.22549）：可学习谱滤波的**低频爆炸**理论 + 双层优化；指出常规
  推荐目标会让可学习滤波器把能量全堆到低频。这条理论正好解释本仓库的"度数主导"。
- **GiffCF**（SIGIR 2024）：把交互看成 item-item 图上的信号，用**热方程**定义各向异性
  扩散（前向平滑 + 反向 sharpen），谱域等价于各向异性噪声调度。
- **S-Diff**（各向异性谱域扩散）、**Flow Matching for CF**、**GSPRec**（arXiv 2505.11552，
  低通抓流行度 + 高斯带通抓个性化 middle-frequency）、**PolyCF**（TOIS 2025，多项式滤波器）。

### C. 冷启动 / 归纳式二部图链接预测（最贴 R1）
- **Shallow-RHS**（arXiv 2606.06225）：非对称架构——LHS 塔做消息传递，**RHS 塔严格只吃内容、
  禁 ID/子图/聚合**，强制把内容映射进协同空间；再用"warm surrogate 邻居"完成隐式图补全。
- **DGT-CF**（Sci Rep 2026）：图-文本**解耦**表示 + 正交正则 + **原型(prototype)冷启动迁移**。
- **MKGR**（冷启动 PPI）、**FS-GNN**（AAAI 2025，特征+结构三通道补全）、**GSSD**（KBS 2026，
  课程学习 + 去流行度偏置 + 对比损失）、**MOTIF**（arXiv 2608.25381，LLM 动机推理 + 图重构）、
  **WBT-BGRL**（非对比二部图自监督）。

### D. 基础模型 / in-context 链接预测（换"更强预测器"这条唯一被验证有效的轴）
- **TFMLinker**（arXiv 2602.08592）：表格基础模型 + 拓扑感知 link encoder + 原型化 local-global
  context，**免微调**跨图链接预测。
- **KGPFN**（arXiv 2605.14907）：知识图谱基础模型，NBFNet 局部上下文 + PFN 全局上下文，
  纯 in-context 适配未见图（本仓库已有 `kgpfn_runtime_v1.py` 雏形）。
- **KG-ICL**（NeurIPS 2024）、**Reification**（arXiv 2609.11347，把迁移机制放进表示而非架构，
  普通 GAT 即可零样本跨 40 个基准）、**HYPER**（知识超图归纳链接预测基础模型）、
  **AnyGraph**（ACL 2026 findings，图 MoE 跨域零样本）。

### E. 因果 / 不变性去偏（把 degree shortcut 变成卖点）
- **InvPref**（KDD 2022）、**CGDR**（KDD 2026，因果引导解耦 + 反事实）、
  **CAGED**（arXiv 2510.04502，把图聚合解释成后门调整，用变分估计无偏聚合权）、
  **DualPop**（TKDD 2026，流行度的"对偶性"）、**CI-GNN**（2026，SCM+do 算子嵌入 LightGCN）。
- 生物侧偏差：**miRBench**（Bioinformatics 2025：仅输入 miRNA、不输入靶位点也能靠类频率偏置
  刷高 AP）、**PULSNAR**（PeerJ CS 2024：非随机标注下的 PU 估计）。

### F. 几何 / 高阶
- **CurvFlow-DTA**（arXiv 2609.xxxxx）：离散 Ricci 曲率流做 DTA。
- 有向/有符号非线性 Laplacian、Temporal Sheaf NN、动态谱滤波——与当前静态二部图关系弱，暂不优先。

## 4. 推荐路线（按优先级）

### ★ R1（首要）严格归纳式 MDA：基准 + 非对称解耦冷启动方法
**核心创新**：
1. 提出 **严格冷药 / 冷 miRNA 归纳评测**（leave-drugs-out、k-shot new drug、MDR↔MDS 跨数据迁移），
   并给出**结构-内容负迁移**的诊断——这是 MDA 领域第一篇。现有工作全是 warm 转导。
2. 方法：**非对称两塔**（借鉴 Shallow-RHS）+ **原型冷启动**（借鉴 DGT-CF）+ **surrogate 图补全**。
   - 左塔（miRNA）：训练正例图上消息传递，保留协同信号；
   - 右塔（drug，或冷端）：**只吃内容**（Morgan、ChemBERTa、SMILES 序列），禁止 ID/聚合，
     强迫内容编码器对齐到协同空间；
   - 冷药推断：内容嵌入 → 检索 warm 代理邻居 / 映射到协同原型混合，做隐式图补全。
3. 加**去流行度/不变性正则**（GSSD/InvPref 思路），让冷药不靠度数。

**为什么能提指标（按 §7 实测修正）**：冷药面内容 kNN 已是强基线（MDR 0.8137 / MDS 0.7682），
**不是 0.78 起步、也不是轻松到 0.85**。实测显示：内容→latent 对齐只在**最冷一档（度 1–4）**
净涨（+0.008 AUC），11–20 度区间无增益。因此正确的提分策略是**按药物度分层**：
在最冷档做对齐/原型迁移，在较暖档直接走内容 kNN，并用协变量切换（degree-gated）把两者拼起来。
预期增益写成"最冷档 +0.01~0.02 AUC、整体不劣化"，不要写成全局 +0.03。
**为什么好发**：新问题 + 反直觉诊断（结构负迁移、内容 kNN 打败 GNN）+ 分层结论 +
对标工业级冷启动方法，Briefings in Bioinformatics / Bioinformatics / PLoS Comput Biol 都吃这套。
**对照必须做**：① warm-fit/冷测（当前 `ctx_warm`=0.82 偏高，因为有度数泄漏）作为上界；
② 内容 kNN 单列；③ 打乱内容的控制；④ 逐药物宏 AUC/AUPR + 覆盖率分层；⑤ 度分层（1–4 / 5–10 /
11–20 / 21+）逐档报告。

### ★ R2（方法升级）可学习各向异性谱滤波 / 图信号扩散生成头
把 `diff` 的固定 PPR/Katz 换成**可学习谱滤波**或**图信号扩散**：
- 用 **ASPIRE 双层优化**学滤波核（避免低频爆炸），或 **GiffCF/S-Diff** 的谱域各向异性扩散
  做生成式重构，或 **GSPRec** 的"低通（流行度）+ 带通（个性化）双滤波"。
- 关键论证：warm 面 AUC 由 degree 主导 → 正是"低频能量爆炸"的图信号解释；
  谱域分离流行度与个性化，能在**长尾/冷门药物**上拿增益（macro drug AP）。

**为什么好发**：现役 MDA 论文从没用过可学习谱滤波/图信号扩散；有 GSP 理论背书，
可写成"从手工扩散先验 → 可学习谱算子"的原理性升级。**注意**：在 warm 全局 AUC 上大概率
仍 ≈ +1e-3，卖点必须在长尾/冷启动与理论，而不是 warm 总分。

### ★ R3（换更强预测器，已验证有效的轴）基础模型 in-context 链接预测
本仓库已证明增益来自"更强预测器 + 新信息"，而非换网络。前沿对应 **TFMLinker / KGPFN /
Reification**：把 MDA 的 (miRNA, drug) 对编码成 pseudo-table 的一行，交给表格/图基础模型
**in-context** 预测，**免按数据集微调**，从而：
- 在 MDR 与 MDS、乃至其它 MDA 数据集上**零样本/few-shot 迁移**（当前单个数据集样本太少，
  这是比"再卷 PLMF-MDA"更好听的贡献）；
- 用 **Reification** 式的统一词表让普通 GNN 也能零样本迁移（实现简单、故事干净）。

**为什么好发**：in-context 链接预测 + 生物关联是全新组合；有跨数据集/跨模态泛化的强 claim。
**实现提示**：可直接改造现有 `kgpfn_runtime_v1.py` + `plmf_innov` 的 `ctx/diff/knn` 特征，
先做"冻结基础模型 + 结构 prompt"的最小验证。

### R4（评测贡献）偏差审计 + 去偏
先复现 miRBench 现象：`score_degree_r` 冷药 AUC 0.7813、`drug_attr_support` 0.7922——
单列就能刷分。做**度分层评测**（按 miRNA/药物度数分箱报 AUC/AUPR）+ 频率匹配负采样，
再上不变性/因果去偏（InvPref/CGDR/CAGED）。可单独成一节，也可作为 R1 的补充。

### R5（长期主线）细粒度 / 条件化关联
把二分类标签升级为 `(RNA, 干预方向/强度, drug, 细胞/癌种, 剂量, 时间, assay, PMID)`，
预测方向与效应量而非存在性。这是 `frontier_reassessment_20260913` 判定的高价值长期方向
（③+⑥+②），但**需要记录级标签整理**，短期成本高，建议 R1 出结果后再启动。

| 路线 | 创新度 | 提分把握 | 成本 | 建议 |
|---|---|---|---|---|
| R1 归纳式基准 + 非对称解耦 | 高 | 中高（最冷档 +0.01~0.02，其余持平） | 中高 | **首选主线** |

| R4 偏差审计 + 去偏 | 中 | 高（评测层面） | 低 | 先做，作为分析节 |
| R5 细粒度条件关联 | 很高 | 待定（缺标签） | 高 | 长期 |

**"MDA 的严格归纳评测 + 分层诊断 + 冷端非对称方法（+可学习谱滤波/基础模型 in-context）"**，

## 6. 最小可验证实验（建议下周就做）

1. **冷药基准固化**（**已初步完成**）：`cold_probe.py` 的 plmf 冷药面已跑全 MDR/MDS
   （结构/内容/融合/单列/打乱控制见 §7）；`ldo` 全药留一面仍在跑，硬得多（MDR ctx_drugcv 0.5968）。
   下一步补 MDS 的 `ldo` 与内容基线。
2. **非对称 RHS 塔最小实现**（**线性版已完成，见 §7**）：drug 侧只吃 Morgan+ChemBERTa，
   禁止 ID 与聚合；结论是线性 `content→latent` 不足以超过内容 kNN，需**按度分层**并做非线性/端到端对齐。
   下一步：把 `lat_profile` 接入端到端两塔 + 度门控，看最冷档是否 > 0.8698（deg1–4 当前最好）。
3. **负迁移归因**：分别测"加结构边的权重从 0→1"，确认融合变差是来自度数尺度还是噪声。
4. **可学习谱滤波**：在 support 图上用 ASPIRE 双层目标学一个低通/带通核，替换 `diff`，
   在冷药 + 长尾宏 AP 上看增益。
5. **in-context 最小验证**：用 `kgpfn_runtime_v1.py` 的接口，做 MDR→MDS 零样本，
   对比逐数据集训练的 LR。

验收标准：冷药面在**每个度分层**上，方法相对该层内容 kNN 基线所有种子为正、整体不劣化，
且有内容打乱负对照；跨数据集迁移零样本不低于目标数据集 warm 训练的 −0.02 AUC。

## 7. 初步实验验证（2026-09-22 实测）

新脚本：`asym_probe.py`（单列对齐打分）、`asym_stack.py`（对齐列接入内容 kNN LR 栈）。
结果文件：`results/asym_probe.csv`、`results/asym_stack.csv`。协议与 `cold_probe.py` 逐位一致
（plmf 冷药 = 药物度 11–20 全做测试；drugcv 交叉拟合 support；5 seeds）。

### 7.1 冷药面上"内容 > 结构"，且结构融合是负迁移（MDR/MDS 一致）

| 面 · plmf 冷药 | MDR AUC/AUPR/macro | MDS AUC/AUPR/macro |
|---|---|---|
| 图上下文 ctx（结构） | 0.7778 / 0.7767 / 0.8041 | 0.7403 / 0.7434 / 0.7812 |
| ctx+diff | 0.7890 / 0.7805 / 0.8269 | 0.7452 / 0.7391 / 0.7922 |
| **内容 kNN LR** | **0.8137 / 0.8012 / 0.8338** | **0.7682 / 0.7549 / 0.7901** |
| ctx+diff+knn（朴素融合） | 0.7821 / 0.7716 / 0.8276 | 0.7352 / 0.7256 / 0.7939 |
| ctx+diff+knn+mech | 0.7935 / 0.7762 / 0.8306 | 0.7269 / 0.7162 / 0.7943 |

单列（MDR）：`degree_r` 0.7813、`knn_tan0_mean` 0.8007、`drug_attribute_support` 0.7922。

### 7.2 内容→协同对齐：线性版只与内容 kNN 打平（MDR plmf）

| 打分器 | AUC | AUPR | macroAUC |
|---|---:|---:|---:|
| content_knn_tan（基线） | 0.8007 | 0.8124 | 0.8206 |
| **lat_profile_tan**（内容加权 latent 原型） | **0.8049** | **0.8180** | **0.8226** |
| svd_map ridge（全局线性 content→latent） | 0.6357 | 0.6587 | 0.6533 |
| lat_profile 取 top-5 相似 | 0.6472 | 0.6967 | 0.6931 |
| combo（rank 平均） | 0.8042 | 0.8158 | 0.8221 |

**接入 LR 栈后无增益**（MDR plmf，5 seeds）：knn = 0.8138/0.8012/0.8338；
knn+clat = 0.8107/0.7958/0.8356。→ 全局线性对齐/原型在 11–20 度区间不解决问题。

### 7.3 关键发现：对齐的增益只在**最冷档**出现（MDR plmf，按药物度分层）

| 药物度分层 | 内容 kNN LR AUC | +内容→latent 对齐 AUC | Δ |
|---|---:|---:|---:|
| **1–4**（极冷） | 0.8614 | **0.8698** | **+0.0084** |
| 5–10 | 0.8301 | 0.8255 | −0.0046 |
| 11–20 | 0.8138 | 0.8107 | −0.0031 |
| 21–105（较暖） | 0.7452 | 0.7331 | −0.0121 |

（AUPR/macro 同向：1–4 档 +0.0066/+0.0085。）这说明 R1 的方法卖点必须是
**度门控 / 分层对齐**，而不是无差别融合；也解释了为什么"结构+内容"在整体上负迁移。

### 7.4 更硬的面：leave-all-drugs-out（MDR，3 seeds，15 折）

| 面 · ldo | AUC | AUPR | macroAUC |
|---|---:|---:|---:|
| ctx（warm fit，泄漏上界） | 0.6979 | 0.6909 | 0.8496 |
| ctx（drugcv 无泄漏） | 0.5968 | 0.6050 | 0.8411 |
| ctx+diff（drugcv） | 0.6200 | 0.6158 | 0.8360 |

`ldo` 面无泄漏 AUC 仅 ~0.60，**headroom 远大于 plmf 冷药面**，是比"再卷 warm 0.95"
更适合做论文主战场的设定；MDS 与内容基线仍在补跑。

### 7.5 对计划的直接含义

- **可靠贡献**：严格归纳评测 + "内容打败结构 / 结构融合负迁移 / 对齐只在极冷档有用"的分层诊断。
- **方法贡献**：必须做**度门控的非对称对齐**（端到端、非线性、含 surrogate 补全），
  并只在最冷档兑现增益；不要承诺全局大涨。
- **更强的面**：`ldo`（~0.60 AUC）与跨 MDR↔MDS 迁移，比 plmf 冷药面更值得押注。

## 9. 不走冷启动的替代路线（补充，2026-09-22）

前提结论：**若"同一 warm 二分类 + 同样三类数据"不变，则无路**（87 机制实测墙）。要避开冷启动，
必须动三者之一：**信息 / 评估面 / 任务输出**。以下按"能提分 + 新颖度"排序，并标注可行性核实。

### 9.1 跨数据集迁移 MDR↔MDS（首选非冷启动方向）
- **可行性已核实**：MDR(1317 miRNA/105 drug) 与 MDS(1252/140) **共享 946 个 miRNA、81 个 drug**，
  实体高度重叠 → 可做 resistance↔sensitivity 的**跨任务/域适应**，而非严格冷启动。
- **新颖**：现役 MDA 论文都单数据集训练，没人做 R↔S 互迁与跨任务正则。
- **卖点**：无需重训/少样本适配即可迁移；目标域 warm 的 −0.02~−0.05 内即成立。
- 方法参考：R3 的 in-context（TFMLinker/KGPFN）、域适应、多任务共享。

### 9.2 负样本/偏差审计基准 + 去偏（成本最低，天然是 benchmark 论文）
- 现状：PLMF-MDA 负例是**随机零**（`neg_MDA_*.edgelist`）；`miRBench`(2025) 证明仅靠
  类频率/度数就能刷高 AP。本仓库实测：单列 `degree_r` 冷药 AUC 0.78、`drug_attr_support` 0.79。
- **贡献**：构建 **hard-negative / frequency-matched / curated-negative** 协议，做度分层评测，
  再上不变性/因果去偏（InvPref/CGDR/CAGED）。不是冷启动，是"评测协议"论文。
- 风险：提高生物可信度不保证旧 AP 上升——卖点应是"更公平/更难的基准 + 去偏后更稳"。

### 9.3 加新信息/监督（唯一被验证有效的提分轴，但需放宽"仅三类数据"）
- 仓库旧 benchmark 上，provenance/evidence 列给出 **+0.002~0.006 AP**（`pv_bce` 等）；
  这是"更强预测器 + 新信息"里唯一稳定的增益来源。
- 可用：miRNA 靶基因（ENCORI/miRTarBase）、drug 靶点（ChEMBL）、gene-gene（HumanNet）、
  DepMap 表达、通路——本仓库已有缓存（`mphgnn_plmf_20260921/cache`）。
- 在 PLMF-MDA 三类数据约束内，`mech` 桥很弱（冷药 0.70），但**warm 面加证据列**值得重测。

### 9.4 换任务输出（不改数据）
- **方向预测**：R 矩阵 vs S 矩阵天然给出 resistant/sensitive 二分类；比"存在性"更贴机制。
- **多任务 MDR+MDS 联合**（946 个共享 miRNA）：旧 benchmark 上 multi-task pooling 被否，
  但**跨任务对齐/正则**未认真试。
- **可解释/因果机制**：仓库已有 `graph_explain.py`；BIB/PLoS CB 吃生物故事（case study）。

### 9.5 方法层（warm 面，卖点非指标）
- 可学习谱滤波/图信号扩散（§4 R2）：理论卖点是"低频爆炸=流行度主导"。
- 基础模型 in-context（§4 R3）：通用链接预测，跨数据集（与 9.1 天然合流）。

### 9.6 结论
不想碰冷启动时，**最现实的两条是 9.1（跨 MDR↔MDS 迁移）与 9.2（负样本/偏差基准）**：
都有真实 headroom、都不需要新数据、且都不是"再融一次"。若愿意放弃三类数据约束，
9.3（加靶点/通路证据）是唯一被本仓库验证过能稳定提分的轴。
