## Fixed local adaptation, before validation performance

The mechanism under test is **head-context-dependent weighting of explicit logical rules**. It does not extend the accepted TabICL feature table or replace a pretrained tabular model. It shares relational-path information with earlier failed path models and the older feature-program work; the prospective claim is narrower, requires the matched global-rule control, and cannot create multiple successes from the rule encoder, context encoder, residual convention or fixed reference combination.

Two neural arms:

- `full`: head-specific structural RGCN context determines each rule's learned score.
- `global_rules`: replace the two concatenated graph-context vectors by their common mean over all RNA heads. This gives the same rule the same learned score for every head during evaluation. Keep the RGCN, GRU, parameter count, per-head dropout draws, rule statistics, locally applicable candidates, rule supervision and optimization budget identical. The common context still receives gradients. Coverage penalties and rule applicability may vary by head in both arms.

Core settings: width 64, two relational mean layers with root transforms and ReLU, dropout 0.1, a one-layer GRU, one-hop edge-built head neighborhoods with at most 32 uniformly sampled neighbors, deterministic preprocessing seed `29016 + 1009*fold + head_index`. Features are `[is_head, is_neighbor, distance, log(1+degree)]`. The degree and all context edges come from the already masked support. No RNA/drug attribute vectors or entity embeddings enter this scorer. Empty neighborhoods are retained as isolated head nodes. The GRU uses packed sequence lengths; the author implementation instead processes its padded sequence. These are explicit adaptations, not an exact reproduction.

All five support graphs delete **the whole neural query fold** before any rule statistic, path, degree, node sampling or graph representation is computed. Canonical binary same-type predicates are undirected, duplicate edges and self loops are removed; cross-type predicates have explicit inverse types. Enumerate the fixed well-typed rule bodies of length 2 or 3 from miRNA to drug. Count only vertex-simple paths: for three edges, subtract the two possible nonadjacent vertex repeats and add their intersection once. This is checked against independent exhaustive DFS. Length-one target rules are excluded. There are 13 rule schemas in the registered graph dictionary.

For each support separately, body count is the number of all unique RNA–drug pairs reached by that simple rule, and support count is how many of those pairs are known positives in the remaining training folds. Rule features are confidence, support fraction, Laplace confidence and the Wilson lower bound with z=1.96. This implements the paper's pair-count convention, not the sampled-triple counter in its code. These observed-positive fractions are not calibrated biological probabilities. Retain rules with support at least 2; for each head, take at most the top 32 applicable rules by Wilson score, with lexicographic schema tie-breaking. Query identities may appear among all possible endpoints, but their outcomes do not enter these calculations.

Predict using the paper's softmax/saturated-grounding idea: temperature 0.5, tanh(count/2), coverage subtraction `0.65*log(number_of_reachable_drugs)`, with no length or redundancy penalty. The new residual is the learned weighted potential minus the potential obtained from the same graph with zero neural rule scores. Zero-initialize the last rule-scoring affine layer. Thus the initial residual is exactly zero, and every residual stays in [-1,1]. This centering is a shared reference convention and is not counted as a technical innovation. Both arms are evaluated as the frozen reference plus 0.1 times the mean residual over the five supports. No unobserved target edge is inserted.

Training uses global BCE on nested OOF reference plus residual, together with 0.1 times the margin-1 rule-ranking loss. At each update, use the current omitted fold's actual positive queries that have both an applicable grounding rule and an applicable rule that does not ground that target. Sample 256 query/positive-rule/negative-rule triplets with replacement from these sets using the same private RNG stream in both arms. These negative **rules** may explain other targets; they are not new labelled biological pairs. The binary BCE still uses all positive and zero-labelled pairs in the fold. This additional BCE objective and sampling are adaptations to the project's global AUC/AP task, not the author's pure ranking objective.

Both arms have 400 AdamW updates and 400 backwards, learning rate selected from 0.001/0.003, weight decay 0.001, clip 5, checkpoints every 20 steps. LncDrug is the exact reference identity branch with no new neural training. Only CUDA device 1 is used for real-data neural fits. CPU fixture checks set only the CPU default generator; CUDA fits first select device 1 and then seed the CPU generator and that CUDA device separately.

## Implementation evidence and validation conditions

Training-only support preflight found 13 valid rules per historical fold; 597–598 of 605 RNA heads had applicable rules, and 487–504 of 517–518 positive queries per omitted fold had a usable positive/negative rule pair. No validation performance was computed. The first unit integration fixture (8-by-6 parity graph) had no valid ranking pair in a fold and correctly triggered the production guard. That failed unit record and source remain preserved. V2 changes only the synthetic integration fixture to a fixed 16-by-12 ring; production implementation is unchanged. All four checks then passed: exhaustive simple-path equality, full support/statistic/context isolation, exact null and global-context behavior, and actual fit/RNG/identity budgets.

The next required steps are real GPU short fits, saved-state/order/chunk replay, every historical and fixed-development support-fold audit, then a sealed screen and three-initialization confirmation. Fixed partitions and the frozen outer recheck remain mandatory if earlier gates pass. MiDrug global ROC AUC and sklearn AP must both improve over the reference and matched global-rule control; every LncDrug seed/split/metric must stay within the 0.001 loss tolerance. Overlapping development splits, historical outer access and method-selection uncertainty remain disclosed. No success is counted until all required stages pass.
