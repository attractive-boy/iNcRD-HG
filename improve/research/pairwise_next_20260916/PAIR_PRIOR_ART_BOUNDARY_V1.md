# Relation to the earlier rectangle experiment

After preparing this study, the broader repository audit recovered the earlier
`research/rectangle_completion_20260910/NOVELTY.md` and its failed 24-fit experiment.
That model jointly updates a target pair from three factors arranged around a
rectangle. The current candidate instead uses attention between two pair states
sharing the same intermediate index, with learned normalized scores. Both belong
to the broader higher-order relational-learning literature. Neither is claimed
to be globally unprecedented, and a revision or an ablation is not a separate
innovation. The rectangle study was already a failure, not an existing successful
direction being counted again.

The current fixed full primary failed its eight-fit screen: the corresponding
additive-value control improved both MiDrug metrics more. It is therefore stopped
without extra confirmation, fixed partitions or outer fitting. This additional
prior-art note does not change any frozen source, selection, or protocol.
