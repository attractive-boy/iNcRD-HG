## 2. 方法

### 2.1 PPRz：查询空心 PPR/Katz 扩散配对通道（`--ppr [--ppr_norm]`）

对训练正例图 A（nm×nd），定义行/列归一化随机游走 `An = A/dr`、`And = Aᵀ/dd`，两向扩散矩阵：
`R_rd = pref·An·(I − λ·And·An)^{-1}`（miRNA→drug），`R_dr = pref·And·(I − λ·An·And)^{-1}`（drug→miRNA），
其中 PPR：`λ=(1−α)², pref=α(1−α)`；Katz：`λ=β², pref=β²`；两组 (α,β) = (0.3,0.01)、(0.6,0.05)。

**查询空心（精确）**：删除查询边 (m,d) 不仅去掉一条边，还把 m 的行度、d 的列度减 1 → `An`、`And` 各有一行/列**整体重归一化**（这是与"只减一个矩阵元"的朴素推导的关键差别）。由此 `G' = And'An'` 是 G 的**精确秩 2 更新**，掩蔽分辨式用秩 2 Woodbury 从缓存逆矩阵得到；掩蔽行/列（用于行 z、行百分位）同样闭式得到。
数值验证（显式删边重算对照，`/tmp/opencode/ppr_verify.py`、`ppn_verify.py`）：
- 8 个扩散值：max |masked − edge-deleted| ≤ 3e-8；
- 掩蔽行（nm/nd 维）：≤ 3e-8；
- 最终通道特征（含行 z）：≤ 3.6e-7（20 个训练正例逐对显式删边重算）；
- 全模型 `--check_inv 20`：最终版 max 1.19e-5 / mean 2.44e-6（`logs/chkinv3.log`），base 同设置 1.48e-5 / 2.51e-6（`logs/chkinv_base.log`）——即新通道不引入额外非空心项。

通道 = 8 个原始量（log1p(20x)）+（`--ppr_norm`）每个量的**掩蔽行 z**（8 列）→ BatchNorm → MLP → 解码器。
（先做过"行 z + 行百分位"版本：百分位在稀疏行/零值处存在并列翻转，特征层面 masked-vs-deleted 差 0.08，全模型 check_inv 1.4e-2；改为只保留行 z 后特征差 ≤3.6e-7、全模型 check_inv 1.19e-5，与 base 同量级，且 seed42 上指标不降反升，故最终版只保留行 z。）
对照 `--ppr_shuffle`：特征在配对间置换（保留边际分布、破坏配对对齐）。

### 2.2 HN：定向难负例（`--hardneg K --hardneg_pool P --hardneg_mode same|deg|both --hardneg_loss bpr`）

对每个训练正例 (m,d)：候选负例 = 官方负例池中**同药 d**（`same`）与**药物度同分箱**（`deg`）且不在训练/验证/测试对中的 (m′,d′)；
预采样 P 个候选，每 epoch 重采样 K 个（fresh negatives），损失 = 官方对 BCE + w·BPR(`score(正例) − score(难负例)`)。
这是第八轮 `--unl`（均匀未标注单元、纯 BCE）的**定向**版本：负例分布对齐到"同药/同度"这一最难区域。

### 2.3 TPE：类型化路径编码器（`--tpe K`，负结果）

对每个配对枚举（查询空心，简单路径不含查询边）：type 0 = m–A–d′–A–m′–A–d；type 1 = m–Sr–m′–A–d；type 2 = m–A–d′–Sd–d；type 3+ = 序列关系桥 m–R–m′–A–d。
每条路径 token = [z_m, x1, x2, z_d] + 角色/类型嵌入（中间状态用 M1 的闭式修正保持精确空心），GRU + 每对路径注意力池化。
4 个变体（K=8/16/32、lr×1/10/30、dim 64/128）全部 ≤ base（−0.001 ~ −0.004）。

要点：
1. **HN 的损失函数很关键**：BCE 直接压难负例会崩（−0.022），BPR（相对锚正例排序）才稳定正增益。原因：难负例是固定池里采样的"未观测"对，其中含隐藏正例；BCE 把它们当硬 0 会把模型推离这些区域，BPR 只要求排在锚正例之后。
2. HN 的 MDR 增益在三种模式（same/deg/both）下一致（+0.0028~+0.0032），MDS 上 only-both 与 base 持平；fold 0 的 MDS 波动（−0.0007~+0.0002）在全量 5 折上转正（见 §4）。
3. TPE 全部变体为负：把 M2 的加权池化 NCN 换成"路径序列 + GRU"，在本数据上没有增量，且路径采样（K）越大越差 → 与第八轮"路径信息已被 M2/full 吸收"一致。
4. 扩散通道最初版本带"行百分位"，在稀疏行/零值处存在并列翻转（特征层 masked-vs-deleted 差 0.08、check_inv 1.4e-2）；最终版只保留行 z，特征差 ≤3.6e-7、check_inv 1.19e-5，且指标不降（§4 全部使用最终版 PPRz）。

## 5. 诚实边界

1. **量级**：最终栈的增益是 **+0.0016 ~ +0.0030**（AUC/AUPR，5cv×3）；80/20 上是 +0.0009 ~ +0.0022。不是量级跃升，而是在项目已确认的 warm 饱和面上（`drug_deg` 单列 0.90+、泄漏探针 0.9616）的稳定小改进。按上一轮的标准（每模块 ≥ +0.001 且两数据集同向），HN 过线（+0.0012~+0.0018），PPRz 单独只有 +0.0001（技术验证完整、增益很小）。
2. **HN 的归因**：对照显示"每 epoch 重采样的 BPR 负例"本身贡献了大部分（uniform 候选 +0.0014 MDR/+0.0008 MDS），"同药/度匹配"再加 +0.0009/+0.0003。因此 HN 的主要机制是**训练分布干预（难负例 + 重采样 + pairwise 排序）**，定向是其中较小但一致的一部分；这与并行第十轮的 `--unl`（均匀未标注 + BCE）在机制上重叠，叠加边际 +0.0002（MDS）。
3. **TPE 是明确负结果**：把手工池化 NCN 换成"类型化路径序列 + GRU"（SP4LP/PathNN 方向），6 个变体全部 ≤ base，且 K 越大越差——与第八轮"路径信息已被 M2/full 吸收、接近上限"一致。同理 ID 嵌入、药物侧 EASE 核、显式流行度分支都没有保留。
4. **PPRz 的定位**：作为"精确查询空心扩散通道"，其技术贡献（度重归一化的秩 2 Woodbury 掩蔽 + 掩蔽行 z）是新的且验证到 1e-7；但单独增益很小（+0.0001），在栈里补 +0.0002~+0.0005（主要 MDS/AUPR）。不应把它写成主要增益来源。
5. 本轮不引入外部信息；未使用 LQO；评估协议未改；所有新通道对查询边空心（数值验证见 §2.1）。
6. 未做的验证：HN 的 w=0.5/2、K=1/4 敏感性只在 fold 0/seed42 上看了 K=4（+0.0002）；`--ppr_lr` 未扫；更长训练（600 epoch）未测。
