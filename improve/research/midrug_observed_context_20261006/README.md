# M123 的训练观测上下文：正、零标签都精确删记录

仅使用独立冻结的 miRNA/drug 输入和当次内部训练记录。抽样零标签是观察状态，
不解释为敏感、抑制或生物拮抗；不补采新负例，不导入外部数据。

## 假设与已有方法的区别

旧的 `cavity_graph_20260915` 在有向边状态上做多层递归，并与历史预测器混合；
其 sampled-zero 版本不如 positive-only，不能把负边本身视作有效改进。
`energy_graph_v1.py` 则展开正边吸引/负边排斥能量；本轮不施加排斥或半正定符号约束。
`midrug_signedpaths_20261006` 曾向 M3 添加符号 EASE/固定路径统计，其结果不等同于
在当前纯 miRNA M123 的两个编码层内学习零标签邻居信息。

本轮仅检验这种**编码器内部的额外观测消息**是否有效。每层仍保留完整原编码器，
额外消息为 `D_C^(-alpha) C U_l(X)`，`C` 使用当次训练记录的正标签或零标签，
两方向各有独立无偏线性变换。`U_l` 全零初始化，不改变原始参数或关系平均分母。
第一层更新进入 LeakyReLU 后再参加第二层，允许在原节点状态中组合两种观察上下文。
原 M2 中间节点和 M3 统计仍按原正例图定义。

八配置：正标签/零标签上下文 × 接收度 alpha=1/.5 × 重建权重 0/10。
额外正标签通道是匹配对照：参数形状、初始化、度尺度、训练预算均一致。
另复用纯 M123 与单独重建 unmasked10。共 24 次训练及 6 个复用 checkpoint 重放。

## 精确删除

记查询在正例图中的值为 `q_A=A[r,d]`，在额外观察矩阵中的值为 `q_C=C[r,d]`。
两个查询值都从当次训练支持中查得，未知查询均为 0；它们不作为预测特征。
对接收端点，额外消息的变化为：

`delta_C = scale(degree-q_C) * (sum_messages-q_C*U(x_sender)) - scale(degree)*sum_messages`。

它与原正例消息删除项相加后，穿过第一层激活求得两个端点的 `delta_h`。
第二层端点加上原自身投影/同类自环变化与两个支持通道的直接删除变化。
查询所在的正边、观察边均已删除，所以改变后的对端状态不会沿查询边回传。

M2 的所有中间节点都排除查询端点，其度分母不变。池化修正分别累计原正边、
原同类边和额外观察边传播的 `U_2(delta_h)`。在零标签上下文中，同一对不可能同时
属于正例与零例，因此某些额外修正的交集为空；通用公式依然保留该项供正标签对照。
这里不是仅对正训练查询删边：零训练查询也从观察矩阵及度分母中删除。

观察矩阵、度数和缩放由每次训练记录重建，不进入 checkpoint buffer，避免重放
旧权重时覆盖显式删记录后的图。原图的节点/边数据不被变更。

## 文献核对边界

[GegenNet](https://arxiv.org/abs/2508.19907v1) 提供正负两类图分别变换的参照。
已核对公开代码 `wanghewen/GegenNet` commit `641364d4f11e95c0931472b00ad0793cfdb51b6f`。
`new_sbg.py::JacobiConv` 的一阶项是 `(a-b)/2*X + (a+b+2)/2*A*X`；a=b 时为
`(a+1)*A*X`。它支持论文式 (7)/(8) 的一阶系数形式，不能消除式 (6) 与之相差 1/2
的文字不一致。代码还采用 Jacobi 参数映射，并非直接照抄 v1 的全部公式。
本轮不使用该多项式、不下载作者数据，也不称为 GegenNet 完整复现。
来源清单在 ../midrug_literature_20261006/raw/gegennet_source_manifest.json。

## 实验协议

相同原训练内部三折、seed42、RMSprop 1e-4/alpha .99、原参数 wd0、新参数 wd1e-4，
最多 800 轮，至少 300 轮，patience200。按内部 (AUC+AP)/2 选轮。
所有配置须对纯 M123 和 unmasked10 同时提高两项均值至少 .002；零标签版本还须
对同 alpha/重建权重的正标签版本达到相同门槛。这只决定是否进入原验证。
最终验收仍为原测试三种子 AUC≥.9733929274、AP≥.9336833737，PLMF 两数据集不降。

`check.py` 检查 20 个 float64 最终输出/梯度案例，含正例、零例、度一变零及未知查询；
每个配置还验证真实图的非零消息、显式删记录、初始化一致和留出标签隔离。
执行：check.py → launch.py → audit.py → summarize.py。
