# 药物条件化潜在表达特征的完整图传播

最终目标保持纯miRNA、无外部数据，原MiDrug测试seed42/43/44均值
AUC≥.9733929274、AP≥.9336833737，PLMF MDR/MDS不下降。
本轮是FiLM条件调节的独立迁移检验，不是新方法家族或论文完整复现。

## 前序证据与机制范围

原名称词干/编号、药物骨架统计已在midrug_mirna_only中测试过，不重复。
此前原始/节点向量双线性项、普通输入修订、RNA邻居注意力、support operator、
源标记传播及药物Transformer适配均保留为已有工作，不能称为未尝试的方向。
普通原始向量双线性项没有在图传播之前为每个候选药物改变RNA的潜在特征。
source_conditioned分支的初始RNA状态为零；本轮两类节点的初始状态均非零，
不借用其三层删边推导。当前原M123完整主干及其M1/M2/M3始终保留。

已有内部误差记录中，M123的同药物内AUC约.72–.77，低于全局AUC；这些配对比较
只占全局比较约.003，不能据此断言它解释了所有剩余全局误差，更不能替代全局验收。
该观察只支持检验更具体的药物–RNA特征交互，不能保证+.02增益。

机制参考已核对的scRADAR（PLoS Computational Biology2026，
DOI10.1371/journal.pcbi.1014392）及其作者代码
31cc93fe76e7c21e24089f0de3ffebc7199faf94中的药物条件FiLM。
其原输入包含通路/药物扰动指纹和原型路由；本轮不导入这些数据或原型。
本轮调节的是原表达矩阵的学习潜在通道，不将这些通道称为真实通路、细胞级药敏
或因果机制。文献核查范围与源文件哈希在predecessor_review.json。

## 模型和匹配对照

原938维miRNA表达与768维药物向量分别经LayerNorm、线性投影及LeakyReLU变为32维。
药物编码输入小型MLP，产生gamma/beta；在每个查询药物d的上下文中，初始RNA状态为
`LeakyReLU((1+tanh(gamma_d))*h_r+beta_d)`。调节器末层从零初始化。
初始药物节点状态是各药物自身的32维投影，在所有上下文中相同。

conditioned用查询药物的表示产生gamma/beta；mean用全部216种原药物表示的均值，
产生一个共享条件。两臂参数、初始值、全部上下文计算和优化预算相同；均值不随
查询批次变化。mean仍可沿图接收真实药物特征，所以不是移除所有药物信息。

每个上下文都在完整605×216节点集合及原训练正边、原同类型边上做两层传播：
`p_r=.5*(A W_dm h_d+S_r W_mm h_r)+W_self,r h_r+b_r`，drug方向同理。
每层经LayerNorm/LeakyReLU。S_r/S_d按原图方向构造，保留对角线的实际重复权重。
读取查询两个端点的第二层状态，以零初始化投影加入原lin1激活前。
不截邻居、不引入零标签消息、不改变原M1/M2/M3参数或图关系。

## 两层精确查询删除

初值只依赖原特征及模型参数，不依赖关联标签或查询集合。删除a=A[r,d]后，
第一层只有r/d两端点改变。两者预激活分别减去`.5*a*W*h_other^0`，重新经过非线性。
第二层查询端点先减去原查询边消息；再加自身线性变换的第一层变化，以及同类型
对角权重乘以该变化的消息。改变后的对端状态不沿已删除的查询边回传。
随后重新经过第二层非线性。该推导允许两类初值非零、同类型图有向和自环重复，
但仅覆盖本轮两层、固定特征条件和无关联度归一化的形式。

独立float64单上下文dense物理删图核对输出及全部参数梯度，含重复关联权重、
有向同类型边、自环、度一节点、已知正例与未知查询。真实图以非零调节权重和
非零融合投影验证整个M123删记录、有限梯度、初始化一致及留出标签翻转不变。

## 冻结实验协议

conditioned/mean × 重建0/10，原训练内部三折，共12次拟合；只复用已核验的
纯M123和unmasked10对照6个检查点，不把哈希核查算成新的GPU重放。
主干RMSprop lr1e-4/wd0，新增分支lr3e-4/wd1e-4，重建lr1e-4/wd1e-4。
新增学习率沿用原分子特征分支配方，未根据本次内部成绩搜索。
800轮上限、至少300轮、patience200，按内部(AUC+AP)/2选轮，重建50轮爬升。
conditioned候选对纯M123、unmasked10和同重建mean对照的两个全局指标均值均须
提高≥.002才推进原验证；不以同药物AUC替代验收，不降低最终双+.02要求。
