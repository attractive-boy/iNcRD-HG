## 2. 方法：`run_gnn.py`

基线（`plain`）= `run_v4.py` 的 plain：kmer(80) / ChemBERTa(768) 行 min-max 特征，kNN(10) 余弦相似图，训练正例为 MiDrug 边，ToUndirected + AddSelfLoops；
GeneralConv(−1,−1,256)×2（邻居求和、关系间平均，本轮用 HeteroConv 逐关系实例化，与 to_hetero 等价：fold 0 test-best 0.9219 = 0.9219）；
解码器 Linear(2h,2h)-lrelu-Linear(2h,h)-lrelu-Linear(h,1)；RMSprop(1e-4)，300 epoch 全批；10% 训练对分层留出选 epoch（所有变体同样）。

### M1 留出查询边消息传递（LQO, `--lqo 5`）
训练正例随机分 K=5 组；每个 epoch 做 K 次前向：第 j 次的消息图 = 其它组的训练正例（+ 相似图），损失只取第 j 组正例 + 1/K 的负例；测试用全部训练正例作消息图。
每个监督对在它被监督时**永远不在消息图里**，与测试对的处境一致。等价于把特征层的 K 折交叉拟合搬进 GNN。

### M2 关系型神经共同邻居配对解码器（RT-NCN, `--ncn --cnt`）
对查询 (m,d) 和当前消息图 A：
- 结构计数（13 列，log1p + z-score，MLP 投影）：deg、path3 及三种归一化、path5、A·S_d、S_r·A、S_r·A·S_d 及归一化；
- 共同邻居隐状态：drug 侧权重 w_d[d'] = A[m,d']·(AᵀA)[d',d]，miRNA 侧 w_m[m'] = A[m',d]·(AAᵀ)[m,m']，e = w·z / (Σw + 1)，各经 Linear(h,h) 后与 z_m, z_d 拼接进解码器。
  这是 NCN 在二部图上的 2-hop 形式（共同邻居 = m–d'–m'–d 路径的中间节点）。
计数与权重全部来自该 pass 的消息图，所以在 LQO 下无查询边泄漏；不开 LQO 时它们含目标边本身而立刻过拟合（§3.1 fold 0：0.912）。

### M3 溯源超边配对通道（`--prov`）
数据：`../plmf_xrel_20260922/data/full_{ds}/data/pair_records.pkl`（ncRNADrug DR_Curated，覆盖 95% 正例：PMID 列表 + 细胞系/表型/疾病 token）。
- 消息图：新增 `study`（944 / 1 240 个 PMID）与 `ctxtok`（1 060 个 token）节点类型，miRNA→study、drug→study 边只来自**消息图正例**的记录（星展开超边），常数特征，邻居平均（超边节点 = 成员均值）。
- 配对通道：M_r[m,s]、M_d[d,s] 为消息图正例的 miRNA / drug–study 关联，共享超边权重 w[s] = M_r[m,s]·M_d[d,s]，输出 e = w·z_study/(Σw+1)（Linear(h,64)）+ 计数 5 列（共享数、按各自超边数归一化、各自超边数）；token 同理。
查询对 / 测试对自身的记录从不进入图或通道（LQO 保证）。对照 `--prov_shuffle`：记录在训练正例间置换。

### M4 旁信息关系配对通道（`--side`）
标签无关的 miRNA 关系：HMDD v4 疾病谱（2 373 个疾病节点，覆盖 83% miRNA；同时作为 miRNA–miRNA 余弦 top-20 关系 `hsim`）、名称家族（895 个，52%）、miRBase 基因组簇（10 kb，51%）。
- 消息图：disease / family / cluster 节点类型（邻居平均）；
- 配对通道：家族 / 簇 / hsim 作为 miRNA 关系 R 进入 RT-NCN（w[m'] = R[m,m']·A[m',d]，即"m 的家族成员 / 同簇成员 / 疾病谱相似者是否与 d 有关联"）；疾病作为超边（M_r = H，M_d = AᵀH，即"d 的已知 miRNA 的疾病谱"）。
对照 `--side_shuffle`：旁信息行在 miRNA 间置换。

这是最严的协议：同一篇论文报告的所有 (miRNA, drug) 对整体进入同一折，测试时既没有该研究的溯源记录，也没有"同研究的姐妹对"作为消息边。

- 在研究分组划分下，**LQO（MDR）与旁信息通道在两套数据上都不显著**（5/10、4/10 折），RT-NCN 与溯源通道仍稳定为正（10/10、9/10）。溯源通道在此协议下的增益来自"测试对的 miRNA / drug 与训练研究的共现结构"（研究级 NCN），而不是同研究姐妹对，置换对照仍低 0.004–0.011。
