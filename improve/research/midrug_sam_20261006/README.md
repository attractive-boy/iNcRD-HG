# 参数扰动训练：纯 miRNA 内部对照

完整补全梯度六次拟合已审计；full_rec10 内部 AUC/AP 为
0.9536760196 / 0.9140345803，没有同时超过停止梯度、随机常数补全和重建基线。
本轮改检验训练参数扰动，保留 M1/M2/M3、关联损失与推理架构。
不是新增图结构、软补图或以论文指标代替本数据集指标。

核读：ICLR 2024 GraphSAM（arXiv:2406.13137v1，§3.3–4.2）及
2026 E2A（arXiv:2602.08855v1，§2–4，DOI 10.1145/3774904.3792707）。
前者讨论分子图 Transformer 的参数扰动；后者实际使用图分类的条件 VAE 和
潜在表示能量扰动，不能把标准 SAM 称为 E2A 复现。当前每轮一个全批次更新，
GraphSAM 每轮重置近似梯度不带来其多批次场景的加速，因此先检验标准两次反传。
详细文献适用范围见 ../midrug_literature_20261006/OPTIMIZATION_READING_NOTES.md。

四配置 × 原训练内部三折，seed42，共12次新拟合：

- sam / sam_rec10：g=∇L，epsilon=0.05*g/(||g||₂+1e-12)，在 theta+epsilon
  计算梯度，恢复 theta 后由原 RMSprop 更新，不对 epsilon 求导。
- random / random_rec10：从独立固定 RNG 采样标准高斯方向，全参数 L2 归一化到
  同一个0.05半径，其余计算流程相同，包括第一次反传。它是方向对照，不能称为SAM。
- 后缀rec10沿用原始特征重建权重10和前50轮爬升；两次前向使用相同的本轮
  重建采样节点。主干wd0、解码器wd1e-4、RMSprop lr1e-4/alpha.99均不变。
- 两次前向均处于train模式；第二次BatchNorm更新的缓冲区恢复到第一次后，
  每轮只累计一次运行统计。恢复参数使用精确copy，不使用加扰动再减回造成舍入漂移。

sam两个配置才有候选资格；各自须在三折平均 AUC、AP 上同时超过相应random、
纯M123和unmasked10至少0.002，才能冻结下一阶段原验证实验。
不增加扰动半径搜索，不按原验证或测试调参。最多800轮、至少300轮、patience200，
按内部(AUC+AP)/2选轮，复用此前审计的6个原训练对照。
12次新拟合与6个复用对照分别报告，不把哈希核验算成新的GPU检查点重放。

初始验证：独立二次函数解、异常恢复、CPU实际模型rho0与原更新数值一致、实际模型独立
autograd两步重算、BN只更新一次、M1/M2/M3显式删边及留出标签翻转不变。
训练后重放概率/指标/选轮、两次loss构成、扰动半径与方向、BN计数和显式删图。
推理时不使用扰动，也不使用重建解码器。

浮点说明：普通CUDA训练前向/反传在相同参数输入下重复，梯度最大差4.77e-7，
见cuda_repeated_backward_diagnostic.json。CPU复用/清零grad缓冲也有约1e-7更新差。
零半径更新与独立第二步梯度以atol2e-6/rtol2e-5检查；扰动方向以atol2e-7检查。
近零梯度经RMSprop可能放大舍入误差，因此先独立校验第二步梯度，再使用同一已校验
梯度核对恢复后的优化器更新。二次函数用float64严检，参数/BN缓冲恢复和同梯度
优化器更新按精确相等检查，不宣称整套float32计算逐位确定。

没有lncRNA、外部数据集、注释、序列或新预训练权重。原测试仍需seed42/43/44均值
AUC≥0.9733929274、AP≥0.9336833737；PLMF两个数据集不下降。目标尚未实现。
