## 2. 方法

### 2.1 VG：把留出的 10% 训练正例留在消息图里（`--val_graph`，来自第十轮）

`run_fold` 先按 10% 分层从训练对里切出 val（选 epoch 用），此前所有轮次接着做了
`train_pos = tr[ytr==1]`（**val 被切掉之后**的），于是 **训练、选 epoch、测试三处用的消息图都少了 10% 的训练正例**。
这是本项目 valsel 协议的自伤：PLMF-MDA 官方协议（以及 R8 §6.2 的对照口径）用的是 100% 训练正例。
`--val_graph` 把 val 正例并回 `train_pos`（消息图 = 全部训练正例），**损失仍然只看 90% 的 tr**：

- 留出对 (m,d) 在图中，但所有通道对它的计算都是查询空心的（它的边被闭式删除），所以**它自己的分数看不到自己的边**，选 epoch 仍然无泄漏；
- 测试对不在图中，且其边从来不训练——测试条件与 val 条件一致；
- 最终测试时消息图 = 全部训练正例，与官方协议逐位一致。

数值一致性：R12 runner 复现第十轮 `--val_graph` 的结果**逐折一致**（MDR 5cv seed42 0.9531/0.9500，MDS 0.9565/0.9549；与 `plmf_r10_20260927/results/VG_*.csv` 相同）。

### 2.2 HN：定向难负例 + BPR（第十一轮，`--hardneg 2 --hardneg_pool 8 --hardneg_mode both --hardneg_loss bpr`）

每个训练正例从官方负例池里的"同药 ∪ 药物度同分箱"候选中**每 epoch 重采样** 2 个难负例，用 BPR 对锚正例做配对排序（BCE 会崩，R11 §3.1）。
本轮在 VG 基线上复测：MDR +0.0017/+0.0026（15/15 折），MDS +0.0011/+0.0020（AUC 13/15、AUPR 14/15 折，均值正）；同-miRNA 模式为负，故最终 HN 仍用 both。

### 2.3 UNL 与 PPRz（第十/十一轮）

- UNL：每 epoch 额外采样 `|train|` 个未标注单元（严格排除 train/val/test）做 label-0 BCE；在 VG+HN 之上只剩 +0.0000~+0.0003（与 R11 的"与 HN 大量重叠"一致），保留。
- PPRz：查询空心 PPR/Katz 扩散配对通道（度重归一化后的精确秩 2 Woodbury 掩蔽）+ 掩蔽行 z；在 VG+HN+UNL 之上 +0.0001/+0.0003（MDR/MDS），保留（技术验证完整，代价是每折约 2× 时间）。

### 2.4 本轮新架构候选（全部筛选后未保留，如实报告）

- **PSA（`--psa DIM --psa_lr`）**：学习式注意力 NCN。对 `--qncn` 的每个关系集合（权重 w、中间节点状态 Z）：
  `logits = q([z_m,z_d])·k(Z)/√d + log(w+ε)`，softmax 后池化 `att@Z`，**再加上中间节点的闭式空心修正**
  （`cm_dm·Σatt·1[d∈N(m')] + cm_mm·Σatt·S_r[m,m']`，d 侧对称）；输出 `o(·)` 与固定池化并排拼接。
  `--psa_uniform` 为去掉 log(w) 先验的对照。空心性数值验证：`--check_inv 5` max 1.91e-6（20 epoch 烟测）。
  结果（fold 0，对 VG+HN+UNL）：lr×1 MDR −0.0023/−0.0035、MDS −0.0018/−0.0030；lr×30 训练不稳定（−0.0052~−0.0066）。**不保留**。
- **MoE（`--moe K`）**：在共享 pair 隐状态上接 K 个线性专家，router 由 `[log1p(deg_m), log1p(deg_d), 积, 差的绝对值]` 产生，router 末层零初始化 → 起始=单头平均。fold 0（对 VG+HN+UNL）：MDR −0.0027/−0.0041，MDS −0.0008/−0.0017。**不保留**。
- **AA（`--aa`）**：把 Adamic-Adar / resource-allocation 加权的掩蔽简单 3-路径（=蝴蝶/4-环计数，中间节点度不受删边影响，天然空心）追加进 qis。fold 0：MDR +0.0001/0.0000，MDS +0.0004/−0.0001。**不保留**。
- **多尺度 kNN（`--knn2 K`）**：Sr/Sd 用 kNN(10) ∪ kNN(K) 的并图（保持单关系，不破坏闭式编码器）。K=30：MDR −0.0016/−0.0001，MDS −0.0019/−0.0018。**不保留**。
- **listwise（`--lw_d/--lw_m`）与 HN 同-miRNA**：见 §0 表。**不保留**。

**这些负结果支持项目此前的模型侧判断**：PLMF-MDA 的可达信息量已被"空心结构通道 + 线性可加特征"近饱和
（R3：线性头 ≥ 树 ≥ MLP；R11：路径编码器全负；本轮：注意力 NCN、专家解码、度校正计数、多尺度图全部 ≤+0.0005）。

## 4. 诚实边界

1. **量级与归因**：F 相对 B 的 +0.0043~+0.0072（valse）里，**最大一块（+0.0028~+0.0037）是修协议**，不是新信息；在官方协议下 VG 增量恒为 0，真正的新增是 HN/UNL/PPRz 的 **+0.0004~+0.0029**（四个 board：MDR/MDS × 5cv/80/20，best/last 全部为正）。请勿把 VG 写成"模型涨点"。
2. **绝对上界**：泄漏探针（测试正例边放进消息图的诊断模型）MDR 0.9616；F 的官方 MDR 0.9551 距离它 0.0065——在"只看 PLMF-MDA 三类数据 + 查询空心"的约束下，剩余头寸很小。
3. **六个新架构候选全负/零**（PSA、MoE、AA、多尺度 kNN、listwise、HN 同-miRNA），其中 PSA 是本轮实现最完整、空心验证最干净的一个（1.9e-6），仍只有 ≈0。这说明模型容量/聚合方式不是瓶颈，"信息量 + 查询空心 + 训练分布"才是。
4. **未做的验证**：VG 的随机边对照（把留出的 10% 正例换成同样数量的随机单元——诊断"是边还是结构"）未跑；HN 的 w/K 敏感性、UNL 的 80/20 面、PPRz 的更细归一化未再扫。官方协议的 5cv 只跑了 seed42（与 R8 §6.2 口径相同），80/20 跑了 0–2。
5. 评估协议、负例、指标、选 epoch 规则全部未变；没有去噪评估、没有转导平滑、没有 TTA、没有伪标签；不引入任何外部信息（ChemBERTa/k-mer 是 base 自带输入）。
