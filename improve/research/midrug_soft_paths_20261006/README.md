# 两条已观测边与一条软补全边

仅原 miRNA/drug 特征、同类关系和当次训练标签；不使用 lncRNA、外部数据、
序列、注释或新预训练权重。原 M123、原划分和 PLMF 保护目标保留。

## 文献与历史区别

NCNC（ICLR2024，arXiv:2302.00890v4）式10对邻居交集中缺失的一条边赋预测权重，
编码器仍使用原图；官方实现对递归预测停止梯度。2025年的IECNC、CGLE、CELP
提供后续参照，核读记录见 ../midrug_literature_20261006/COMPLETION_READING_NOTES.md。
上一轮CGLE适配已完整审计，未达到内部门槛。

本轮是受限二部图适配，不是NCNC复现，也不声称原创。旧 rectangle_modules.py
已经对三个潜在配对因子做乘法；这里复用相同的矩形包含排除恒等式，但限制每条
候选路径必须有两条观测正边，仅第三条由特征预测器赋权。没有递归补全多条缺边、
硬伪标签或向M123编码器加边。这是明确的结构消融，不能把“软补全”当作全新家族。

## 预测器与路径

两个原特征输入分别经LayerNorm、Linear128、LeakyReLU、Linear32，使用缩放内积
加两侧特征偏置生成整个miRNA×drug的logit矩阵L。它从当前训练标签以0.1倍BCE
辅助损失共同学习，没有另一个预训练数据源。sigmoid(L)只作为软权重，不宣称校准。
令A为训练正例矩阵，K为全部训练观测（正例和采样零标签）的位置掩码。
U=(1-K)*sigmoid(L)，因此不会把已观测采样零标签当作待补全边。

定义R(X,Y,Z)[r,d]=sum_{i!=r,j!=d} X[r,j]Y[i,j]Z[i,d]。
三个额外特征分别为log(1+R(U,A,A))、log(1+R(A,U,A))、log(1+R(A,A,U))。
这相当于缺失左边、中边、右边；每条路径恰有一条未观测边，另两条是观测正例。
计算采用float64矩阵乘法与包含排除，再转回原dtype。

查询端点i=r和j=d都排除，所以当前(r,d)在A或K中的变化不能进入任何保留项。
即使删除正例后U[r,d]变为非零，或删除零标签后解除K[r,d]，它也仍被排除。
原M1/M2/M3继续使用自己的精确查询删除。独立逐路径枚举和显式删图核验这一性质。

补全权重停止梯度；特征预测器通过直接logit输入和辅助BCE获得梯度。这与端到端
穿过补全权重求导不同，须在梯度核验中保留同一停止梯度定义。
直接logit与三个路径特征进入4→64→1残差头，末层零初始化，初始恢复原M123。

## 固定消融与验收

- direct：相同预测器、辅助监督、残差头，三个路径输入为零。
- uniform：相同直接logit，U=(1-K)*0.5，比较可行路径数量是否已经足够。
- soft：相同直接logit，U=(1-K)*sigmoid(L)，检验学习的软权重。

三个模式×原无掩码重建0/10×原训练内部三折，seed42，共18次拟合。
各模式分配同样参数，direct未使用的路径输入权重不算额外有效训练容量。
RMSprop lr1e-4、alpha.99，主干wd0、新分支/重建wd1e-4；800轮上限、至少300轮、
patience200，内部(AUC+AP)/2选轮。重建权重前50轮线性增加，特征BCE权重恒为0.1。

仅soft和soft_rec10为可推进候选；分别须同时超过匹配direct、uniform、纯M123及
unmasked10，两个指标的三折平均增益均≥.002。不能事后改选某个对照作为本轮成功。
最终要求仍为原测试seed42/43/44均值AUC≥.9733929274、AP≥.9336833737；PLMF两集不降。
原验证/测试不参与本轮。先check.py，再launch.py、audit.py、summarize.py。
