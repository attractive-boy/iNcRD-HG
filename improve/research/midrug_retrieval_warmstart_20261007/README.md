# 案例分支的原模型初始化与主干冻结

最终目标保持原MiDrug测试seeds42/43/44均值AUC≥.9733929274189016、
AP≥.933683373732677，PLMF两集不下降。只用原miRNA/drug，不引入lncRNA、
外部数据、序列、注释或新权重。仍只使用原训练内部三折开发。

## 证据与问题

前轮label/features/direct三臂九次拟合未通过内部筛选。label在85/90/88轮选中，
原unmasked10在244/512/327轮选中；其独立结果不能当作同检查点消融。
选择冻结后的同检查点干预表明，去掉案例标签或整个分支反而降低已训练模型指标，
说明共同训练改变了主干。这个结果不证明主干更新是失败原因，只支持对其进行检验。
见 ../midrug_task_literature_20261007/RETRIEVAL_FOLLOWUP.md。

本轮不更改32近邻、64维key、value结构或排序。完整复用上一轮冻结的检索实现，
区别是从原unmasked10已选权重出发，而不是从随机主干开始。

## 冻结三臂协议

- frozen_label：原主干及重构模块所有参数冻结，主干eval模式固定BN缓冲；只训练原
  label案例分支。唯一可推进候选。
- joint_label：同一源权重和相同零残差分支，主干/重构继续更新；案例结构和学习率相同。
- frozen_features：与frozen_label相同，但values中去掉标签embedding，保留key差值MLP。

各臂×三折，共9次新训练，seed42。所有源权重/BN缓冲逐项恢复；案例分支新初始化且
末层为零，stage_epoch0精确恢复原预测。已有优化器状态不存在，全部用空RMSprop
状态启动，不声称精确继续原训练轨迹。

案例分支RMSprop lr1e-4/wd1e-4；joint主干lr1e-5/wd0，重构lr1e-5/wd1e-4，
alpha.99。主干较小学习率继承前期微调协议，不开学习率/残差系数网格。
set_to_none=True。冻结参数不进入优化器，停用label表的None梯度不触发weight decay。

重构私有采样seed20261006+fold，先重放源best_epoch次后继续；三臂每步推进同一
半节点采样序列。记录BCE+10×重构MSE。冻结臂的重构在no_grad中计算，是对案例参数
无梯度的常数；joint保留其梯度。没有新标签监督项或改变原数据类别比例。

最多300次新更新、至少100次，最佳阶段轮次后100次无改善则停。按内部(AUC+AP)/2
最早最大值选轮，stage_epoch0也在候选中。记录源概率并核对初始前向，不因CUDA微小
数值误差改变stage0指标。回退只保证内部选择有原检查点选项，不保证外部泛化。

frozen_label须相对joint_label、frozen_features、源unmasked10及纯M123，三折平均
AUC/AP都提高≥.002才推进原验证；不事后改选共同更新对照。本轮不读取原验证/测试。

## 核验

拟合前逐项核对原初始化、零残差、空优化器、恢复采样器、三臂分支参数一致。
三次真实更新后检查冻结参数和BN逐位未变、joint计数增加，正负查询标签排除、
独立NumPy案例聚合、完整M1/M2/M3物理删边通过。
保存所选/最终检查点和两份优化器状态；重放检查最早最大选轮、BN计数、冻结源权重
精确相等、stage0回退及RMSprop逐参数步数。旧六对照复用已有不可变完整重放。
PLMF十个模型、冻结图/划分及发布源码只作保护性哈希核对。
