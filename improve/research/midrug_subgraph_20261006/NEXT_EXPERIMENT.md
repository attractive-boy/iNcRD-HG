# 下一步：训练内部的折外残差学习

目标仍为固定原测试集的 AUC/AP 均相对原始值增加 0.02，并保住 MDR/MDS。
只使用现有纯 miRNA/drug 输入；不能使用 lncRNA、外部序列/注释、原验证或测试标签。

本轮纯结构子图均值增加约 0.000197 AUC / 0.000597 AP，幅度不足。
主干的训练分数高于内部留出分数；这说明有拟合差距，但不能证明某种残差方案必然有效。
子图输出是联合训练的残差项，不能用它单独的 AUC 判断是否具备独立分类能力。

下一试点检验：用未见过每条查询标签的主模型预测作为残差学习的 offset，
是否比直接对主模型的训练内误差加一个分支更有效。先固定一个可审计的少量配置。

1. 保留当前三折作为开发评估的外层，每折约 6,475 个训练对、3,237 个内部留出对。
2. **在每个外层训练部分之内再划五折**。基模型对四折训练，预测第五折，拼成外层
   训练部分的 OOF logit。使用预先固定的训练轮数（如原 300 epochs），不要用被预测
   那一折的标签选基模型 checkpoint，避免把标签通过选轮传入 offset。
3. 子图残差训练只能使用该外层训练部分的标签。SG 输入按对应的内层训练图构造，
   保持当前配对正负记录删除。可复用已核验 Extractor 与纯结构 SubgraphGNN；
   不能直接使用现有 GraphCache 的外层缓存冒充内层图，需要重新缓存并做删边检查。
4. 外层留出预测用在完整外层训练部分训练的固定轮数主模型，加残差分支；主模型
   对照采用相同轮数。残差 checkpoint/少量强度只在外层内部留出评估，仍不触及
   原验证/测试集。改变训练图密度也是这个流程的一部分，不把结果解释为单因素因果证据。
5. 三折两指标平均增益都足够大，才冻结配置进入原验证确认；最终仍需原固定测试集
   seeds 42/43/44 与 PLMF 保护核验。没有达到最终验收线时保持 active。

这只是下一项待执行实验，不是已有性能结果或达标证明。
