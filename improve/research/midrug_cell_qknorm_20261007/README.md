# 原表达列注意力的固定范数查询/键对照

只用原 miRNA/drug 属性与原训练标签；无 lncRNA、细胞注释、新权重或外部数据。
最终标准不变：原 MiDrug 测试种子 42/43/44 均值 AUC≥0.9733929274、
AP≥0.9336833737；PLMF MDR/MDS 不下降。

## 具体依据

前轮 dot-attention 的 drug_rec10 内部 AUC/AP 为 .953622731/.913789501，
未通过冻结门槛，不作事后晋级。其注意力有效列数约 938/938，切换真实/平均
药物查询的平均概率变化约 7.48e-9。原表达列并不完全相同。
本轮 precheck.py 在已选定的六个前轮重建检查点上检查初始化/训练后向量范数、
训练配对得分的列间标准差及训练 BCE 梯度。没有新拟合或新留出集打分。
该诊断不能单独证明衰减正则是唯一原因，亦不证明注意力变尖锐就能改善分类。

## 唯一机制变更

全部原 938 列的 token 构造、值向量、readout、零初始化投影和主干均沿用前轮。
将 `q·k/sqrt(32)` 改为 `sqrt(32) * (q/max(||q||,1e-8))·(k/max(||k||,1e-8))`。
归一化分别沿每个查询/键的 32 维特征执行；mean 臂先对原 216 药物查询取均值，
再归一化。固定 sqrt(32) 使各向同性随机单位向量点积的得分方差约为 1；
不是从指标或熵调出的温度。范数高于 epsilon 时，正比例缩放任一查询或键
不改变注意力。这消除范数收缩对点积幅度的直接影响，但不阻止方向变得相同。

保持所有优化器、学习率、衰减、维度、完整列数和重建权重 10。
只运行 normalized drug_rec10 与 normalized mean_rec10 各内部三折，seed42，
共六次新拟合。保留前轮 dot drug_rec10/mean_rec10 各三折及纯 M123/unmasked10
各三折为 12 个不可变旧重放对照，不将它们计作本轮新拟合。

主干 RMSprop lr1e-4/wd0；列分支与投影 lr3e-4/wd1e-4；
重建 lr1e-4/wd1e-4，权重 10 前 50 轮线性爬升。
max800/min300/patience200，按内部 (AUC+AP)/2 选轮。
唯一候选 drug_rec10 相对纯 M123、unmasked10、旧 dot drug_rec10、本轮 mean_rec10，
三折平均 AUC/AP 都须增加至少 .002，才允许下一阶段冻结原验证。
旧 dot mean_rec10 作为机制背景报告，不参与另行候选选择。
不自动追加头数、宽度、衰减或温度搜索。

## 正确性与后续诊断

继承前轮逐列/逐配对独立 float64 参考，但使用直接平方和开方实现归一化，
核对全部参数梯度、列置换梯度及分块等价。额外检查查询/键正比例缩放不变性、
零向量边界有限性，以及合成非均匀列上对药物查询的敏感性。
真实非零投影训练仍核对原主干初始化、所有分支梯度、BN 一次、留出标签翻转、
完整 M1/M2/M3 物理删除。每个新检查点重放、检查选轮及损失、删除重建解码器等价。
所有列计算仅依赖原属性和参数，不读取支持标签；原物理删除公式保持适用。

冻结选择后再进行零投影、切换 drug/mean 查询和仅反转背景列的干预。
这些干预不撤销联合训练，注意力分布不作为生物学或因果证据。
PLMF 10 个既有检查点、冻结图/划分与发布源码全部哈希保护。
