# 补全概率的完整梯度

上一轮图条件补全已完成18次训练和24次检查点重放，soft_rec10未同时超过
direct_rec10、uniform_rec10或unmasked10。本轮仅检验停止梯度这一选择。
原版本保留在 ../midrug_graph_completion_20261006，不修改既有代码或结果。

前向仍使用原第一层GeneralConv、同一个rank32预测器、精确删除查询的端点表示
和预测行/列、两条观测正边加一条未观测边、同一个零初始化残差头。
仅去掉计算补全概率与路径特征的no_grad，使关联BCE可通过路径权重更新预测器
与共享第一层。该公式由已归档函数的__wrapped__直接复用，源码哈希固定。
普通推理的torch.no_grad仍有效，不在内部重新启用梯度。

这不是NCNC官方停止梯度实现的复现，也不算新的架构家族。概率是学习的权重，
不宣称校准。对查询r,d，第一层仅两个端点改变；中间缺边权重不变，左/右缺边
分别使用修正行/列，因此完整梯度也必须与物理删图后独立枚举保持一致。

固定两配置full/full_rec10×原训练内部三折，共6次拟合、seed42。
除了补全梯度，其余配方与上一轮一致：辅助BCE恒为0.1；原重建0/10、前50轮增加；
RMSprop lr1e-4/alpha.99，主干wd0、分支/重建wd1e-4；最多800轮，至少300轮，
patience200，以内部(AUC+AP)/2选轮。没有增加调参或去掉辅助监督的变体。

各配置必须对匹配的停止梯度soft、direct、uniform，以及纯M123和unmasked10，
两个指标的三折平均增益均≥.002才推进原验证。旧对照复用已审计的检查点、
原始概率、配对/标签/索引及源码哈希，不重新拟合旧对照。

只用原miRNA/drug输入，无lncRNA、外部数据、注释、序列或新预训练权重。
最终仍要求原测试seed42/43/44均值AUC≥.9733929274、AP≥.9336833737，PLMF两集不降。
此前固定概率混合上限只针对那56个内部预测，不是这项新训练或原测试的上限。
