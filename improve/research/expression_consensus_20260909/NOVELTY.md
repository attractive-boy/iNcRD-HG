## 当前候选的具体区别

以原始表达测量的细胞系列作为可重采样单位，在训练拟合的共同 PCA 坐标下量化表示波动；同时重算同一条边在互补细胞系中的 Kendall 相关支持。把由同一测量来源得到的可靠性用于两个位置：保留入边总量的边收缩，以及不构造节点间负例的选择性预测一致性。

这里可能形成贡献的是“测量复现性如何指导传播与不变性约束”的任务化机制及其证据，而不是重采样、边权、自监督三个模块本身。文献中没有在本次定向检索里找到完全相同的组合，不能据此断言它在全球文献中不存在。

## 要通过的对照

1. `reliable_edges − abs_edges`：复现性需比原相关强度提供更多可用信息。
2. `consistency_reliable − consistency_uniform`：选择性需超过普通一致性正则化。
3. `joint − joint_shuffled`：真实可靠性与节点/边的对应关系需有价值。
4. `joint − pca`：联合方法需超过当前已经改善的输入基线。
5. 新划分和按药物排名：全局随机边指标的提升不能代替生物学筛选能力。

前四项已预先写入正式实验方案。按药物排名作为额外诊断，不参与选模。若可靠性对照没有获益，将如实判为该机制尚未得到支持。

## 已知限制

- 随机互补细胞系不等于癌种或干预环境；当前不支持癌种特异性或因果不变性表述。
- 视图共享 PCA 基底，不是统计独立样本。可靠性分数不是后验置信度或置信区间。
- 输入核对发现节点可靠性与 PCA 范数相关（Spearman 约 −0.41 至 −0.61），不能自动将可靠性解释成全新的生物学信息。若初步结果通过，应补充范数匹配对照。
- 现有相似边的收缩因子中位数约 0.955，绝大部分边本来已较稳定，因此边可靠性部分的可用增量可能较小。
- 所有新处理沿用已有转导节点属性；不声称已经完成严格归纳冷启动评估。

## 第二轮：诊断上下文多实例建模

第一轮联合可靠性机制未通过，随后测试以来源诊断分组的表达视图作为实例，以全局 RNA–drug 关联作为 bag 标签的共享 GNN。具体设计见 `../../CELL_CONTEXT_MIL.md`。它将“所有视图一致”的约束改为平滑的部分上下文支持假设，必须分别超过均值池化和同大小随机分组。

多实例学习和 log-mean-exp 聚合都是已有方法。在药物/化疗反应预测中也有直接先例，例如 [Deep multiple instance learning for predicting chemotherapy response in non-small cell lung cancer using pretreatment CT images](https://doi.org/10.1038/s41598-022-24278-3)（2022）；其输入是 CT 图像，不能据此判定本实验的表达上下文构造完全相同，也不能因模态不同就宣称首创。定向检索结果保存在 `multiple_instance_prior_art.json`。

该第二轮是同一验证划分上的自适应探索。若没有超过相同输入的均值聚合与随机分组对照，应保留为负结果，不以癌种上下文或多实例名称包装成有效创新。
