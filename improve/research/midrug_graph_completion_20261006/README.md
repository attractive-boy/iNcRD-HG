## 图条件预测器与查询修正

从原M123共享的第一层GeneralConv取激活后状态hm/hd，经类型专属
LayerNorm→Linear128→LeakyReLU→Linear32，再缩放内积加两侧特征偏置打分。
训练辅助BCE权重为0.1，且辅助logit也必须使用查询删边后的两个端点状态。
不能把包含目标正边的第一层状态用于该正例的辅助监督或直接预测。

删除(r,d)只改变第一层的两个端点；其他节点第一层状态不变。具体为
hm_q=LeakyReLU(pm[r]−A[r,d]*message_d(d)/n_rel_m)，药物端对称。
该修正在激活前施加，保留消息偏置和关系均值。预测器只有逐节点变换，没有跨节点
归一化，所以变化仍只影响预测矩阵的第r行、第d列。

仍只允许r—j—i—d路径中两条是观测正边，第三条是未观测边，i!=r、j!=d。
令K为训练观测掩码。中间缺边使用P_full[i,j]，因为两中间节点都不受查询删除影响。
左缺边使用修正hm_q与全体hd生成的P_row[j]，右缺边使用全体hm与修正hd_q生成的P_col[i]。
全局P_full不能直接代替这两个修正行/列，否则会间接包含当前查询的图消息。

左缺边权重：W_left[j]=(A^T A)[d,j]−A[r,d]*A[r,j]，随后置W_left[d]=0。
右缺边权重：W_right[i]=(A A^T)[r,i]−A[r,d]*A[i,d]，随后置W_right[r]=0。
各自与未观测掩码及P_row/P_col点积。中间缺边使用原矩形包含排除恒等式。
所有路径累积用float64；即使删除记录使K[r,d]解除，它也被端点排除规则隔离。
没有枚举query×miRNA×drug张量。

直接查询logit与三个log(1+加权路径数)进入4→64→1残差头，末层零初始化。
补全概率停止梯度；共享第一层和预测器通过直接预测/辅助BCE学习。
这是停止梯度的训练定义，不声称等于穿过补全概率的完整导数。
为保持发布代码不变，分支另算一次原第一层；原M1/M2/M3和编码器图保持原实现。
