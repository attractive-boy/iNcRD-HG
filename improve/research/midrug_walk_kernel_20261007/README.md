# 查询子图的逐节点属性匹配图核

最终目标仍为原测试 seeds42/43/44 均值 AUC≥.9733929274189016、AP≥.933683373732677，
PLMF MDR/MDS 两项不下降。无lncRNA、外部数据、注释、序列或新权重；只在原训练内部三折开发。

## 根据和机制差异

复用[MoSE指定章节核读及适用性检查](../midrug_post_head_literature_20261007/READING_NOTES.md)。
MoSE正文端点图核为 sᵀ T^p s，T=H⊗A。本轮唯一候选在每步乘以当前位置的属性匹配S，
即沿完整路径匹配节点，明确不同于只比较两端的公式。不是MoSE整篇复现，不采用其
匿名游走抽取、专家路由或负载正则，也不继承论文条件表达能力结论。

为隔离核机制，保持原sg1_cov的一阶查询子图抽取：先删除查询记录，最多各16个miRNA/药物，
根节点、20维结构特征、排序和原缓存完全相同。局部分支只使用MiDrug及反向正边，
不使用缓存负边。MiMi/DrugDrug完整相似关系仍在M123主干里；不把局部分支称为完整异构图。
本轮无随机游走采样；若后续改抽取，必须作为另一个独立实验，不能混淆本轮归因。

原属性经各自LayerNorm+Linear16，加结构Linear20→16，再逐节点LayerNorm。
8个隐藏图，每图2个miRNA和2个drug原型，16维可学习属性。原型与输入节点同类型才匹配，
S=sigmoid(dot/4)，异类型和padding为0。隐藏图只有跨类型边，softplus参数并对称构造；
原子图和隐藏图均用 D^-1/2 A D^-1/2（度数至少1）归一化，无自环。

令T=H⊗A，v0=s，所有臂共有K0=sᵀs。
pathwise/fixed: vp=diag(s)T vp-1，Kp=1ᵀvp，p=1,2,3。
endpoints: vp=T vp-1，Kp=sᵀvp。
两者K0/K1相同，p≥2的差别是路径中间节点匹配；不是仅修改读出权重。
no_edges使用恒等T，所以Kp=sum(s^(p+1))，仍保留输入的距离/度结构特征，
因此只称“无邻接传播”，不能称“无结构信息”。其隐藏边参数冻结且不进入有效计算。
每个核除以4×有效子图节点数，log1p后将8×4个值输入32→64→1头，末层零初始化。
fixed冻结隐藏边初值，原型属性/投影/头仍可学习；三者有效容量不完全相同。

## 固定15次拟合和选择

pathwise（唯一候选）、endpoints、fixed、no_edges、mpnn × 三折seed42。
mpnn是原sg1_cov局部GNN（hidden32、3层、原0.1 dropout），但在本轮相同已选源主干上
只训练分支；它不是历史joint sg1_cov训练轨迹的重跑，也不与核臂参数量/随机性完全匹配。
四个核臂相同初始参数；全部恢复原unmasked10所选完整状态；原M123/重构参数和BN缓冲冻结，
仅subgraph有效参数学习。新增logit初始为零，stage0恢复源预测；不复用前轮反馈权重。
BCE，RMSprop lr1e-4/alpha.99/wd1e-4，set_to_none=True；max300/min100/patience100，
包含stage0的最早最大内部(AUC+AP)/2选轮。无核臂dropout，不更改mpnn的既有dropout。
保存所选/最终状态、优化器、曲线和预测。原源已经在同一内部留出选轮，本轮非独立验证。

pathwise只有相对control、unmasked10、endpoints、fixed、no_edges、mpnn的三折平均
AUC和AP均≥+.002才进入原验证。不能事后换候选、核步数、抽取大小或阈值。
最终双+.02及PLMF保护要求不变；开发门槛不等于完成目标。

## 检查

独立逐路径枚举与Kronecker产品、float64输入/隐藏图梯度检查、K0/K1等价与p2/p3差别，
节点置换不变以及同度异图的有限异质属性例子。该例子不是通用表达能力证明。
真实数据逐查询缓存与删除监督记录重新抽取逐项相同；同参数完整M1/M2/M3物理删图，
正负查询、逐查询批次、留出标签翻转、真实梯度和固定状态检查。
训练后所有所选模型重放、最终状态及逐参数优化器步数审计。
选择冻结后可报告训练指标、末步曲线、核分量与参数变化，不能按诊断重选。
