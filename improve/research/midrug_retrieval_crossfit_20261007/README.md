# 案例分支的折外与训练内offset匹配对照

最终验收仍为原MiDrug测试seeds42/43/44均值AUC≥.9733929274189016、
AP≥.933683373732677，且PLMF两集不下降。只用原miRNA/drug，原训练三个内折；
不使用lncRNA、外部数据、序列、注释或新权重。原验证/测试不参与本轮开发。

## 依据及已有负结果

冻结主干的案例分支仅有内部+.000395/+.000173收益，训练拟合改善较大。
其训练offset来自已经见过这些监督样本的源模型。这个差距不证明标签错误或性能上限。
旧midrug_crossfit_20261006已有纯M123、固定300轮、5个嵌套折的子图残差实验，
未超过较强优化对照，不支持OOF残差优于独立分支；本轮不能称OOF家族首次尝试。

与旧实验的区别：基模型保留unmasked10重构；残差使用近期已审计的原属性案例value；
三个残差臂共享全部案例key、标签库、预测器、推理offset，只改变训练offset或标签value。
不重新选邻居数、宽度、学习率、残差系数。

## 阶段一：18个固定基模型

每个内折训练部分再按StratifiedKFold(5,shuffle=True,seed20261006+fold)分区，
沿用旧OOF实验的确切嵌套索引。训练五个4/5基模型和一个完整训练基模型，共18次。
均为原M123+unmasked10，seed42、固定300轮，无被预测折指标选轮或早停。
RMSprop lr1e-4/alpha.99，主干wd0，重构wd1e-4；重构权重10前50轮爬升，
私有半节点采样seed20261006+fold。原查询正边始终精确删除。

为每个完整内折训练样本生成恰好一个OOF logit，来自没有该样本及标签的基模型。
完整300轮模型同时产生训练内logit和内折留出logit。三个数组按原样本索引对齐。
注意：OOF基模型训练数据和图更稀疏，推理使用完整基模型；这个密度差异仍存在，
不能把比较解释成只移除参数中的单个标签影响。案例分支的图外原属性key及案例库
在三臂始终相同，避免旧子图分支本身随嵌套图变化的额外混杂。

## 阶段二：9个案例分支

- oof_label：BCE(OOF logit+delta,y)，唯一可推进候选。
- insample_label：BCE(完整模型训练logit+delta,y)，其余相同。
- oof_features：OOF offset，但移除label embedding，保留key差值value。

各配置×三折共9次，案例分支完全复用label_retrieval的32近邻、64维key和值结构。
三组从同一零残差初始化出发，完整300轮基模型全部参数/缓冲冻结，主干eval。
训练只反向更新案例参数；案例库仅当前内折训练配对，正负自身查询均排除。
原数据的零标签不解释为药物敏感性。先前源模型没有使用原验证/测试。

案例RMSprop lr1e-4/alpha.99/wd1e-4，set_to_none=True。最多300次更新、至少100、
耐心100，按内部(AUC+AP)/2最早最大值选轮，完整基模型的stage0也在候选中。
记录训练BCE，冻结基模型的重构损失不影响案例梯度，故不重复计算该常数。

唯一候选须对insample_label、oof_features、完整300轮基模型、既有纯M123及既有
已选unmasked10的三折平均AUC/AP全部提高≥.002才可推进。不以较弱固定轮次基线
替代已选强基线，不事后改选对照。最终原测试双+.02门槛保持不变。

## 核验

嵌套索引与旧已审计缓存逐项相同，训练/预测/内部留出互不重叠，OOF覆盖恰好一次。
18个基模型固定轮次、BN、损失与所有缓存logit独立重放；构图只含相应训练正边。
阶段二核对零残差、固定推理base、只有所声明训练offset不同、原主干/缓冲逐位不变、
案例自身标签不影响预测。九所选模型重放，并核对阶段0及优化器实际更新步数。
六个既有强对照引用不可变完整重放。PLMF十个模型和发布路径继续保护性哈希复核。
