# 从原重建检查点启动的匹配微调

原 MiDrug 测试 seed42/43/44 均值 AUC≥.9733929274、AP≥.9336833737，且 PLMF 两集
不下降，仍是最终目标。本轮仅原训练内部三折，无 lncRNA、外部数据/注释或新权重。

## 依据与本轮问题

训练量研究显示重建正则化有稳定但小的收益，并缩小训练/留出差距。九个已选
重建检查点的规定采样步未见原始梯度反向冲突，加权重建梯度范数较大；
这不证明重建损害泛化，也不支持直接进行冲突投影。
本轮检验：在这些表示已经训练好后，转向关联任务微调能否改善排序。

每折固定从原 unmasked10 的已选检查点初始化全部参数/缓冲，包括重建解码器。
三个分支使用相同输入、初始化、原 M1/M2/M3、采样顺序和优化器设置：

- keep：继续保持辅助权重10，是额外训练/优化器重启的匹配对照。
- off：辅助权重始终0，仅按关联 BCE 更新。
- decay：第t次更新权重为 `10*max(0,1-t/100)`，第100次起为0。

各分支仍计算辅助 MSE 作为诊断。权重为0时在 no_grad 下计算它，不更新解码器。
无新推理模块或特征，原推理模型保持相同结构；所有源权重来自原训练数据。

## 冻结微调协议

主干和解码器 RMSprop lr1e-5（原学习率的1/10），alpha.99；主干 wd0，解码器 wd1e-4。
使用空的 RMSprop 状态重新启动。原检查点没有优化器状态，本轮只恢复权重/缓冲，
不能称为精确继续旧训练。较小学习率在本轮训练前固定，不作速率搜索。
辅助节点采样私有生成器仍为 seed20261006+fold；重放至源 best_epoch 后继续。
三组每轮都推进相同的采样器，关闭辅助损失不会改变之后的采样顺序。

三个分支×三折，共九次新微调。seed42；最多300次新更新、至少100次，距最佳
阶段轮次100次未改善则停。按内部(AUC+AP)/2选轮，并把共同的源检查点作为
stage_epoch=0纳入选择；平分保留较早轮次。这只保证内部选择允许回退，
不保证新数据性能。源检查点本身已经用同一内部留出集选轮，不是新的独立验证。

候选为off/decay，各自需相对纯M123、源unmasked10及本轮keep，三折均值AUC/AP
都提高≥.002，才允许后续冻结原验证。按对全部规定对照的最小双指标平均增益
选择候选；不在keep成为最好时事后改称关闭/衰减策略成功。最终双+.02标准不变。

## 核验和报告

初始检查逐折核对三个分支的源参数/缓冲及保存概率一致、优化器状态为空；
核对权重日程、采样器状态一致、一次实际更新的有限梯度和BN增加一次，
确认off只更新关联路径，完整正/负查询物理删除通过。
训练后九个检查点重放；BN计数须等于源best_epoch+阶段best_epoch，stage0回退
须逐项等于源参数/缓冲。保存最终及选中优化器状态，以验证微调实际步数。
六个既有纯M123/unmasked10对照复用已有完整重放并核查元数据/输入/概率哈希。

冻结选择后，在相同训练配对上报告BCE、重建MSE、参数偏移及训练/留出差距，
不按诊断重选候选。去除重建解码器不应改变预测。PLMF十个检查点、冻结输入
和发布源码继续保持哈希保护。

## 关闭边界修正

原轮审计发现：默认zero_grad保留零梯度，使decay第100步仍更新解码器。
本版本显式set_to_none=True，并核对99→100→101步参数及优化器状态。
原轮数据保留于 ../midrug_reconstruction_finetune_20261007/failure_manifest.json。
重跑相同9组以统一修正后的清梯度协议；学习率、目标、采样和选轮均不变。
