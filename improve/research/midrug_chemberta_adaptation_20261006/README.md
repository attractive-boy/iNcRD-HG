# 原版 ChemBERTa 最后一层的任务适配

目标不变：纯miRNA、无外部数据，MiDrug原测试三种子AUC/AP分别至少
.9733929274/.9336833737，PLMF的MDR/MDS不下降。本轮不是新架构家族或LoRA创新。

## 输入与历史核对

本地已存在seyonec/ChemBERTa-zinc-base-v1，revision
761d6a18cf99db371e0b43baf3e2d21b3e865a20。只以local_files_only离线读取，
不下载新权重，不使用其他RNA、蛋白、靶点、注释或文献数据。
重新编码原216个SMILES，重现原drug_features-chemBertA.csv：原值最大误差
3.34e-6，行min-max后最大误差1.08e-6。CID/顺序及原始文件哈希一致。
这证明此次使用原输入的同一模型表示，不是换成其他预训练模型。

原代码均值包括padding。历史network_feature_inputs.py和首轮结果已经比较过
masked/unmasked pooling（当时是ChemBERTa-77M），结果不支持笼统的“去掉padding
一定更好”。本轮不把它当作新发现，也不单独重复池化网格。
midrug_molecular_encoder试过原子GNN/原子bag/固定ChemBERTa投影，均未通过门槛；
global_features也试过已池化特征的非线性修订。它们没有更新原版药物Transformer
内部的注意力参数，因此本轮检验的是**池化之前、由当前关联监督驱动的语义适配**。

## 模型与控制

冻结前五层，只缓存其最后输出。最后一层的query/value线性映射增加LoRA：
W'=W+B A，rank8、alpha8（缩放1），A按普通无偏线性层初始化，B为0。
原Transformer所有权重保持冻结，dropout在训练及推理时均关闭。
非padding token均值包含原BOS/EOS。1个1146-token药物仍按原规则截到512，
不声称本轮恢复了该分子的全部结构。其余215个药物无截断。

让p0为未适配原最后一层的masked均值，pθ为适配均值，n为原行min-max：

`x_drug(θ) = x_original + n(pθ) - n(p0)`。

实现先计算括号中的差，初始差严格为0，保留原M123初始预测。
对照pooled在相同p0上施加`pθ=p0+B GELU(A p0)`，中间宽度16、B为0。
token/pooled都有24576个可训练适配参数及相同AdamW lr1e-4/wd.01；
这是参数数目/优化配置匹配，不是表达能力或计算量相等的声称。
两个方案分别比较重建0/10，共4配置×原训练内部3折=12次训练。

适配药物特征进入原GeneralConv的第一层及精确查询删边项，所有原M1/M2/M3保留。
关联图和同类型邻接不随新特征重建。重建目标仍是原始表达/ChemBERTa矩阵；
原重建初始化、取样序列与权重50轮爬升保持一致。每次主损失和重建共享一次
可微特征计算，上下文退出即清缓存，避免旧梯度图或跨更新复用。
特征仅依赖原SMILES及学习到的参数，删查询边不改变其值，所以原M1/M2公式适用。

## 效率与核验

将固定前五层的输出按真实token长度分桶，只裁掉尾部padding，再运行最后一层。
模型不对padding赋注意力，所以真实token结果与512位输入一致；已逐药物和完整
预训练模型输出核验，最后一层独立重放误差为0。缓存是原药物的中间特征，不含标签。
训练后缓存和预训练权重不能被检查点覆盖；重放时重新从已核验文件构造。

初始校验包括：独立合并矩阵的LoRA输出/梯度、非零LoRA与合并最后一层的等价性、
初始主干/重建/预测一致、全部可训练适配参数有限非零梯度、冻结权重零变化、
特征上下文正确复用/清理、完整M123物理删记录与留出标签翻转不变。
后续逐检查点重放、批次/逐查询核验、重建解码器移除、冻结权重与输入哈希再核对。

主干和重建仍用原RMSprop设置；仅24576个新增参数用AdamW。
最多800轮，至少300轮，patience200，按内部(AUC+AP)/2选轮。
token候选须相对纯M123、unmasked10及同重建设置pooled对照的两指标均值
各增加至少.002才可进入原验证。最终+.02要求不变，不用原测试选型。
