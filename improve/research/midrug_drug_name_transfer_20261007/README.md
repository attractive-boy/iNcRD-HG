# Direct association transfer through frozen drug-name similarity

The previous name-input model completed9fits and passed all replay/deletion checks, but failed its frozen gate. Its text branch was active (fixed-model probability changes around.002) and gave only tiny gains over permuted names. This experiment asks a different question about the same frozen covariate: can spelling similarity directly summarize observed training associations? It does not retune ngrams or claim retrieval is a new family; prior group/scaffold/profile/retrieval experiments already exist. The new input here is specifically original Drug_Name similarity, absent from those older direct-transfer models.

Use exactly the216×902TF-IDF and fixed permutation from midrug_drug_name_20261007. No vocabulary refitting. K=XX^T in float64, diagonal exactly0, no threshold/neighbor-count/power tuning. For query(miRNA r,drug d), P=sum_j A[r,j]K[j,d], N=sum_j B[r,j]K[j,d], using only current-inner-training positive and observed negative pairs. Five features are log1p(P),log1p(N),P/(P+N+1),log1p(P+N),P/(sum_j K[j,d]+1). Zero diagonal excludes the query from both positive and negative support. Zero labels are observed dataset classes, not asserted biological inactivity.

These five values append to the existing M3 pair-channel input and use its training-derived mean/std. Added columns of pc.0.weight initialize to zero; all original parameters and reconstruction targets are copied exactly from the same seeded unmasked10 initialization. No encoder/graph/node-feature changes occur. Physical deletion comparisons preserve the original training normalization constants, as in all prior query-exclusion checks.

Three arms: aligned kernel (only eligible), deranged-name kernel, zero kernel. All allocate the same additional five input columns. Only the aligned candidate may proceed; both mean inner AUC/AP must improve by.002 over each of permuted, zero, original M123, existing unmasked10 and the previous aligned name-input model. The two strongest older references are not replaced with weaker controls. Same three frozen original-training folds,seed42,800max/300min/patience200 and earliest maximal mean(AUC,AP). RMSprop1e-4, original base/expandedM3 wd0, reconstruction wd1e-4, reconstruction weight10 with50epoch ramp.

Preparation and initial checks cover frozen vocabulary hashes, CID order provenance, exact zero diagonal, symmetry, independently summed neighbor support, positive/negative own-label exclusion, heldout-label invariance, original-model initial equivalence, finite/nonzero new-input gradients and complete physical deletion. All nine selected checkpoints must replay before the gate is applied. No original validation/test or external data is loaded. Only miRNA and drug; PLMF unchanged. The original three-seed frozen-test target remains AUC>=.9733929274189016 and AP>=.933683373732677.
