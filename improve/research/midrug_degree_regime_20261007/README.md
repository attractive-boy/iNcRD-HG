# 共享M123与支持度条件残差专家

原测试AUC/AP同时绝对+.02、PLMF MDR/MDS不下降，纯miRNA/drug、原数据，目标不变。
本轮仅原训练内部三折seed42，不能以内部成绩代替最终原测试三种子验收。

## 依据及限制

预检发现：两端支持度都低组只有12–21训练正例，约60%的AUC逆序来自不同支持度组。
原M3已经含这些度信息，不主张新增信息。四个完全独立模型缺乏低支持组训练证据；
改用所有样本共享的原M123，并只给每组小型残差修正。误差异质性不保证该方法有效。
历史GraphMETRO专家（合成偏移）、16成员均匀概率平均、编码器度归一化和输入全局
路由都已尝试；本轮固定条件残差不同于这些已测实现，不声称新方法家族。

## 三个匹配分支

degree：查询正边扣除后的两端度，以当前训练查询中位数划低/高，四组单路由。
random：配对整数ID的固定仿射hash，切点仅由训练配对决定，使训练四组人数与
degree逐组完全相同。验证人数不保证相同；random不使用标签分组，不可成为候选。
uniform：相同四个专家等权输出，分离额外容量与条件路由作用，不可成为候选。

三组保留相同原M123/重构初始化及四个专家初始化。专家输入是原M123融合向量的
无参数LayerNorm，每个MLP为D→64→1、LeakyReLU.1，输出层零初始化。四路残差
按门控加到原logit；原主干始终共享，不让稀疏组独自承担完整分类。
没有路由辅助损失、重新加权标签或补采负例。random人数匹配不意味着类别数或
正例比例匹配；这是原度数含关联支持信号的结果，不将随机对照解释为单一因果变量。

主干RMSprop lr1e-4、wd0，重构lr1e-4、wd1e-4；专家lr1e-3、wd1e-4，alpha.99。
专家速率在本轮训练前固定为主干10倍，不搜索速率/宽度/组数。辅助权重10、50步
预热，私有mask seed20261006+fold，所有清梯度set_to_none=True。
最多800步、至少300，按内部(AUC+AP)/2选轮，200步无改善停止，平分取最早。
三配置×三折共9次新训练，唯一候选degree必须比纯M123、源unmasked10、random、
uniform的三折平均AUC/AP每项都高≥.002才能进入原验证。最终双+.02标准不变。

## 查询删除与核验

度门控每次从当前训练图计算，正查询同时扣两端度；random仅依赖配对ID。
训练得到的中位数/hash切点是冻结预处理常量，和原M3标准化一样装入checkpoint，
显式删一条查询记录重建图时仍用同一已训练模型中的常量；不重新训练预处理器。
验证标签不进入门控。物理删边检查含度一变零、正/零查询、完整M1/M2/M3/最终输出。
原重构模块可删而不改预测；专家是推理的一部分，不能等价删除。
选型冻结后再报告专家残差幅度、门控占比及关闭专家的诊断，不能据此重选分支。
