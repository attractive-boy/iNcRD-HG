## 1. 文献与技术扫描（2026-09，arXiv export + Europe PMC，`lit/search_xrel*.py`，结果 `lit/scan_xrel*.json`）

- 2026 年 miRNA–药物关联新文（Europe PMC 标题检索）：Router-guided dual attention + graph masked autoencoder（Comput Biol Chem 2026）、MVGSCA 谱编码 + 稀疏交叉注意力（TCBBIO 2026）、PLMF-MDA（PLoS CB 2026）、MPHGNN（BiB 2026）；再往前 GAM-MDR、GCFMCL、NASMDR、BNEMDI、MDIPA。全部是随机划分 + 新融合架构，没有一篇做溯源、组学证据或无标签池。
- 定向先验核查（标题/摘要限定）：miRNA–药物预测中用 IC50/GDSC 谱、LINCS/CMap 签名、ceRNA、基因组簇、CTD 的工作：**0 命中**；"miRNA–药物–疾病三层网络"仅 TLNPMD（2022，目标是 miRNA–疾病）与一篇多任务 GAE（2023）。arXiv 侧：pharmacogenomic/ceRNA/LINCS × miRNA 关联 0 命中；稀疏节点 + 旁信息的链路预测只有 2017 年的一篇生成模型。
- 可用技术判断：本轮所有新通道都是"标签无关旁信息/证据 → 确定性启发式 → 线性读头"的同一范式；文献里没有先验，创新点在关系来源与研究无关（study-disjoint）过滤，不在架构。

## 2. 诊断：PHL 之后残差在哪（`error_after_phl.py`、`probe_gate.py --diag`、`probe_raredrug.py`、`probe_univariate.py`；seed 42）

- **负例侧**：得分最高的负例是（热门药物，中等度数 miRNA）对（top-100 负例：药物度中位数 107、miRNA 支持度中位数 5），ctx 组贡献 +1.8 logit；按体量算，**稀有药物**（数据集里药物度数中位数只有 4）承担 59%（MDR）/ 71%（MDS）的负例损失；已记录隐藏正例只占负例损失 1.5%。
- **正例侧**：损失仍集中在支持度 0–3 的 miRNA（0.047–0.094 平均损失）；稀有药物（≤10 链接）上的正例平均损失 0.65。
- **外部关系的单变量强度**（稀疏 miRNA 行内 AUC）：看起来强的列（靶基因谱 kNN 0.87、lncRNA–药物计数 0.85）全是药物流行度代理；真正的配对相容列（疾病余弦、靶基因–签名富集）只有 0.50–0.55。这就是五类外部关系失败的原因：它们不含"这个稀疏 miRNA 和这个药物"的信息。
- **稀有药物内部排序**（支持度 ≤10 的药物，每折只有 39/60 个正例）：PHL 子集内 AUC 0.933 / 0.898，度门控（`gate:d5/d10/d20`）与逆度权重（`w:0.5/1`）在两数据集上符号相反，最大 |Δ| 0.001 → 放弃。

## 4. 三个正向改进

### 4.1 溯源补全（provenance completion）

`build_full_records.py` 生成 `data/full_{ds}/data/pair_records.pkl`（键 = PLMF 名称 × DrugBank id，效应匹配），`final2.py --variant provf / phlf`。

### 4.4 两个小而稳的标签无关证据

- **基因组簇关系**（miRBase v23.1 `hsa.gff3`，前体同链 10 kb 内成簇；PLMF 用旧命名，用去后缀的茎名映射 97%）：+0.0006 / +0.0006（MDR 4/4）、+0.0002 / +0.0003（MDS）；置换 −0.0001。
- **研究无关 GEO 组学证据**（ncRNADrug DR_GEO：耐药/敏感样本 miRNA 差异表达；DT_GEO：给药前后差异表达）：先用 eutils 把每个 GSE 映射到 PubMed id（`gse_pmid.json`），**剔除所有被策展记录引用过的系列**（73 个里 32 个被引用），剩下的才作为证据（`geo`：同向/反向 GSE 数、最大 −log10 p、给药差异 GSE 数、显著数、药物覆盖标志）。随机划分 +0.0006 / +0.0007（MDR 4/4）、+0.0002 / +0.0001（MDS）；置换 0；不过滤（geoall）并不更大（+0.0007 / +0.0003）。研究分组划分下放大到 +0.0016 / +0.0026、+0.0014 / +0.0011（§5）—— 独立实验证据在去掉同研究传递性后更有用，这是它与文献派生特征的本质区别。

## 6. 论文写法与边界

- 三个改进的叙述顺序：① 溯源补全 + 研究/语境超边（信息侧主贡献，并给出 PLMF-MDA = ncRNADrug 策展集这一数据事实）；② miRNA 旁信息关系；③ 无标签池训练（协议侧修正）。基因组簇与研究无关组学证据作为"标签无关证据超边"补充，配 study-grouped 结果。
- 必须如实写：溯源与基准同源（只用训练正例的记录 + 交叉拟合）；GEO 证据只用未被策展引用的系列，并给 geoall 对照；提升相对 base 是 +0.010~0.012 AUC / +0.011~0.015 AUPR，相对 PLMF-MDA +0.04 / +0.05；剩余误差是稀疏 miRNA 与开放世界负例，五类知识关系无效说明它们不含配对相容信息（这本身是可写的分析）。
- 单模型 / 线性读头 / 参数量 ~140 的定位不变。
