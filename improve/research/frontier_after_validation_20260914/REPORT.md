**iNcRD-HG：完成近期验证后的前沿技术再评估（截至 2026-09-14）**

还有改进空间。近期最值得检验的是 **④ 证据语义分层 → ⑬ 保留靶位点与基因身份的配对表示 → ⑨ 冻结的多模态药物编码**。中期研究应围绕“RNA 对特定基因的调节，在特定细胞状态下，如何关联药物反应”展开，整合⑤⑥③②。①⑧仍值得做，但应指定功能读出；单纯扩覆盖、拼更多表示或更换 HGT 的优先级下降。

**本轮新增的代码与数据发现**

**1. 位点的基因身份被保留在原始表中，但在当前 RNA 向量里丢失。**

[rna_functional_inputs.py](../../rna_functional_inputs.py) 的窗口表保留 `gene_id`、转录本、位点、PMID 和支持类型。miRBind 输出逐位点隐藏向量及 binding score；`assemble()` 将同一 miRNA 的所有位点取均值/SD，当前下游向量没有逐基因或逐药物的局部表示，也没有使用 binding score。

这意味着模型难以区分“该 RNA 的哪些局部功能对应当前药物的靶点”。已完成的 `target_local` 只是 RNA 通路摘要与各药物靶基因通路轮廓的均值/top-3 相似度；[实现](../../tabicl_functional_modules.py)没有使用位点隐藏向量或药物作用类型。因此，保留位点—基因对应的实验与已有 `target_local` 不同。

但可用连接很稀疏。以下覆盖在 **605×216＝130,680 个全部候选配对**上计算，完全没有读取关联标签或评价配对：

|位点集合与药物靶点矩阵|有至少一个相同基因的候选配对|占全部候选|涉及 miRNA / 药物|
|---|---:|---:|---:|
|全部窗口＋原机制靶点|2,177|1.67%|435 / 92|
|全部窗口＋扩展结合靶点|7,808|5.97%|546 / 153|
|按来源过滤窗口＋原机制靶点|2,162|1.65%|434 / 89|
|按来源过滤窗口＋扩展结合靶点|7,760|5.94%|546 / 152|

这些是输入证据覆盖，不是正例比例、测试覆盖或药物反应证据。适合先做明确子集的验证，不能预期一个直接靶点交互分支普遍提分。未覆盖候选必须保留，不能通过删掉难例提高成绩。

**2. “真实序列窗口”不等于“已证明功能抑制的窗口”。**

6,975 个窗口、546 个 miRNA、523 个基因对应 4,083 条不同的 RNA–gene 连接。按原始 `support_types` 拆分：

|支持类型分组|全部窗口|来源过滤后|
|---|---:|---:|
|有 `Functional MTI`，且没有任何 Non-Functional 标记|826|789|
|只有 `Functional MTI (Weak)`|6,093|6,093|
|只有 Non-Functional 类标记|39|39|
|Functional 与 Non-Functional 混合|17|15|
|合计|6,975|6,936|

这里的强/弱是数据库证据类别，不是结合能或调控效应大小。全部窗口中有 56 个带某种 Non-Functional 支持，但它们不是 56 个真实阴性 RNA–药物配对，也不是已证实的标签污染原因。当前程序将其作为编码输入，并未将这些支持类型直接变成关联正标签。

改进机会在于分别保留支持类别和冲突，不宜一律平均，也不宜把少量非功能标记机械删除后宣称“数据清洗提分”。单独使用强功能窗口会显著降低覆盖，必须做覆盖匹配对照。

此前因验证/留出 PMID 重合而排除的 39 个窗口，与这里“只有 Non-Functional 标记”的 39 个窗口是不同集合，交集为零。

**3. 药物作用记录可用，但作用粒度需要审查。**

本地 [drug_to_gene.tsv](../../results/tabicl_pathway_inputs_20260913/drug_to_gene.tsv) 已保存 `action`、`mechanism`、`target_type`。共有 654 条机制记录，对应 93 个药物、365 个基因、645 条不同 drug–gene 边；当前模型主要使用二值矩阵。记录包含 563 条 INHIBITOR，以及激动剂、拮抗剂、通道开放剂、降解剂、稳定剂等类型。

其中只有 **136 条记录是 SINGLE PROTEIN**，对应 69 个药物、84 个基因、135 条边。其余涉及复合物、家族等；复合物的药物作用不能未经核查就赋给每个基因成员。即使限制为单蛋白，`MODULATOR` 也不提供明确激活/抑制方向。

在来源过滤位点上，单蛋白机制连接支持 844 个候选配对；再限强功能支持为 336 个。这是机制原型的可用起点，同时说明它暂时很难覆盖整个任务。结合实验扩展的 IC50/Ki/Kd 也不能自动变成抑制方向。

**4. 数据就绪程度决定哪些方案算“快速”。**

现有 216 个药物都有 SMILES 记录，CID 集合与固定药物字典对齐；本轮没有运行新药物编码器，当前 TabICL 环境没有 RDKit，故未声称完成新的分子解析或预处理兼容性验证。

当前 RefSeq 缓存是 FASTA 和请求元数据，缺少 CDS/UTR 注释；不能直接将这些位点标为 3′UTR，更不能确定原实验优势异构体。当前 lncRNA 缓存是 PARNET 局部隐藏表示及权重，没有具名 RBP 的头部占据预测；超长转录本仍采用匹配采样，不能当作全长编码的复现。已有 DepMap 表达和细胞系元数据也不等于已具备 CRISPR dependency 或药物扰动读出；在已检查的数据目录中没有定位到可直接使用的相应矩阵。

可复核审计：[LOCAL_INFORMATION_AUDIT.json](LOCAL_INFORMATION_AUDIT.json)、[ACTION_SCOPE_AUDIT.json](ACTION_SCOPE_AUDIT.json)、[数据就绪与缓存字段](DATA_READINESS_AUDIT.json)、[逐药物覆盖 CSV](local_site_drug_coverage.csv)。矩阵统一使用 21,318 基因的上下文字典，并校验冻结输入哈希；没有按不同字典的列号直接混合矩阵。

**最值得先做的三个有限实验**

**Q1：保留位点证据语义，复用现有缓存。**

以当前固定参考和功能均值/SD 分支为对照，将位点分为“强功能支持、弱功能支持、只有非功能支持、混合支持”四个通道，记录各通道的覆盖和数量。用固定总维度压缩各通道的均值/离散信息，保持下游预算；不把新增维度当作证据语义的贡献。

需要两个关键对照：只提供数量/覆盖的简单统计，以及保留每个 RNA 的覆盖、支持类型和位点数分布的表示打乱。若尝试强功能子集，须在相同实体子集和相同候选集合上比较，再报告全体候选结果。来源任务使用已过滤的 6,936 个窗口。

这能回答“当前混合池化是否抹掉证据差异”。少量 Non-Functional 窗口不是已经确认的性能瓶颈；如果分层表示不能超过统计/打乱对照，就停止扩大此分支。

**Q2：让 RNA 的局部表示随当前药物改变。**

对 RNA r 与药物 d，只聚合基因属于该药物靶点集合的位点向量，并保留无匹配掩码、匹配基因数和支持类型。第一版用固定均值或简单低秩交互即可。原机制靶点与新增结合靶点分通道；作用未知和复合物关系分别保留，暂不强行赋符号。

一个有辨别力的对照是：**在同一 RNA、同一证据通道内交换位点向量与基因的对应**。这样各通道和全 RNA 的均值/SD、位点总数、RNA–gene 拓扑和配对覆盖保持不变，但“哪段位点信息对应哪个药物靶基因”被打乱。须报告实际可交换比例；只有一个位点或同一基因的组不能提供有效错配。另可用现有度数保持的 drug–gene 错配对照检查基因连接贡献。

先比较当前全 RNA 池化、简单的药物特定池化和上述打乱，限制为同一输入维度/预算。只有真实对应关系稳定胜过对照，才值得加入交叉注意力或 gene 节点。解释时同时报告约 6% 的全候选覆盖边界；没有共享靶基因不能当作不存在调控作用。

该试验主要针对 miRNA 的现成位点数据。lncRNA 不能直接套用 miRNA 靶位点逻辑，也不能因为 miRNA 子任务有效便宣称两个 RNA 任务共同改进。

**Q3：一次冻结 M2UMol 的药物表示比较。**

[M2UMol，Nature Communications 2026](https://doi.org/10.1038/s41467-026-69302-6) 使用模态专属适配器，把 3D、文本和生化知识迁移到 2D 分子编码器；下游可以只提供结构。它比重新补齐所有药物注释更适合作为有限的表示对照。公开 README 已提供 `M2UMolencoder`、冻结编码示例和 `pre-trained_M2UMol.pt` 链接；本轮只核验文档，没有下载或执行权重。

固定 RNA、图特征、候选配对与分割，将现有 ChemBERTa/指纹与 M2UMol 压到相同维度，只在训练/支持侧拟合投影。先做一种预先指定的 M2UMol 表示，不连续搜索多个融合权重；保留相同覆盖和简单分子描述符对照。接入时需核查金属、多组分和大分子的预处理兼容性，所有未覆盖药物保留。

这里“生成的文本/生化表示”是模型从结构推断的向量，不是新测得的功能数据。预训练用到 DrugBank 的机制、临床描述和靶点信息，必须披露来源与潜在证据重叠；仅在下游关闭文本输入不能证明预训练知识与评价来源完全独立。

[SELFormerMM，Bioinformatics 2026](https://doi.org/10.1093/bioinformatics/btag451) 可作备选。它的全文消融显示，增加单一模态有时优于四模态全加，缺失 Text/KG 会影响结果；这支持做覆盖和信息量控制，也削弱“更多视图一定更好”的预期。没有必要先复现其大规模预训练。

三个实验都应沿用既有接受标准；对最终共同参考的替换不能因单一子任务或个别指标上涨而放宽条件。它们属于新候选，不是本轮已执行结果。

**中期最有研究价值的三条技术路线**

**A. 功能依赖性：明确基因在当前细胞中是否重要。**

[FORGE，Nature Communications 2026](https://doi.org/10.1038/s41467-026-73977-2) 用共享稀疏因子同时解释基因依赖性和 IC50，说明值得引入的是功能读出。你的下一步可先对齐单蛋白作用较明确的一组药物、其 RNA 靶基因和准确细胞系，再加入 CRISPR dependency。

先比较“表达＋靶点”与“表达＋靶点＋dependency”的稀疏线性/双线性模型，再与同信息图模型比较。dependency、表达、药物响应分别拟合/处理缺失；不要把缺失值填作无依赖，也不要把不同尺度的 GeneDependency 概率和 GeneEffect 分数混用。相关筛选、投影和超参数必须只在训练侧完成。

基因敲除、RNA 抑制和药物作用的强度、方向与时程不同，三个符号相乘不能直接推出耐药。[SLIM 预印本](https://doi.org/10.64898/2026.08.07.743481)的摘要提供了紧凑 STRING 表示＋闭式双线性 ridge 的低成本思路，但尚不能作为本项目能提高性能的证据。

**B. miRNA：从“有位点”推进到“位点在该状态可用，并影响抑制”。**

[miRBind2，Bioinformatics 2026](https://doi.org/10.1093/bioinformatics/btag410) 的结合预测和 3′UTR repression 是不同任务。后者训练于 miRNA 转染后的 mRNA fold change，测试 Pearson 约 0.30、AUC 约 0.60；它的结果不支持把所有 binding score 当成可靠调控强度。

[MIRNAPEX，RNA 2026](https://doi.org/10.1261/rna.080990.126)则提示，同一个基因表达量下，3′UTR 异构体和 APA 可改变位点可用性；miRNA 表达变化还可能反映靶位点与降解机制变化。正文明确 APA 的总体增量有限、对不同 miRNA 不一致，且分析不能确定因果方向。

因此，优先补正确转录本、UTR 区域、细胞内异构体使用与局部可及性，而不是马上给全部 RNA 做昂贵结构预测。先在一小组转录本可核实的对象上比较 binding、repression 与状态条件化读出，保留同输入序列模型、基因/状态打乱和简单均值对照。

**C. lncRNA：具名 RBP 组成与定位，单独验证。**

[RBP occupancy composition，IJMS 2026](https://doi.org/10.3390/ijms27125593)在长度和结合数量之外，研究“具体哪些 RBP 结合”对核/胞质定位的增量；在更完整的协变量控制后仍有预测信息，跨 K562→HepG2 AUC 约 0.71。其优点是使用独立定位读出、线性基线和染色体分组，而不只是展示复杂网络。

这是一项只有两个细胞系的计算重分析。特征来自实测 eCLIP 对整个基因座（含内含子）的覆盖；当前 PARNET 成熟转录本隐藏向量不等同于这些特征。PARNET 预印本中的染色质解离半衰期任务又不同于核/胞质定位。本地历史公开权重与兼容提交已归档，但未证明等同于论文各项最终实验配置。

可先检查公共检查点的 RBP 输出对应，或取可对齐的实测占据特征，用独立定位数据比较具名 RBP、当前隐藏向量均值与长度/GC/表达基线。功能读出有效后再接药物任务。

**负样本、来源和多任务应该怎样配套**

[miRBench，Bioinformatics 2025](https://doi.org/10.1093/bioinformatics/btaf233)证明 miRNA 类别频率可以形成预测捷径。本地已有强药物频率信号，因此⑭应贯穿实验，而不是仅增加一种 hard-negative sampler。高分未标注配对也可能是真正正例，不能直接当可靠负样本强化训练。

PU 学习可以比较，但须声明正例收录机制及先验假设。[PULSNAR](https://doi.org/10.7717/peerj-cs.2451)针对非随机收录的思路有相关性，本轮仅核读摘要。[BIN-PU，Bioinformatics 2026](https://doi.org/10.1093/bioinformatics/btag067)的全文还提醒了一个具体问题：其内部交叉验证含计算产生的伪标签，外部有真阴性的 CYP 验证是另一层证据。不能复制伪标签评价，然后据此声称解决了真实阴性缺失。

可保留旧关联任务作工程对照，同时报告药物宏 AP、低频药物/未见实体结果以及来源验证；各指标必须标明对应的候选分布。药物内排序值得独立比较，但若“负类”仍是未标注，它评价的是已收录关联的排序，不能直接校准成真实作用概率。

已有来源分组应继续沿用，并在训练侧按来源交叉验证选择配置。PMID、原始记录和包含结论的 Support 文本主要用于分组、核验与误差追踪，不应把直接复述标签的文字输入预测器。来源对抗也不能无条件删除癌种信号：[FourierDrug](https://doi.org/10.1093/bioinformatics/btag276)使用真实药敏标签和编码后潜在空间的非对称约束；数据库“耐药株中表达升高”不满足同样的敏感/耐药解释。

精细多任务的最小语义设计可包含：收录关联、表达差异描述、经核实的 RNA 干预药敏，以及 RNA–gene 抑制或定位等辅助功能。各任务独立记录目标定义、类别含义和缺失 mask。没有干预、终点或细胞状态的记录不能通过共享头自动升级成干预标签。

**表外更值得补的内容：机制验证与问题定义**

比继续加一层注意力更有论文价值的验证，是从独立实验/论文整理一组带条件的 RNA–gene–drug 机制记录，检查模型能否恢复关键基因、效应方向和适用状态。输入使用过的通路或靶点库不能再充当独立机制真值；注意力与输入通路富集也不能单独证明机制。

[Science Advances 2026 扰动模型基准](https://doi.org/10.1126/sciadv.aed3414)的摘要显示，表达相似性与差异基因恢复测量不同目标，跨细胞类型没有始终占优的方法。[机制注释基准预印本](https://doi.org/10.64898/2026.08.19.745729)进一步提出方向性机制评价；本轮只读到摘要，适合借鉴问题，不应立即将其评分视为已验证标准。

更强的研究问题可以表述为：**在来源独立、实验语义明确的条件下，保留 RNA 局部功能、基因身份与细胞依赖性，能否改善药物内候选排序，并恢复独立证据支持的调控关系？** MPHGNN 已有 gene 元路径，MIFNDRA 已有通用多模态与对比，mDADGAN 已有跨 RNA 图与扩散，RGDAGMAE 已有图掩码和路由。贡献需要由上述信息与验证增量建立，不能仅由组件组合建立。

**建议执行顺序与判断规则**

先完成 Q1，再做 Q2 的稀疏局部表示；Q3 可作为独立的药物编码对照。每个实验预先指定主比较、总维度、样本、支持上下文、推理/训练预算和停止规则。相关性筛选、PCA、权重及超参数选择只用训练侧；不扩大对已参与开发的验证集的反复搜索。

如果 Q1/Q2 不能胜过相同覆盖与信息量的统计/打乱对照，暂停更复杂的局部注意力和 gene 图。若出现稳定增量，再投入单蛋白靶点—依赖性数据和经原文核实的方向小集。lncRNA 先证明自己的功能目标有效。新的来源留出仍保持关闭，待方案冻结后按既有协议使用。

本轮产出是文献与可行性证据，没有新增训练、分数校正或留出评价，也没有改变已接受模型。审计脚本为 [audit_existing_information.py](audit_existing_information.py) 和 [audit_action_scope.py](audit_action_scope.py)；文献查询、原始响应、哈希与失败后重试记录保存在当前目录。Crossref 两次初始 429 已保留，随后两条 DOI 均成功复核。
