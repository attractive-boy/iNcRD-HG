Knowledge Graph Foundation Model via In-Context Learning*，arXiv:2605.14907v1
（2026-05-14 预印本），作者 HKUST-KnowComp/KGPFN 提交
`af415c33a950bdb975eeb1b6f4e93e86b6ec929c`。公开权重、源码下载和全文阅读记录
保存在本目录。没有声称完整复现论文的预训练或结果。

## 方法与比较对象

用冻结 ULTRA 的关系图编码器及六层关系条件 Bellman–Ford 编码器，将目标三元组
映射为结构 token，再由公开权重的定制 PFN 根据带标签的同关系示例进行条件推理。
本地不训练任何神经参数。核心假设是**关联到正确标签的关系示例对预测有额外作用**，
而不只是再次迁移一个固定图向量。

- `full`：发布结构 token 与 PFN；上下文使用训练支持标签及作者软标签修正。
- `shuffled_context`：完全相同的编码器、token、上下文示例与标签多重集；只对修正后
  标签作固定置换，破坏示例与标签的对应关系。保留标签分布，避免修正规则造成混杂。
- `ultra_only`：同一支持图和发布编码器的原始 MLP 分数，不经过 PFN。

每个训练查询折在其余四折中，以固定三个种子 666、0、1 分别选择 20 个正例、80 个
采样零标签作为上下文。每个上下文内部无重复。三个上下文的全部目标事实与整个查询折
目标事实一起删除，然后才生成逆向边及关系图。评价使用这五张支持图；不额外用全部
训练事实拟合。三个上下文的原始分数取均值。控制臂使用同一图和预算。

每条训练记录只获得自己查询折的 OOF 分数。每臂独立拟合共同的两参数凸残差校准：
`mean BCE(anchor_oof + beta * standardized_score + intercept, y)`
加 `0.005 * (beta² + intercept²)`，BFGS 梯度最大绝对值 ≤ 1e-7。
评价时先平均五个支持图分数，再作同一个校准，残差裁剪 ±2，以固定权重 0.1 加到
当前强参考。校准和平均只是共同的接入方式，不单独计作创新。

LncDrug 预先指定为参考分数的精确恒等，不新增训练。全局 ROC AUC 与 sklearn AP
为主指标；历史 → 三个追加分区 → 冻结 outer 的既有联合门槛不变。full 必须在两项
均值上同时胜过强参考及两个机制对照。三个历史参考种子不是三个独立 KGPFN 拟合；
这里是确定的三上下文平均算法，没有把重复评分计作训练或初始化证据。

## 发布实现的适配边界

1. 权重 SHA256 为 `366c3e3795738da81a05691c626497372bda58109ad7bf178bfc7fe21136a87a`；
   368 个状态项、26,668,874 个参数元素全部严格加载，参数冻结。checkpoint 没有 config。
   使用公开 train_all 的六层/64 维结构配置、三个 hop、包含 tail、结构增强和标签修正。
   PFN LayerNorm 无偏置由完整状态匹配识别；源码默认有偏置会缺少 32 项，首次严格加载
   因此失败，没有忽略缺失项或留下随机层。
2. 作者脚本指向的 `config/tabicl/tabicl.yaml` 不在固定仓库中。PFN 其他参数使用发布类
   的默认值并由状态形状验证；无法从权重确定的运行开关以上述公开配置为准。
   论文写 20 正/60 负与三个预训练图，train_all 为 20 正/80 负及 `graphs: all`；
   test 配置又关闭 context_graph。不能把这个 checkpoint 的完整训练配方当作已确认。
   `graphs: all` 的源码目录包含 Hetionet 等 57 个展开数据集；因此不宣称预训练语料
   与生物知识完全独立，也不宣称已证实本项目测试集污染或无污染。
3. 保持作者 fused RSPMM 的实际 C/CUDA ABI：第一行是输出 row，第二行是输入 col，
   `out[row] += weight * relation[type] * input[col]`。本地采用按关系的 CSR 矩阵乘法，
   不使用方向相反的普通 PyG fallback。只支持当前 sum/DistMult、冻结参数的路径；
   其他 reducer、消息函数或梯度请求直接拒绝。独立逐边公式、权重/重复边和完整模型
   对照均通过。没有声称在本机编译并运行了作者 CUDA 扩展。
4. 作者 get_representations 直接调用 bellmanford，不经过训练 forward 的自动删边。
   本地显式删除查询与上下文目标事实。这里只约束本地运行，不据此判定作者全部训练泄漏。
5. 作者 CustomTabICL 注释说 RowInteraction 追加 CLS；实际 vendored RowInteraction
   **覆盖前四个位置**。本地保留该行为；13 个输入 token 中前四个 hop token 被覆盖。
   单元检查证明任意更改这四个位置不会改变表示，不能声称它们在本配方中提供信息。
6. 所有计算使用 FP32、关闭 TF32 和自动混合精度，固定 cuda:1；不依赖 Flash Attention。
   同一个实体遍历中提取前三层及末层，缓存行表示，避免作者便捷接口的重复遍历。
   合成图及真实训练图均与作者便捷前向对照；真实图最大误差 5.49e-6，查询换序/分批
   最大误差 3.78e-6。容差 3e-5（绝对及相对）。训练专用探针约 9 秒、峰值 0.246 GiB，
   没有计算评价性能。

## 创新和证据范围

旧 LINK_PFN 是自建合成任务上的小型配对描述符模型；旧 REIFM 是冻结实体表示加核读出。
本候选迁移的是图关系条件表示与学习到的示例条件推理器，仍与更宽的 PFN/图基础模型家族
有重叠。只有上述两项对照均支持上下文机制，且全部验证门槛通过后，才有资格讨论是否能
算作一项不同于既有提升的技术；当前不计成功，也不把本地兼容性工作计作创新。

所有历史、追加分区及旧 outer 均有开发暴露；原始保留测试集未读取。
上下文零标签是采样的未观测关联，修正为 0.5 是算法启发式，不是新增生物测量。
