**外部细胞系药物响应通道对 RNA–药物关联没有可用信号。** 2026-09-16。只读诊断，未训练模型、未调用评价标签以外的标签、未修改任何封存产物。入口 `evaluate_response_channel_v1.py`，结果 `RESPONSE_CHANNEL_V1.json`。

## 做法

对每个配对 (RNA r, 药物 d)，用外部细胞系数据计算 r 的表达与 d 的实测响应在共同、全有限细胞系上的 Pearson 相关。数据取自已冻结的 PRISM 19Q3 活性矩阵与项目 RNA 表达矩阵的对齐输入 `results/functional_response_inputs_20260914/`（来源 Bioconductor ExperimentHub EH7530/EH7554）。该特征是**无标签的**：只用外部表达与药物活性，不使用任何 ncRNA–药物关联标签。

## 结果

| 项 | 数值 |
|---|---:|
| 完全有限细胞系 | 127 / 725 |
| 精确结构匹配的项目药物 | 34 |
| 可评估的历史 MiDrug 评估配对 | 242 |
| 其中正例 | 13 |
| **相关特征单独 AUC / AP** | **0.358 / 0.067** |
| 同 242 配对上的药物度数先验 AUC | 0.754 |

相关特征在匹配配对上**低于随机**，而同一批配对上的药物度数先验明显有效。也就是说，RNA 表达与药物实测响应之间的协变，对这个关联任务不携带可用信号。

## 与前序证据一致

项目此前的功能响应实验（`FUNCTIONAL_RESPONSE_FINDINGS.md`）已用 PRISM/CRISPR 作为辅助监督训练表达编码器，结果对留出细胞**不优于均值基线**（药物 MSE 胜出 0/5）。本次的配对级相关诊断与之一致，并直接排除了“换成 GDSC IC50 就可能有效”的变体：通道本身没有信号，换数据集不会改变结论。

## 对目标的含义

这是既有证据链的最后一条可行通道。结合 `mechanism_saturation_20260916/SYNTHESIS_V1.md`（87 份机制评估：性能门槛 84/87 通过，但机制余量均值为零、正向比例约抛硬币），可选空间如下：

- 允许的“新机制”方向：机制余量为零，无法通过机制门槛且不随分区稳健。
- 唯一历史上产生稳健增益的方向（更强预测器、新证据/上下文列、融合/收缩）恰是目标约束 (3) 明确排除的方向。
- 唯一可能补充正交信息的通道（细胞系药物响应）本次实测无信号。

因此，在当前数据与约束下无法落地“三个全新且经验证的技术”。解除阻塞需要：**(a) 放宽约束 (3)，允许把新的外部证据列并入特征库；或 (b) 提供新的外部数据/新评估口径**（例如独立的 ncRNA 干预效应数据、LINCS 扰动签名、或一个未参与开发的新队列）。
