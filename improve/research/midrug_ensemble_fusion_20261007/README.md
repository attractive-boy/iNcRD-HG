# 原 M1/M2/M3 融合向量上的联合多成员预测头

目标：原 MiDrug 测试 seed42/43/44 均值 AUC≥.9733929274、AP≥.9336833737，
PLMF MDR/MDS 不下降。只用原 miRNA/drug 属性与原训练标签；无 lncRNA、额外注释、
数据或新权重。沿用原训练内部三折，原验证/测试不参与本轮开发。

## 证据与区别

前轮归一化注意力虽然减少有效列数，却未改善分类，真实药物条件臂在三折两指标
均低于平均条件臂；不继续自动搜索注意力参数。
[TabM 范围核查](../midrug_literature_20261006/TABM_SCOPE_REVIEW.md)记录了文献和
历史同类工作。本轮是已知方法的本地适配，不声称首次使用 TabM。
旧 GraphTabM 用混合 RNA 图的手工统计替换整个流程；其加载器/特征/缓存不调用。

本轮保持原 M1 精确查询删除端点表示、M2 路径池、M3 查询不变统计与 EASE。
这些向量按原顺序拼接，继续联合训练原图编码器及各通道投影。只改变最后原有
`lin1 -> LeakyReLU -> lin2 -> LeakyReLU -> lin3` 的参数形式。

## 参数与两个训练目标

固定 16 个成员，沿用历史本地成员数，不搜索它。隐层宽度沿用原 512/256；
不增加层或 dropout。每个隐层的成员 i 为 `s_i * W(r_i * x_i) + b_i`：
共享 W 沿用同种子原层初始化；偏置复制原偏置；首层 r 是独立随机±1，其余
r/s 初始为 1。输出层成员权重/偏置独立：第一个保留原 lin3 初始化，其他按
原 Linear 的均匀分布独立初始化。增加成员会改变初始预测，但保持原通道参数
及重建模块初始化。单成员恒等检查把所有缩放置 1，应复现原整个模型。

两个配置具有完全相同参数、初始化、输入和预测：

- independent_rec10：16 个成员分别计算 BCE 后平均，符合 TabM 训练机制。
- mixture_rec10：先平均成员概率，再计算 BCE。是等参数训练目标对照，
  不声称它是 TabM 推荐训练方法。

推理均平均成员 sigmoid 概率，不平均 logits。为兼容原 Adapter 的单分数接口，
返回 `logsumexp(logsigmoid(z_i)) - logsumexp(logsigmoid(-z_i))`；其 sigmoid
等于平均概率，无概率裁剪。训练通过 member_logits 一次计算共享主干及 BN，
不会把 16 个成员当作独立配对样本，也不把三个训练种子与内部成员混为一谈。

主干和头 RMSprop lr1e-4/wd0；原重建 lr1e-4/wd1e-4，权重 10 前 50 轮爬升。
max800/min300/patience200，按内部 AUC/AP 均值选轮。两个配置×三折共六次拟合。
复用纯 M123/unmasked10 六个不可变旧对照的完整重放证据。
仅 independent_rec10 是候选，三折均值 AUC/AP 须相对两个旧对照及 mixture_rec10
各增加≥.002，才进入后续冻结原验证。最终双+.02要求保持不变。

## 核验

独立逐成员物化矩阵 `diag(s_i) W diag(r_i)`，核对输出、输入及全部头参数梯度；
用独立概率公式核对两个目标及其梯度，含极端 logits 的稳定性。
真实图检查原拼接向量/通道初始化、单成员完整预测、各训练目标的非零共享主干
和成员梯度、BN 一次、留出标签翻转不变。完整物理删除要核对每个成员的 logits
和最终平均概率，不能仅用平均后抵消来掩盖成员错误。测量一次完整训练更新资源。
训练后六个检查点重放保存概率/指标/选轮/损失，去除重建解码器应保持预测等价。

冻结选择后报告每个成员与整体的 AUC/AP、概率方差、平均个体 BCE 与混合 BCE、
成员分歧及消融，不按单个留出成绩挑选成员子集。

首次预检要求 GPU 上原融合向量逐位相等，因约 4.58e-5 的差异失败，原日志保留。
最终检查输入张量仍逐位相等，融合向量及其重复计算采用此前真实图物理删除的
固定容差 atol2e-4/rtol5e-5，并记录两种误差。没有改变 float64 独立梯度参考容差。
