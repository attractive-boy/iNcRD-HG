# Original drug-name fragments

Original Drug_Name contains an unused allowed covariate. Shared spelling may help transfer drug information beyond the original ChemBERTa coordinates. This is a covariate-coverage experiment, not a claim that spelling proves pharmacological mechanisms or verified drug classes. No external vocabulary, annotation, sequence, dataset or pretrained text model is used; all nodes remain miRNA and drug.

Freeze character TF-IDF before any labels are read: sklearn char_wb, ngram_range(3,5), lowercase, min_df2, smooth IDF, sublinear term frequency and L2 row normalization. The 216 original names yield902shared fragments and209nonzero rows. The seven unsupported names get zero features. Vocabulary fitting on all drug covariates is label-free transductive preparation. CID order is independently matched to the original ChemBERTa table, whose normalized features exactly reproduce the clean graph. A separate tokenizer/count/IDF oracle verifies the resulting matrix.

The input branch is one bias-free902→768linear projection added to the original drug input of the full M123 encoder. Its weights start at zero, so every arm initially equals the original unmasked10 model. The same refined drug features are used by the dense query-edge correction and auxiliary encoder. Reconstruction continues targeting the original938/768normalized coordinates, not drug-name values. No graph edge is added or changed.

Three arms: aligned names (only eligible candidate), fixed deranged drug-name assignment (seed20261007, resampling permutations only to remove fixed points), and zero name inputs. All allocate identical parameters, and all shared/branch trainable parameters initialize identically. The zero arm has no active text gradients, so identical allocated parameter counts do not imply identical effective capacity. The permuted arm is a correspondence control, not a causal test.

Nine fits: three fixed original-training inner folds, seed42, 800max/300min/patience200, earliest maximum mean(inner AUC,AP). RMSprop1e-4; original parameters wd0; text projection and original reconstruction decoder wd1e-4. Reconstruction weight10 with50epoch ramp. Only aligned may proceed, and only if both mean metrics exceed each of permuted, zero, existing plain M123 and existing unmasked10 by at least.002. There is no ngram/grid search or post-hoc promotion of controls.

Initial checks verify baseline parameter/output identity, unchanged graph/features, heldout-label isolation, finite/nonzero text gradients and physical query deletion. Selected checkpoints are replayed and selection recomputed. Fixed-model text removal is a descriptive prediction-sensitivity diagnostic, never a checkpoint-selection criterion. Original test dual+.02 and PLMF non-decline remain mandatory.
