Multi-Channel Equilibrium Graph Neural Network for Multi-View Semi-Supervised Learning
====
This is the Pytorch implementation of MEGNN proposed in our paper:

[Shiping Wang](https://scholar.google.com/citations?user=_Yhc9TwAAAAJ&hl=zh-CN&oi=ao), 
[Yueyang Pi](https://scholar.google.com/citations?hl=zh-CN&user=c748qXkAAAAJ&view_op=list_works&gmla=AH8HC4zD7rbZq0oIlH3jTYOgy3_lb_7cb6i7bbppHOSExU57hSouo9LOzvE8lQpx5kkU_qSuqph6DQjzsQpQupI3_JDoLNmQZiCbIY_I3Mkod6GFPxI), 
Yang Huang, 
[Fuhai Chen](https://scholar.google.com/citations?hl=zh-CN&user=sP-7Y0EAAAAJ&view_op=list_works&sortby=pubdate) and 
[Le Zhang](https://zhangleuestc.github.io/)*, 
[Multi-Channel Equilibrium Graph Neural Network for Multi-View Semi-Supervised Learning](?), IEEE Transactions on Pattern Analysis and Machine Intelligence 2025.
![framework](framework/framework.png)

## Requirement

  * Python == 3.9.12
  * PyTorch == 1.11.0
  * Numpy == 1.21.5
  * Scikit-learn == 1.1.0
  * Scipy == 1.8.0
  * Tqdm == 4.64.0

## Usage

```
python main.py
```
