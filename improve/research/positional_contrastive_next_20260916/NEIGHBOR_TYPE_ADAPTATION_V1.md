实际实现依据为正文 §6.1、附录 D 和作者 `ssm_loss`。二部图初始状态分别来自 RNA 和药物；线性传播保持两个来源的精确分解。若 `E_r` 与 `E_d` 各含这两个分量，则余弦分子的四个双线性项使用同一个完整向量范数分母。正配对保持完整余弦，负配对按候选端的来源类型加权。两个条件方向取平均。

局部变化及固定配方：

1. 只传播当前任务的已收录正关联，所有拟合查询折的正、零标签均从支持图移除。无自环；采用对称度数归一化，两层线性传播，包含初始状态并平均三层。MiDrug 有 605 个 RNA、216 个药物；不使用其他 RNA 任务的监督损失。
2. 初始状态是现有 RNA/药物属性的类型专属线性投影与可训练节点向量之和。属性逐行 RMS 归一化，投影后逐行 L2 归一化；没有新增外部数据或表格特征列。两类初始状态允许保留可解释的来源分解。宽度 64。
3. 配对解码器是 `[left,right,left*right,abs(left-right)]` 上的 64 宽 MLP，GELU、dropout 0.1，最终层零初始化。原始论文直接以协同内积排序；此处为了学习强参考误差，解码器及 BCE 是明确的本地适配。
4. 主损失是 `BCE(nested OOF anchor + residual) + 0.1 * NT-SSM`。每步循环一个支持折，监督与对比正例均取该折训练查询；这些标签只参与损失，不进入当前支持图。没有以验证标签采样负例。两个方向温度均为 0.2。只在批内作对比；共享任一端点的批内重复正例从负项中删除，防止它们互相充当假负例。其他批内交叉配对是隐式替代项，不宣称为实验验证的无关联。
5. 固定系数采用正文 Table 5 的 LightGCN / MovieLens-1M 配方：`alpha_uu=1.2, alpha_ii=0.8, alpha_ui=0.8, alpha_iu=1.0`。在观测本候选性能前选定；MiDrug 与该表中 MovieLens 同为 RNA/用户端多于药物/物品端、且密度较高的矩阵。没有把这当成本任务的最优系数，没有搜索四个系数。
6. 对照 `type_shared` 保留双向目标、温度及每方向平均系数，但在该方向的两个来源类型间共享系数：预测药物为 0.9，预测 RNA 为 1.0。它删除类型差异，控制平均负项尺度。对照 `bce` 删除辅助目标。所有臂的初始参数、容量、RNG、数据、步数与解码器完全相同。所有臂计算相同批内掩码；`bce` 的辅助梯度严格为零。
7. 推理仅使用强参考加 `0.1 * 五支持折平均原始残差`；没有将查询批次作为模型上下文。LncDrug 在本候选查看性能前登记为零参数、零训练步的恒等分支，逐记录核对严格不变。
