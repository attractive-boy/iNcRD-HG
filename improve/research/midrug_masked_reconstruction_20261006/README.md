# 原特征掩码重建正则：纯 miRNA–药物

目标仍为固定 MiDrug 测试 seeds 42/43/44 均值 AUC ≥0.9733929274189016、
AP ≥0.933683373732677，且 PLMF-MDA MDR/MDS 不下降。当前尚未完成。

本轮由 [RGDAGMAE，2026](https://doi.org/10.1016/j.compbiolchem.2026.109236)
摘要中的特征掩码重建思路启发，仅检验共享编码器上的辅助重建损失。
未使用其路由模块、数据或权重，不声称完整复现该论文。
原文证据见 [已保存的文献笔记](../midrug_literature_20261006/RESEARCH_NOTES.md)。

## 输入和方法

只加载 `../midrug_mirna_only_20261006/graph.pt` 与 `inner_data.npz`：
605 个 miRNA（938 维原表达特征）、216 个药物（768 维原特征）。
目标关系只来自当前内部折的训练正例；原验证/测试标签从未加载。
保留原 M1 查询删边、M2 中间节点汇聚、M3 MC-EASE 和原融合头。

每轮从两种节点中分别随机选择 50%，将完整特征向量替换为该类型的可学习 token，
token 初始为本类型原特征均值。共享原两层 GeneralConv 编码器重新计算节点表示，
经 LayerNorm→Linear(256,128)→LeakyReLU→Linear(128,原特征维数) 解码。
目标是原特征按列去均值/除标准差的值，标准差下限为 0.05。
仅计算所选节点的 MSE，miRNA 和药物各占一半权重。
均值和标准差只依赖已有节点属性，与任何关联留出标签无关。

辅助传播使用当前训练图，输入复制后遮蔽，**不会改写关联预测所用的图或特征**。
原同类相似图保持冻结，因此该实验是现有图上的转导正则，不是未知节点或
完全隐藏属性条件下的重建评估。推理时不使用重建解码器和 token。

## 固定比较

| 配置 | 辅助输入是否遮蔽 | 重建权重 |
|---|---|---:|
| masked001 | 是 | 0.01 |
| masked01 | 是 | 0.1 |
| masked1 | 是 | 1.0 |
| unmasked01 | 否 | 0.1 |

未遮蔽对照也在完全相同的随机半数节点上计算目标，参数数目与解码器相同；
它保留原输入，用于比较遮蔽的增量。随机 mask 使用独立 generator，seed=20261006+折号。
关联 BCE 加辅助 MSE 权重在前 50 轮线性增至表中值。
RMSprop lr=1e-4、alpha=0.99，辅助解码器/token weight_decay=1e-4，主干不加 weight decay。
最多 800 轮，至少 300，最优轮后 200 轮无改善即停。
按内部 `(AUC+AP)/2` 选 checkpoint；配置按三折相对已优化纯 miRNA M123 对照的
`min(mean ΔAUC, mean ΔAP)` 选择。两指标均增加 ≥0.002 才考虑原验证确认，
这个开发门槛不是最终 +0.02 的替代。

初始辅助梯度范数约为 0.392，BCE 梯度范数约为 28.09，两者余弦约 0.076。
这些仅是初始化诊断，不能推断整个训练过程的梯度关系或预测收益。

## 复现

解释器 `/data1/licheng/miniconda3/envs/ncRNAdrug/bin/python`，环境变量
`OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2`。
第一阶段顺序：`check.py` → `launch.py` → `audit.py`。
第一阶段的最大已试权重 1 在三折两指标上均有增益，因此随后在 `phase2/` 中
预先固定 masked3/masked10/unmasked3/unmasked10，执行该目录的 `launch.py` → `audit.py`。
最后回到本目录运行 `error_audit.py` → `summarize.py`，汇总两阶段共 24 次新训练。
训练拒绝覆盖已有同名结果。模型、预测、选轮曲线、原始日志、输入与源码哈希随目录保存。
初始检查包括原主干权重相同、预测数值等价（GPU 浮点差 <6e-7）、
不改写输入、内部留出标签翻转不改变重建损失、辅助梯度与完整预测删边检查。
