# 原M123配对表示的边界辅助监督

最终目标：只使用原miRNA/drug数据，原MiDrug测试seed42/43/44均值
AUC≥.9733929274、AP≥.9336833737；PLMF MDR/MDS不得下降。
本轮不新增推理参数，不修改原M1/M2/M3，不使用lncRNA、外部序列、注释或权重。

## 来源与独立适配范围

上一轮药物条件化表达分支未超过unmasked10，不推进原验证或测试。
近期BES论文提供“关注表示空间边界”的思路，但其节点类别、公开代码单token
注意力、论文/代码损失差异及按test选轮均不能照搬。具体源码commit、合成核查、
阅读范围见`../midrug_literature_20261006/EXPRESSION_FOLLOWUP_NOTES.md`。
历史增强表示实例InfoNCE也已记录，不宣称第一次使用对比损失或新的方法家族。

六个原M123/unmasked10内部检查点的诊断中，约25%的留出配对所在边界区域参与
约71–75%的AUC逆序质量；边界正例贡献约54–60%的AP缺口。错误集中不证明可恢复，
更不证明双+.02可达。本轮直接用原训练配对观测标签做辅助监督，不虚构节点类别
或把抽样零标签解释为生物学拮抗。模型从原初始化重新训练，不加载诊断检查点。

## 训练时边界与匹配对照

每轮仅运行一次原训练前向，通过临时hook读取lin3前的配对表示Z，随后移除hook。
这些表示沿用原M1/M2/M3精确删除当前查询记录的前向。EB BatchNorm只更新一次。

用本轮训练配对的Z（停止梯度）计算每列均值和总体标准差，下限.001。
标准化表示U=(Z−mean)/scale；样本协方差加`.1*max(mean(diag(C)),1e-8)*I`。
几何统计、协方差及线性求解均用float64。设原观测类别中心为c0/c1，
`v=(C+ridge I)^(-1)(c1−c0)`，边界距离采用
`abs((U−(c0+c1)/2) @ v)`，包含中点偏移，不用作者过原点的slab假设。

boundary在**每一观测类别内部**选择距离最小的`ceil(.25*n_class)`个配对。
random从每类全部训练配对中无放回随机抽取完全相同数量。
两臂都计算几何及两种索引，随机生成器独立于初始化和重建抽样。
这样即使两模型训练轨迹不同，每轮样本数量和类别比例也严格匹配。
与前期诊断的“全局25%区域+5NN多数异类”不同，本轮使用类内固定预算排序；
不加入5NN筛选，避免实际监督预算随模型变化。相同距离按原记录顺序稳定排序。

## 类别原型损失及梯度边界

把每个训练U按行L2归一化，再对每类求均值并归一化得到两个原型P0/P1。
mean、scale、原型与选样索引全部停止梯度。对于被选中的配对i，
`u_i=normalize((Z_i−mean)/scale)`，以`[u_i·P0,u_i·P1]/.2`为两个类别logit，
计算稳定的交叉熵。辅助梯度只直接进入被选中配对表示，进而更新原共享模型。
每轮重算停止梯度的统计量属于训练规则；不将其描述为对所有统计量求全梯度，
也不借用BES的平方距离中心恒等式或潜变量可识别性证明。

总损失是`BCE + lambda*prototype_CE + reconstruction_weight*reconstruction`。
lambda前30轮为0，随后30轮线性增至.05；温度.2与最大权重.05来自已登记的历史
对比配方，不据本次分数搜索。重建权重0/10、前50轮爬升，保留原重建目标。
原型及统计量不保存到推理模型；推理完整沿用原M123，重建解码器也可等价移除。

## 冻结协议与检查

boundary/random × 重建0/10 × 原训练内部三折，共12次拟合，seed42。
主干RMSprop lr1e-4/alpha.99/wd0，重建lr1e-4/wd1e-4；800轮上限、至少300轮、
patience200，以内部(AUC+AP)/2选轮。只复用已重放的纯M123/unmasked10六个对照，
旧哈希核查不计为新GPU重放。

boundary候选须相对纯M123、unmasked10及同重建random，在三折均值上AUC/AP均
至少提高.002，才允许进入原验证。最终仍按原测试双+.02与PLMF保护验收。

独立NumPy核对几何、选样、原型、损失和显式梯度；固定停止梯度上下文后做有限
差分，核验未选样本辅助梯度为零、类内预算一致、平移/正比例缩放等变（标准差
未触发下限时）、常量/共线特征有限、零权重与BCE梯度一致。真实模型检查初始
参数/预测、完整训练步、EB计数一次、全部梯度有限、留出标签翻转不变及M123物理
删记录预测。训练后重放所有新检查点，重算指标/选轮/损失组成，核验无训练hook
残留、移除重建解码器等价，以及PLMF受保护模型/输入/发布源码哈希。
