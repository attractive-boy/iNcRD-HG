# 原始特征的全局路由，再进入 M123

仅使用独立冻结的 miRNA 表达谱和 drug ChemBERTa；没有 lncRNA、外部数据或新权重。
这是受 2026 年 HDIGRL/RGDAGMAE 摘要启发的独立适配，不是作者实现的复现。
来源、已阅读范围及任务差异见 ../midrug_literature_20261006/FOLLOWUP_NOTES.md。

每类特征按原节点全集的均值/标准差标准化，映射到 64 维。route 模式用每类 8 个
可训练 token 汇聚节点特征，再让每个节点读取两类共 16 个 token。pool 使用两类
各自的均值，各类型等权。local 只使用自身 MLP 表示。最后经同结构残差输出层映回
原始维度，以 0.1 × 原列标准差缩放后加入原特征；输出层为零初始化。

三种模式各比较重建权重 0/10，合计 18 次原训练内部三折拟合。原 M123 的参数初始化、
相似边、M2/M3 统计不变。特征变换和原编码器通过监督损失共同训练；有重建时也共享
原特征重建目标。所有模式分配相同模块，不活动参数冻结并排除出优化器；不声称有效
容量或计算成本完全相等。pool/route 的额外上下文来自全部原始节点，属于传导设置。

特征变换不接收图边、配对标签、节点度或查询集合。因此删边前后变换相同，原两层
M1 解析修正只需统一使用变换后的输入；M2 的节点状态修正仍用原公式。没有将带查询
标签的表示作为所谓“无标签”特征。第一层完整消息和删除消息的变换是同一确定性函数，
重复计算以避免跨 batch 的缓存和 autograd 生命周期问题。

初始检查比较 9 个 float64 非零残差下的输出及参数梯度、六配置的真实图显式删边、
节点重排等变性、原输入无修改、零初始化恢复原模型、路由梯度以及留出标签翻转。
训练前 plan 固定：seed42，RMSprop 1e-4，原参数 wd0，新增有效参数 wd1e-4，最多
800 轮、至少 300 轮、patience200，按内部 (AUC+AP)/2 选轮。

所有候选需相对纯 M123 与 unmasked10 各指标平均至少 +0.002 才推进；pool 另需超过
同重建权重的 local，route 另需超过同重建权重的 local 和 pool，各指标也为 +0.002。
这是内部开发门槛；最终仍需原测试三种子 AUC≥0.9733929274、AP≥0.9336833737，且
PLMF 两数据集不下降。原验证和原测试不参与本轮。
