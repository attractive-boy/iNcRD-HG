## 1. 诊断：valsel 协议一直在丢掉 11% 的图

前九轮的 valsel 都是这样做的：从训练对中分层留出 10% 选 epoch，**这 10% 的正例从消息图里拿掉**（否则普通 GNN 的验证对会看到自己的边）。后果是测试时的消息图也只有 90% 的训练正例，也就是只用了 72% 的已知关联。

线索来自一个"假阳性"的发现：把 LR 管线缓存的交叉拟合特征（`plmf_warm_20260922/cache/*ctx+diffK10*`）作为额外通道喂给 GNN，得到 +0.0027/+0.0030（MDR）。但把同一族扩散特征改成精确空心重算（`--hdc`，逐点验证到 1e-16）或改成 GNN 自己的交叉拟合（`--xfit`），增益都是 0。区别只有一个：**那个缓存的测试特征用的是 100% 训练正例构图**，包括 GNN 留出的验证正例。增益来自这 11% 的边，而不是特征本身。

## 2. 方法

### R1 HVG：空心图内验证（`--val_graph`）
验证正例留在消息图里。训练损失只用 90% 的训练对，epoch 仍由 10% 验证对的 AUC 选择，测试时的消息图包含全部训练正例。

为什么只在空心架构上成立：第八轮模型对任意查询 (m,d) 满足 f(m,d; A) = f(m,d; A − A[m,d] e_m e_dᵀ)（`--check_inv`：2e-5）。所以验证正例在图里时，它的分数和它不在图里时一模一样：选 epoch 用的信号是干净的，而它的边仍然作为结构信息服务于其他所有查询。非空心模型做同样的改动时，验证正例会看到自己的边，val AUC 失真、epoch 选错（plain −0.002~−0.006；不掩蔽的通道 −0.16）。

与链路预测的常规做法（OGB / PyG `RandomLinkSplit`：训练与验证时不用验证边，**只在测试时**把它们加进消息图）的比较，5cv seed 42（`--val_graph_test`）：

| | MDR | MDS |
|---|---|---|
| 第八轮 full + 测试时加入验证边（OGB 做法） | +0.0036 / +0.0045 | +0.0022 / +0.0022 |
| 第八轮 full + R1（训练、验证、测试同一张图） | **+0.0046 / +0.0059** | **+0.0026 / +0.0028** |
| plain + 测试时加入验证边 | +0.0016 / +0.0019 | +0.0005 / +0.0005 |
| plain + R1 | −0.0008 / −0.0007 | −0.0064 / −0.0074 |

空心模型的训练图 = 验证图 = 测试图，没有 OGB 做法那种"训练时 90%、测试时 100%"的分布偏移，所以增益更大。普通模型只能用 OGB 做法。

### R2 HWC：空心全矩阵对比（`--unl 1 --unl_strict`）
每个 epoch 从"不在消息图里的所有单元格"中均匀抽取与训练对等量的单元格，标为 0，与训练对一起算 BCE（全批、一次前向，原有的通道特征照常计算）。

- **严格池**：池 = 全部非消息图单元格，**包括验证对和测试对所在的单元格**。池本身不透露任何评估对的信息，代价是 0.8% 的池单元格其实是验证/测试正例，会被当成 0。非严格池（排除评估对）结果相同（MDR seed42：+0.0017/+0.0027 vs +0.0016/+0.0025），报告严格版。
- 为什么只在空心架构上成立：非空心模型里，训练正例的输入永远含有自己的边，未标注单元格永远不含。对比样本越多，模型越依赖"有边 ⇒ 正例"这条捷径，测试时反而更差（plain + R2：−0.001~−0.004）。空心模型里，训练正例和未标注单元格的输入分布一致，额外的负样本只能教模型真正的区分信号。
- 增益落点（`gain_by_degree.py`，5cv×3）：主要在高流行药物的负例上。MDR 中度 > 100 的药物上负例排序损失 0.2615 → 0.2522，也就是同一个热门药物内部的 miRNA 区分变好了。
- 按流行度加权抽样（`--unl_pop`）有害（−0.002 ~ −0.016）；抽样量 1× 与 4× 相同；权重 0.25~4 平坦。

## 4. 剩余误差（本轮 full，MDR 5cv seed42）

- 测试负例中 2.13% 是 MDS 的正例（同一对 miRNA–药物，另一种表型有文献记录），平均分 0.51，其余负例 0.096。只去掉这些负例，AUC 就从 0.9539 升到 0.9590。按"不引入外部信息、不改评估"的要求，这部分无法消除。
- 正例损失集中在稀有药物（度 ≤ 20：正例占 9%，损失占 35%）和度为 1 的 miRNA（正例占 10%，损失占 20%）。这两组都几乎只能依靠内容相似度，而内容相似度各类探针都没有给出新增信息。
