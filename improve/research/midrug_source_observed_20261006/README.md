# 全图源条件传播中的训练观测关系

本轮检验已有机制的组合：在上一轮完整三层药物源条件传播中加入原训练抽样零记录。
不是新家族，也不是新论文的官方复现。只使用原 miRNA/drug 输入、原训练内部三折。
最终要求仍为原测试 seed42/43/44 均值 AUC≥.9733929274、AP≥.9336833737，PLMF 不下降。

## 为什么做这项受限检验

上一轮 source_rec10 确实使用了源标记，但没有胜过 unmasked10。此前
midrug_observed_context_20261006 已在普通两层节点编码器中学习正/零消息，也没有
通过门槛；cavity、signed paths、非线性关联 profile 等历史结果也不提供成功保证。
这里唯一尚未检验的交互是：零记录在每一个查询药物各自的传播上下文中参与路径，
路径的第二/三层状态进入原非线性融合。它不同于与查询药物无关的节点状态，
但不能单凭这种区别宣称有用或独创。失败后不自动扩大关系/深度网格。

新增 C 为原训练零记录的计数矩阵；对照 C=A 为重复正例关系。每层 C/Cᵀ 分别
有无偏线性变换，全部零初始化；先构建上一轮原 source 模型及投影，再添加新参数，
保证原 source 参数、重建初始化和最初预测严格一致。对照参数和优化器预算相同。
两臂的边数/拓扑不同，因而差异包括额外观测关系及其密度，不能归因于纯符号作用。
没有强制负变换或排斥损失，抽样零记录不解释为生物负作用；未知配对不加入 C。

## 三层精确删除推导

沿用初始 miRNA 状态为零、药物 d 上的共享 q 标记、每层边界注入、零对角同类型图，
每个药物都是独立上下文，全部原节点参加。以 A/C 为接收 miRNA、发送 drug 的矩阵，
令查询在两矩阵中的权重为 a=A[r,d]、c=C[r,d]，必须从两矩阵都删掉该项。

第一层只有查询 miRNA r 改变：其预激活减去 a W_dm,0 h_d^0+c W_cdm,0 h_d^0，
重新经过 LayerNorm/LeakyReLU，得到 δh_r^1。第二层查询 r 的预激活减去两条
查询消息，加上自身线性变换的 δh_r^1，再经过非线性，得到 δh_r^2。
第二层其他药物 j 的预激活增加 A[r,j] W_md,1 δh_r^1+C[r,j] W_cmd,1 δh_r^1；
同类型 miRNA 邻居 i 增加 S_r[i,r] W_mm,1 δh_r^1。分别重新经过非线性。

第三层查询 r：先减掉 A/C 的原查询消息，再加所有剩余 A/C 药物邻居的第二层
变化、同类型邻居的第二层变化及自身变化。查询药物 d 的第二层状态不用计算，
因为两条 d→r 消息都已删掉。拼接 r 的第二/三层输出，经原零初始化投影加入 lin1。
这个推导仅适用于上述初值、三层、无关联度归一化以及零对角同类型关系。
重复权重全部删除，零标签查询同样删除 C 中的记录；不外推到任意深度。

`check.py` 用独立单源 dense 全图物理删边验证输出及全部参数梯度，覆盖正/零/未知、
重复权重、有向同类型关系、度一节点，以及两观察关系重叠的更强测试。
另检验真实图的非零新权重完整 M123 删记录、原初始化一致、留出标签翻转与有限梯度。
C 和源几何从当前支持集重建，不写入 checkpoint，不会覆盖显式删记录后的图。

## 冻结实验

四配置 zero/positive × 重建0/10，共12次拟合。原 source/source_rec10、纯 M123、
unmasked10 共12个已重放旧检查点复用哈希证据；不将其算作新拟合或新GPU重放。
原主干 RMSprop lr1e-4/wd0，源分支及投影 lr.003/wd1e-4，重建 lr1e-4/wd1e-4。
最多800轮，至少300轮，patience200，按内部(AUC+AP)/2选轮，重建50轮线性升权。
zero 候选必须对纯M123、unmasked10、对应旧source和新positive对照的两指标均值
分别提高至少.002才能进入原验证。内部门槛不替代最终+.02要求。

不导入外部数据、lncRNA、序列、注释或新权重。参考文献及历史源审查见
`predecessor_review.json` 和 `../midrug_literature_20261006/SOURCE_OBSERVED_NOTES.md`。
