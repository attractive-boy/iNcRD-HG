# 独立初始化的八成员概率集成：训练前协议

目的：检验完整模型的独立初始化误差是否可以通过固定等权平均减少。
不是新的集成方法，不把旧负结果解释成普遍上限，也不预言能达到最终目标。

## 与历史实验的区别

`improve/RESULTS.md` 约698–720、773–800、895–930、2190–2210及2401行已记载
独立种子和跨配置集成，小幅或无增益。`improve/ensemble.py` 使用旧模型、验证AUC
选轮并平均logits；`improve/val_ensemble.py` 使用旧混合RNA加载和随查询集合变化的
分数标准化。这里只阅读它们，不导入旧加载器、不使用lncRNA。
当前严格协议中的 `midrug_ensemble_fusion_20261007` 是共享参数多成员头；
`midrug_weight_average_20261007` 是同轨迹参数平均。它们都未通过内部筛选。
本轮是当前纯miRNA数据/划分下的独立完整M123模型加既有unmasked10重构，
不声称独立集成在项目中首次尝试。

## 冻结方案

- 仅既有605个miRNA和216个药物的原始特征及图；原训练的三个固定内折。
- 固定8成员，不筛成员、轮数组合、子集、平均方式或权重。
- 内部root seed42；成员0是既有经过模型重放的unmasked10/seed42。
  成员j>0取 `np.random.SeedSequence([root_seed,j]).generate_state(1,uint32)[0]`。
  最终若推进，root seeds42/43/44使用同一规则，三组种子须互不重叠。
- 新拟合7×3=21次，所有模型独立初始化并独立训练；原M123结构不变。
  重构半节点的私有采样种子均为20261006+fold，隔离初始化差异。
- 原RMSprop/alpha.99，主干lr1e-4/wd0，重构lr1e-4/wd1e-4。
  重构权重10，前50轮线性爬升，无输入遮蔽。800轮上限，至少300轮，耐心200。
  每成员取最早最大mean(inner AUC,inner AP)的检查点，与成员0的已有协议相同。
- 每个成员的float32概率先保存，再以float64等权平均；无查询集合标准化。
  预测无需集成成员以外的已知标签；训练/推理成本约为单模型8倍。
- 唯一候选ensemble8，与纯M123/seed42、unmasked10/seed42、全部8个单成员
  的平均指标比较。只有相对每个对照的三个内折平均AUC和AP均提高至少.002，
  才可推进原验证；这是内部筛选门槛，不能代替最终原测试双+.02验收。
- 冻结选择后再看误差相关性、预测分歧及各成员差异，不据此改权重或成员数。
- 每新模型重放、检查选轮/损失及查询删边一致性，既有6个对照核验不可变重放。
  PLMF的10个已完整重放模型及发布源码、冻结图/划分只作保护性哈希复核。

最终要求仍为原测试seeds42/43/44均值AUC≥0.9733929274189016、
AP≥0.933683373732677，PLMF两个数据集均不下降。本轮不读取原验证/测试。
