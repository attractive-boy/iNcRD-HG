# CORE 信息瓶颈补边与逐查询压缩：预定适配

目标是检验结构补全与信息约束是否为 MiDrug 的强参考提供额外排序信息。LncDrug 从登记开始严格恒等，不训练新模型。完整验证前不计成功技术。

## 原文与核验边界

Kaiwen Dong, Zhichun Guo, Nitesh V. Chawla. *CORE: Data Augmentation for Link Prediction via Information Bottleneck*. Crossref 精确标题/作者匹配的 TKDD 记录为 2026-03-07，DOI [10.1145/3789200](https://doi.org/10.1145/3789200)。实际取得并核读的是 [arXiv:2404.11032v1](https://arxiv.org/abs/2404.11032v1)，2024-04-17 的公开预印本，不能声称已经核对 2026 期刊全文。

阅读范围为第 3 节、主要实验，以及附录 A/B/C 的相关目标、实现和消融、D/E 的理论条件、F 的限制。PDF 的 Received 2007 / revised 2009 是模板占位，不作出版日期。PDF SHA256 为 `27ca9e936d4f39ebce446bf67a5bb44097c83930b4accc2bf37288414651c33d`。检索未找到可验证的作者代码，本地为按公式独立实现。检索命中的 `arbenson/cflp` 是另一篇 core-fringe 论文，不作为 CORE 作者实现。

原文先 Complete、后 Reduce。完成阶段用链接启发式补充候选连接；压缩阶段针对每个目标连接，以子图表示作 query、边表示作 key，学习边保留概率。监督项加信息瓶颈的变分 KL 上界。附录 A 特别区分“每图边 KL 求和、对图平均”和“对所有边平均”；本适配保留前者。原文还包含新增边的十分位 rank 编码及训练采样、概率加权推理的实现讨论。

## 本地固定实现

- 每一当前查询折先删除全部目标事实，再构建无向布尔物理图。只依赖支持训练正例，不读取评价标签。
- 用 Resource Allocation `A D^-1 A` 提议同类型、尚无连接、至少有一个共同邻居的虚拟边。名义预算为原无向边数 10%；边界同分全部保留，因此可能略超预算。
- **同节点类型限制是本地改动**，保证补边不能插入任何 RNA–drug 目标查询。新增边只是结构候选，不加入监督或宣称为真实生物关联。
- 每个查询独立提取一跳双中心诱导子图，使用五类中心距离标记。沿用已有提取基础设施，不把标记或提取器计作本次新贡献。
- 32 维、两层共享 GCN 先编码完整增广子图。子图均值作为 query；无向边两端表示的和、绝对差及 origin/rank embedding 作为 key。点积生成边保留 logit。
- 原边先验 0.8，虚拟边先验 0.5，采样温度 0.67。一个无向边的两个消息方向共用一个 Gumbel sigmoid 连续松弛样本；自环恒为 1。
- 同一编码器再编码加权图。中心表示、逐维乘积、全图均值经过零初始化输出层形成残差。使用增广图固定度归一化和压缩前标记，**不声称信息已被完全压缩**。
- 目标为 `BCE(anchor_oof + residual, y) + 0.001 × mean_query(sum_undirected_edge KL)`。内嵌参考严格使用当前折未参与拟合的 OOF 分数；不会用当前查询结果拟合偏置。
- 推理用 sigmoid 概率边权，是 plug-in 近似，不是精确边后验边际化。确定性推理按最多 128 查询分块，对五个支持图取残差均值，再按固定 0.1 系数加到原参考。

## 预定比较与预算

三臂固定为 `full`、`no_kl`、`no_completion`。`no_kl` 删除整个 KL 梯度；`no_completion` 仅将补边比例设为零，其余模块及 KL 规则不变。所有臂参数模块相同；无补边臂的实际子图更小，不主张相同计算量。

正式历史阶段沿用 seed 666 筛选、seed 0/1 确认、学习率 0.001/0.003、400 次 AdamW 更新、每 20 步一次验证。每步使用一个轮转遗漏折的全部查询，一个松弛图样本，一次反向传播。无 KL 权重、补边率、先验、温度或合成系数搜索。每步保存 BCE、KL、加权 KL、保留率、边数、折及梯度范数。私有 cuda:1 generator 控制边采样；不调用所有 GPU 播种。

先完成三个五步 MiDrug 训练专用短测、三个 LncDrug 恒等重放，以及历史和三个固定分区、两任务共 40 折隔离审计。短测不计算性能。历史筛选预定 6 次新 MiDrug 拟合和 6 条身份评分记录，全部门槛通过才追加 6 次确认拟合。完整模型须同时超过两个机制对照的平均全局 ROC AUC 和 sklearn AP；仅历史通过还须固定分区、outer 和相应不确定性核验。LncDrug 每种子、每分区每项指标容忍下限为 −0.001，本方案预期严格为零。

本候选测试“支持图补全加逐查询信息约束”的组合机制。它不同于既有成功的表格模型、特征扩列、anchor shrinkage 和冻结表示属性核；与已研究的广义图结构学习有联系，不按控制项、KL 估计器、复用或基础设施重复计数。没有证明找到了因果结构，也不直接套用原文理论保证来替代本数据验证。
