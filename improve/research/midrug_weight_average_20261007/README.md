# 原重构训练轨迹上的固定参数平均

目标不变：原MiDrug测试seed42/43/44均值 AUC≥.9733929274、AP≥.9336833737，
PLMF MDR/MDS不下降。仅原miRNA/drug，原训练内部三折开发，无外部数据/新权重。

依据：Sapkota等，Parameter Averaging in Link Prediction，K-CAP2025，
DOI 10.1145/3731443.3771365，arXiv2510.25361v1，§3固定SWA。
论文研究KGE/MRR，不保证当前二分类AUC/AP有效；历史coldstart.py已有按验证AUC
挑top10模型做权重平均，所以平均不是首次出现的方法家族。该历史数据入口不调用。

本轮每折只产生一条从头训练的原unmasked10轨迹，同时维护：
- raw：按原内部(AUC+AP)/2选出的单轮参数，匹配训练/推理对照；
- mean：从固定第100次更新起，等权平均每一步的全部可训练参数。

100在本轮训练前固定，为原辅助权重50步预热的两倍；不按表现调整起点/窗口。
不使用验证分数决定某个快照是否进入平均，不采用论文的验证自适应ASWA。
mean自身仍按内部(AUC+AP)/2选轮，平分保留最早轮次，和raw采用同一指标规则。
其每个候选平均严格包括[100,该轮]的所有快照，无事后剔除。

原RMSprop lr1e-4、alpha.99，主干wd0、重构wd1e-4；辅助权重10、50步预热，
每步随机采样一半节点、私有seed20261006+fold。明确zero_grad(set_to_none=True)。
最多800更新、至少300；仅按raw距最佳轮次200步停止，mean不延长训练。
三折seed42，共3条训练轨迹、6个选中模型；不把6个检查点说成6次独立训练。

平均仅用于单独评估，绝不写回梯度更新轨迹、优化器或采样器。
参数求和float64；保存选中和最终累积和便于核验。BN位于固定EASE输入上，
统计量不依赖模型权重；使用当前轨迹BN缓冲，不平均整数计数、不额外校准。
所有非参数缓冲亦取当轮值。保存模型仍为原M123结构，重构解码器不影响预测。

唯一候选mean需相对纯M123、既有unmasked10、本轮raw的三折平均AUC和AP
每项均提高≥.002才进入原验证。旧测试记录不得参与选择，最终双+.02标准不变。
检查包括显式快照求和、起点单快照恒等、评估不改训练状态/梯度/优化器、
完整查询物理删除、旧raw轨迹指标对照、所存参数和累积和一致、PLMF哈希保护。
