# 全图药物源条件传播：纯miRNA迁移实验

最终目标不变：原MiDrug测试seed42/43/44均值AUC≥.9733929274、AP≥.9336833737，
PLMF两个数据集不下降。只加载原miRNA/drug白名单图、原训练内部三折。
没有lncRNA、外部数据集、序列、注释、预训练权重或新的背景图。

## 前驱与动机

两轮参数／配对表示扰动降低了对应敏感性，却未通过内部双指标推进门槛。
历史PLMF代码run_enc.py中的NBF类已有三层、精确删查询边的药物源条件传播；
该机制在更简单的PLMF配置上有效，但其REPORT_ENC.md §5明确指出叠加完整
配对通道后增益很小。因此这是当前MiDrug图上的迁移检验，不是新发明或增益保证。

已核读的BioPathNet相关方法属于NBFNet源条件传播家族。历史biopath_experiment.py
还使用其他节点、背景注释、预训练父预测和折组遮边，不能满足当前范围。
本轮只读其源码与记录作区别，没有执行那些加载器，也不导入其背景图、权重或模型。
本实现从本地PLMF三层推导重写，不原样复现BioPathNet六层DistMult/PNA。

## 固定机制

每个药物d对应一个传播上下文。初始所有miRNA为0，药物d处为共享可学习向量q；
每层在同一位置再加入该层共享边界向量。对照uniform在所有药物均匀放置
q/sqrt(n_drug)与边界向量/sqrt(n_drug)，每个上下文的总L2范数与source相同。
两配置参数量与完整传播预算相同，uniform不标记当前查询源。

传播包含正例miRNA–drug双向边、原M2使用的零对角同类型边和可学习self映射；
同类型算子按原图方向转成receiver×sender，保留重复边权重，不截取邻居或节点。
三层关系Linear→相加→LayerNorm→LeakyReLU，宽度32；无负边传播或新增伪边。
读取查询miRNA的第二／第三层状态，线性投影后加到原lin1激活前。
该投影从零初始化，等价于向原融合头追加输入列，初始化恢复原M123输出。
原M1/M2/M3和原融合头代码完整复用；推理需要这个已训练分支，不能去掉分支后
称为等价。重建解码器仍只用于训练。

## 精确查询删除

移除A[r,d]全部权重。初始miRNA状态为0，因此第一层只有r发生变化；
第二层r、自r接收消息的其他药物、同类型miRNA邻居变化；第三层只重算目标r。
删除后的d→r权重为0，因而无需用于读出路径的第二层d状态不进入修正。
非线性每次都在修正后的完整预激活上重算。此推导仅对这三个层次及初始条件成立，
不将其外推任意深度或带初始miRNA特征的网络。
sampled-zero查询的A[r,d]=0，不改变传播图，其标签只用于原关联BCE。

初始检查以float64、独立单源dense矩阵传播的物理删图为oracle，比较层2/3输出
及全部参数梯度，覆盖权重2重复关联、非对称同类型图、度一端点、零边查询。
真实MiDrug图再比较独立删图分支状态、非零新投影下的完整M123预测与各模块。

## 冻结训练／验收

source、uniform各自重建0/10，三内部折、seed42，共12次新拟合。
原主干RMSprop lr1e-4/alpha.99/wd0；新分支及其投影lr.003、wd1e-4，
该30倍学习率来自历史PLMF实现，此处预先固定，不做MiDrug半径／学习率搜索。
重建lr1e-4/wd1e-4，权重10前50轮爬升，初始化与旧unmasked10逐参数一致。
最多800轮、至少300轮、patience200，按内部(AUC+AP)/2选轮。
