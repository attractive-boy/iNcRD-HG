# Within-cell ranks of original miRNA expression

Hypothesis: original per-miRNA min-max removes relative expression magnitudes across miRNAs in a cell. A within-cell rank representation may expose stable between-miRNA order while reducing sensitivity to expression tails. This is distinct from appending row minimum/range, whose fully audited nine-fit experiment failed the frozen inner gate.

The motivating source is Souza and Mehta (bioRxiv2026, DOI10.64898/2026.02.11.705358), method A1 text in the downloaded original HTML. Its task is single-cell classification and it uses reference cell atlases; none of these external data or labels are imported. Only the within-cell rank principle is adapted. Author formula GIFs/JATS returned429, so no claim is made to reproduce the paper's exact percentile convention.

Prespecified representation: on the original float32 MiExp matrix (605miRNAs by938cell lines), rank the605miRNAs independently within each cell. Use average ranks for ties, p=(rank-.5)/605, z=normal_inverse_CDF(p). Map z to[0,1] using the symmetric theoretical rank endpoints. This final fixed affine map keeps features bounded for the original encoder. It is our transfer convention. Raw MiExp values are not asserted to be RNA-seq counts; no count normalization or pseudo-bulk/atlas construction occurs.

Matched inputs: `cell_gaussian` (eligible), `cell_minmax` (raw per-cell min-max, same axis), `row_gaussian` (Gaussian ranks across938cells within each miRNA, same nonlinearity). All input widths, model parameters, initialization, graphs, training labels, M1/M2/M3 and original feature-reconstruction targets are identical. Only the938miRNA input coordinates differ; original drug coordinates are unchanged. The auxiliary target remains the original row-minmax expression and ChemBERTa coordinates in all arms, avoiding a different auxiliary objective for each transform.

Nine fits, three existing original-training folds, seed42. Unchanged RMSprop1e-4, reconstruction weight10 with50epoch ramp, decoder weight decay1e-4, 800max/300min/patience200. Earliest maximum mean(inner AUC,AP) selects checkpoint. `cell_gaussian` must gain at least.002 in both three-fold means over each of the two matched controls, original plain M123 and existing unmasked10. No controls may be promoted after observing results. No original validation/test is read by these scripts.

Prepare/check include exact replay of the original normalized inputs, cell/name alignment, an independent direct-comparison rank oracle with ties, monotone-transform invariance, exact equality of initialized model states and original reconstruction targets, heldout-label invariance, and physical query deletion. The original frozen-test target remains both absolute+.02 and PLMF must not decline. No lncRNA or external datasets/weights are used.
