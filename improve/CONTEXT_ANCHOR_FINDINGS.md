# 通用（任务共享）锚收缩：MiDrug 提升且 LncDrug 不下降（2026-09-15）

## 结论

在已接受的 TabICLv2 参考（历史 inner：MiDrug 0.962593/0.927204，LncDrug 0.993750/0.987141）之上，
加入一个**通用、任务共享、无任何任务特定条件分支**的后处理融合：

```
score = sigmoid( (1 - w) * logit(reference) + w * mean_{m in S} logit(member_m) )
S = {HGB, ExtraTrees, MLP, LogisticRegression}   拟合在冻结的 context76 特征库上
w = 0.30，两个任务完全相同
```

**该配方通过 inner 联合门槛，并在三个独立开发重划分上确认；同时满足"MiDrug 提升、LncDrug 不下降"。**

| 表面 | MiDrug ΔAUC | MiDrug ΔAP | LncDrug ΔAUC | LncDrug ΔAP | 门槛 |
|---|---:|---:|---:|---:|:--:|
| inner（3 推理种子均值） | +0.000145 | +0.000666 | +0.000491 | +0.001008 | 通过 |
| 重划分均值（42/2026/31415） | +0.000315 | +0.000728 | +0.000400 | +0.001394 | 通过 |

逐项（`context76|hgb+et+mlp+lr|w0.30`）：

- inner MiDrug ΔAUC `+0.000124 / +0.000145 / +0.000166`（3/3 为正），ΔAP `+0.000677 / +0.000653 / +0.000667`；
- inner LncDrug ΔAUC `+0.000554 / +0.000468 / +0.000452`，ΔAP `+0.001107 / +0.000991 / +0.000927`（每个种子均 ≥0）；
- 重划分 MiDrug ΔAUC `+0.000147 / +0.000510 / +0.000287`，ΔAP `+0.000592 / +0.001012 / +0.000580`（每个划分均 >0）；
- 重划分 LncDrug ΔAUC `+0.000249 / 0.000000 / +0.000951`，ΔAP `+0.000446 / +0.000047 / +0.003688`（每个划分均 ≥0）。

## 为什么它是"通用"的

- 同一个成员子集 `{hgb, et, mlp, lr}`、同一个权重 `w=0.30`、同一套算子，MiDrug 与 LncDrug 完全一致；
- 没有任何 `if task == 'MiDrug'` 之类的任务特定分支（此前 `anchor_mixed` 只在 MiDrug 额外加 TabDPT 权重，
  属于任务特定配方，本次不采用）；
- 特征库 `context76` 的 76 列在两任务上是同一套定义；
- 唯一按任务拟合的是四个 from-scratch 学习器在各自训练对上的参数，这与任何单模型按任务训练一致，不构成结构分支。

## 信息性对照

用相同算子、相同权重、只把训练标签打乱重训（`shuffled` 对照），所有共享配方的联合门槛均为 False，
其 MiDrug AP、重划分 LncDrug 多为负值。说明真实标签携带可迁移信息，增益不是单纯方差缩减。

## 搜索与选择说明

- 共评估 60 个共享配方（2 个特征库 × 4 个成员子集 × 6 个权重 + 12 个标签打乱对照），其中 26 个通过两面联合门槛。
- 结论对子集与权重不敏感：`{hgb,et,mlp,lr}` 在 w=0.20/0.25/0.30 均通过；`{hgb,et,lr}`、`{hgb,et,rf,mlp,lr}` 也通过。
- 因此这不是"刀尖上的单点"，但仍是在**反复使用的开发划分**上选出的配方，存在选择偏差；
  不能宣称统计显著或独立生物验证。
