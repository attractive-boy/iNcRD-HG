# ncRNA–drug 模型结构改动：两轮实验交付

**保留原关联预测方向，已实现“节点与配对状态联合编码”及“双流配对编码”两种结构重构；当前两轮主候选均未通过预设筛选，还没有找到同时提升两个任务、且结构消融支持的新架构。**

后续已完成一轮 [双流参数补救](DUAL_PAIR_TUNING.md)：追加 122 次正式训练及全部重放，MiDrug 相对旧双流参数有小幅改善，LncDrug 的 AUPR 未改善，整体结构结论未改变。该追加实验的完整数值见 [调参最终结论](results/dual_pair_tuning_20260910/FINDINGS.md)；下文保留最初两轮结构实验记录。

结构主线从“一个 RNA 节点向量服务全部药物”，扩展到“每个 RNA–drug 配对有自己的隐藏状态”。相邻配对可以沿 RNA 关系或药物关系交换信息。第二轮又为配对自身交互保留独立分支，与传播分支共享输入投影和最终解码器。整个系统仍预测一个关联分数，保持原数据、标签和 BCE 目标。

这是已落地的结构改动：新状态由输入计算、参数在配对间共享，不是配对 ID 查表；两条坐标上的稀疏计算避免显式构造完整配对图的邻接矩阵。它仍要存储 RNA 数 × 药物数 × 隐藏维数的状态，不能宣称解决任意规模的图扩展问题。

**第二轮五种子外层验证均值**

| 结构 | LncDrug AUC / AUPR | MiDrug AUC / AUPR |
|---|---:|---:|
| 固定默认原结构 | 0.979086 / 0.940822 | 0.951771 / 0.911385 |
| 相同查询训练的原结构 | 0.981532 / 0.949808 | 0.955986 / 0.919570 |
| 双自身交互 | 0.981946 / 0.951544 | 0.955998 / 0.919432 |
| 双邻域传播 | 0.982001 / 0.953605 | 0.955980 / 0.919464 |
| 自身交互 + 邻域传播 | 0.980933 / 0.951753 | 0.954939 / 0.917528 |

只与默认原结构比较，双流主模型的 AUPR 增加约 1.09/0.61 个百分点；相同查询训练原结构也增加约 0.90/0.82 个百分点。因此不能把双流模型相对默认设置的全部增益写成结构贡献。MiDrug 上，主模型在五个种子中的 AUC/AUPR 均落后于查询原结构及两个同规模对照。

LncDrug 的配对非线性交互值得保留为后续设计线索：第一轮单分支和第二轮双自身交互，相对各轮查询原结构的 AUPR 均值分别增加 0.004259/0.001736。第二轮双传播的 LncDrug AUPR 均值更高，但它与双自身交互的配对比较只有 3/5 个种子提高，且 MiDrug 未同步受益。这些是后验线索，不是两类 RNA 的生物机制差异证明。

**论文叙事的边界**

“共享节点表示可能不足以刻画具体 RNA–drug 配对”可以作为研究动机；“配对表示如何沿关系传播”可以描述技术实现。若要写成性能与创新贡献，仍须证明它超过相同训练设置、同规模的逐配对模型，并在重新冻结的数据划分上成立。当前实验没有支持“两个分支互补带来稳定提升”，也不支持“首次实现配对表示”或“发现耐药因果机制”。

两轮均使用既有且反复查看的外层验证集；第二轮受到第一轮结果启发。初始化种子不能替代新划分验证。图还包含工作区原有 circRNA 扩展，所以默认对照不等于原论文的原样复现。

当前交付建议是保留完整代码和否定结果，将双流主模型标为未通过，继续把采用查询遮边训练的原结构作为公平比较基线。后续配对结构应先证明“传播这一步有可重复的额外作用”，再据此组织核心故事。
