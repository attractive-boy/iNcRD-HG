**新增一条通过开发验证的非表格方向：冻结 REIFM 图表示＋属性核。MiDrug 与 LncDrug 的全局 AUC/AP 在三个重划分上均提高，并通过预设机制对照门槛；三种不同创新技术的目标仍未达到。**

最新完整结果见 [REIFICATION_TRANSFER_FINDINGS.md](REIFICATION_TRANSFER_FINDINGS.md)。三个重划分平均，MiDrug ΔAUC/ΔAP 为 **+0.003040 / +0.003653**，LncDrug 为 **+0.001749 / +0.004033**。MiDrug 在三个划分都胜过原核和随机权重图编码器对照。该结果是已用、重叠开发数据上的确认；AP 与机制增量的分组扰动区间仍包含零，且 LncDrug 药物宏 AP 有回退。当前强 TabICL 参考未替换。

以下经典核及失败方向保留为完整历史证据；新图迁移方案修复了经典核在历史 LncDrug AP 上的明显回退。新增 18 次确认拟合后，此处列举的本轮非表格拟合运行共 220 次；冻结上下文推理和校准器另计。

2026-09-14。以下结果来自完成审计的 156 次训练/确认运行，评价均为全局 ROC AUC 与 `average_precision_score`。相同开发数据的重划分不等于独立生物验证；没有读取原始测试标签。本报告补充并限定早先 `NONTABULAR_TRANSFER_FINDINGS.md` 的结论：那个报告中的多种预测器仍使用表格特征，且主要比较更强的 TabICL 参考，不能据其结果否定直接图模型相对原 GNN 的改进。

**可以保留的结果：原 GNN＋乘积核逻辑模型。**

模型直接计算 RNA–药物分数矩阵，节点核来自原始属性与注释基因身份。它使用低秩张量积交互、节点加性项及正则化逻辑似然；不使用 36/62/76 列配对特征库。历史内部探索后，固定为 `0.5 × GNN logit + 0.5 × kernel logit`，在三个开发集重划分上重新训练。两个任务都应用此修改，无 LncDrug 专用旁路。

|任务|原 GNN AUC / AP|GNN＋核 AUC / AP|平均 ΔAUC / ΔAP|两指标同升的划分数|
|---|---:|---:|---:|---:|
|MiDrug|0.953756178 / 0.909479565|0.956018916 / 0.912437249|+0.002262738 / +0.002957685|3/3|
|LncDrug|0.986627271 / 0.971681158|0.987827854 / 0.972913697|+0.001200583 / +0.001232539|3/3|

这些数字比较的是修正后、查询边屏蔽的 GNN 实现；并非论文未改动协议。重划分为 42、2026、31415，模型种子固定为 20260914。它们的平均指标与历史内部划分不同，不能交叉比较。

**必须同时保留反面证据：** 相同核组合在历史内部划分中，LncDrug AUC/AP 为 **0.989598 / 0.969908**，相对该划分原 GNN 的 **0.989621 / 0.975741**，AP 下降 **0.005834**。MiDrug 在该划分仍提高约 +0.002403 AUC / +0.002514 AP。已核对两处保存的 GNN 分数均为原始 logit，不是混用了概率。这说明“通过三个重划分的预设工程门槛”不等于所有已使用开发划分均无损，也不足以保证实际统一替换满足 LncDrug 约束。

MiDrug 相对“GNN＋仅节点加性核”仍有 ΔAUC **+0.001060211**、ΔAP **+0.001562929**，说明此处交互项有额外信号。但是经典核逻辑模型本身不构成前沿新发明，此项记作工程改进，不能充当三项创新中的三个变体。

**增益的范围和不确定性。**

使用 1,000 次 RNA 与药物两端分组扰动：分别抽取 Poisson(1) 权重，相乘后给配对加权；三个重叠划分共享同一端点权重。下表是给定已训练模型的描述性 2.5–97.5% 区间，没有重新训练模型，也不是独立外部数据的置信保证。
