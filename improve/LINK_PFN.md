# 缺失机制感知的链路 PFN：紧凑验证

2026-09-12。落实 [创新方案第 2 条](research/innovation_directions_20260910/PROPOSAL.md)：先检验合成关联先验能否迁移到真实的新药物与少支持预测。实现采用现有 Python 3.8 / PyTorch 1.13 环境；正式结果、冻结参数和核验记录保存在 `results/link_pfn_20260912/`。

本轮是从头训练的小型 prior-data fitted network。它直接以带标签的 RNA–drug 配对作为上下文，以未知配对作为查询，在合成任务上学习条件预测。它没有使用官方 GraphPFN/TabPFN 权重，也不是原论文百万级预训练的复现。

## 模型与先验

每个配对输入 59 个量：25 个当前支持图的结构/属性支持统计、两端各 16 维属性、2 维 RNA 任务类型。结构统计包括目标度数、相似关系传播、三步路径、跨 RNA 类型支持及属性支持；全部依赖显式传入的可见关联矩阵。RNA/药物的标准化和 PCA 仅在拟合端点上训练。原始 circRNA 关系在所有组中均不使用。

模型宽度 64、两层、4 个注意力头。支持 token 含已观测标签；查询 token 使用独立的未知标签标记。注意力加入同 RNA、同药物、RNA 属性余弦、药物属性余弦及余弦乘积五种关系偏置。节点索引只用于判定端点相同，没有可训练的实体 ID 表。查询只读取上下文，不读取其他查询，因此改变查询顺序、分批大小不会引入额外证据。两次固定上下文采样的 logit 均值作为预测；每次最多 128 个支持 token，结构统计仍利用全部可用支持，RNA 候选不做截断。

| 组 | 合成预训练 | 真实适配 |
|---|---|---|
| `scratch` | 无 | 相同链路 PFN |
| `random` | 随机属性函数产生关联，辅助图独立生成 | 相同链路 PFN |
| `hetero` | 共享潜在社区/属性产生两类关联与辅助关系，均匀漏记正例 | 相同链路 PFN |
| `missing` | 同一异构世界，药物/RNA 属性相关漏记及零曝光药物 | 相同链路 PFN，主候选 |
| `tabm` | 无 | 相同 59 维配对特征的 TabM |

`hetero` 与 `missing` 在每个合成种子下共享潜在完整关联、辅助图和查询划分，并匹配预期使用的正例观测数量；零曝光后的可用池不足时观测数按池大小截断。差异是哪些正例可见。生成器并不知道真实评估标签，其参数是预先指定的仿真假设，没有拟合真实缺失概率。

合成支持标签为观测关联 O，零值可包含漏记的真实正例；合成查询监督为完整潜在标签 Y*。整个查询候选池在特征构建前移出支持图。冷药物合成任务同步清空两种 RNA 关系。上下文与查询按约 1:2 采样正例和零例，与完整候选总体的阳性率不同，输出不解释为校准的生物学概率。

每个先验使用 4,096 个合成任务、512 个优化步骤，三个初始化为 666、0、1。三个初始化共享同一任务库；因此方差只刻画初始化差异。记录 512、2,048、4,096 个任务时的模型及合成留出指标。留出分布包括普通异构、非均匀缺失、同时改变稀疏度/属性耦合/漏记率，以及额外加入约等于观测正例数 5% 的假阳性。最后一种比例不是“所有真实阴性的 5%”。

## 真实数据边界

只读取原外层训练的 `pairs_train`、`y_train` 和原始端点属性。旧图在单任务设置下包含另一 RNA 任务的全量关联；本轮丢弃这些关联及反向边，使用两任务各自的训练正例重建矩阵。相反方向始终由矩阵转置产生。

按两任务合计训练正例数分层，将 216 个药物身份划为五组，固定种子 `2026091201`。前三组拟合、第四组选参、第五组评估。内部训练每次再留出一个拟合药物组，删除该组在两种 RNA 关系中的全部标签。化学属性、RNA 属性及固定的相似/跨 RNA 辅助关系可用，所以这里的冷启动专指关联标签冷启动。

| 部分 | 药物数 | LncDrug 正例 | MiDrug 正例 |
|---|---:|---:|---:|
| 拟合 | 132 | 941 | 2,116 |
| 选参 | 42 | 191 | 535 |
| 评估 | 42 | 134 | 585 |

对选参和评估药物，各预留最多 3 条且不超过其正例一半的记录用于少支持实验。全部预留行在所有支持预算下均从查询集排除。评估时分别揭示每药物 0、1、3 条本任务正关联；另一个 RNA 任务的该药物标签保持隐藏。新增正例必定进入 PFN 上下文，所有组重新计算支持图特征，不在评估药物上更新模型权重。

共同评估查询为 LncDrug 593 行（121 个已知正例）、MiDrug 1,791 行（544 个已知正例）；能计算双类别药物宏 AP 的药物分别只有 11 和 32 个。小样本宏指标的不确定性需要保留。

分组只改变开发验证方式，没有创造新的外部数据。历史外层验证和测试数组均不载入；此前可用训练数据上的新分组仍属于开发证据。

## 选参与判定

每组用 seed 666 搜索两个学习率：PFN 为 `1e-4/3e-4`，TabM 为 `1e-3/3e-3`；最多 300 个适配步骤，每 20 步评估一次。以最近三次 `0.5*药物宏 AP + 0.25*(AP+AUC)` 的均值选一个实际检查点，第 0 步也参与比较。冻结学习率后使用 0、1 两个初始化，仍只用选参药物选择检查点。全部模型路径冻结后才评价第五组，没有根据评估结果重训或改选。

四组 PFN 的架构、真实任务抽样、预算相同；三种预训练组的合成任务数与计算步骤也相同。TabM 采用相同配对特征和两配置搜索，但使用其自身的内部集成和批大小，属于完整预测器对照。

主终点是零支持药物宏 AP，同时跟踪 AP/AUC。`missing` 相对 `scratch` 与 TabM 的两任务平均宏 AP 提升需超过 0.005，相对 `random/hetero` 需为正；各任务宏 AP 差不得低于 −0.005，平均 AP/AUC 差不得低于 −0.005，且三个初始化中至少两个的两任务平均宏 AP 差为正。各项分别报告；这些是原型筛选阈值，不是显著性或非劣效检验。

少支持结果、全候选 Recall@20、不更新真实任务权重的上下文迁移以及上下文标签/关系偏置干预均为辅助诊断。上下文标签干预固定图统计，不能解释为删除全部图证据。真实数据零标签仍代表未观测关联；仿真中的完整真值不能消除真实观测机制的不可识别性。

## 复现

在仓库根目录使用 `ncRNAdrug` 环境，并设置 `OMP_NUM_THREADS=4 MKL_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4`：

```bash
python -m unittest improve.test_link_pfn -v
python -m improve.link_pfn prepare --out-dir improve/results/link_pfn_20260912
python -m improve.run_link_pfn_pipeline \
    --out-dir improve/results/link_pfn_20260912 --devices cuda:0,cuda:1
```

短流程在独立目录对 `prepare` 加 `--smoke`。流水线依次生成合成任务、缓存训练特征、预训练、选参、冻结、评估和重放。各作业的文件哈希、源码快照、标签分组及日志均保存；完成的作业经检查后跳过。修改冻结训练源码时必须新建实验目录。

14 项单元检查覆盖两类关联同步删除、查询标签/评估标签隔离、拟合端点 PCA、固定少支持查询、先验配对、顺序和分批不变性、可用梯度及实际检查点选择。正式核验重算全部场景特征、重放适配与合成阶段检查点，并复算指标。

## 来源与贡献边界

[GraphPFN](https://arxiv.org/abs/2509.21489) 的已核对 v4 明确不直接支持链路任务。其[官方仓库](https://github.com/yandex-research/graphpfn) README 仍提供节点任务接口；仓库许可证为 Apache 2.0，要求 Python 3.11+，推荐 PyTorch 2.4/DGL。代码、依赖和许可证的查询记录见 [source_audit.json](research/link_pfn_20260911/source_audit.json) 与 [后续依赖核对](research/link_pfn_20260911/compatibility_followup.json)。原 `requirements.txt` 请求为 404，随后成功读取 `pyproject.toml`；本次 UniLP 摘要页连接失败，保留失败记录并沿用已有方案核对，不将失败请求算成成功验证。

本原型借鉴 PFN 的合成任务条件预测原则，采用自写的配对入口、显式异构描述符和关系注意力。上下文链路预测已有 [UniLP](https://arxiv.org/abs/2402.07738) 等先例。检验重点是不同先验能否带来真实迁移增量；当前设计本身不构成新颖性认证，也不能据小规模成败推断全部 PFN 方法有效或无效。
